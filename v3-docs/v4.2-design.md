# TFS-Net v4.2 — 先去噪后提亮 + Retinexformer 风格乘法提亮

## 版本演进
| 版本 | 核心变更 |
|------|---------|
| v4   | 并行三源 concat 融合 |
| v4.1 | IGRF 顺序级联（光照→噪声→运动）+ IFPN 加法残差 |
| v4.2 | **去噪→运动→提亮**（先降噪后提亮，避免噪声放大）+ Retinexformer 乘法提亮 + `.detach()` 梯度截断 |

---

## 1. 设计动机

### 1.1 v4.1 的两个问题

**问题 A：提亮操作放大噪声**

v4.1 的修复顺序是 光照→噪声→运动，即先提亮再去噪。但数学上：

```
img_brightened = img_dark × lit_up_map
noise_brightened = noise × lit_up_map   ← 噪声同步放大！
```

乘法提亮会按比例放大所有像素值，包括噪声。即使后续 StageBlock 有去噪功能，它面对的是已被放大的噪声，去噪难度增加。

**问题 B：中间监督梯度穿透**

v4.1 中 `img_s2 = img_s1 + delta_2`，L_s2 的梯度通过 img_s1 回传到 Stage_illum，与 L_s1 的直接监督信号互相干扰（详见 §3.4 讨论）。

---

## 2. 核心设计：先去噪后提亮

### 2.1 物理依据

低光成像退化模型：

```
y = γ(x*k + n)
```

其中：
- `x`：真实场景
- `k`：运动模糊核
- `n`：传感器噪声
- `γ`：低光非线性亮度衰减（gamma-like）

**修复逆序**（v4.1 的思路）：先逆 γ（提亮），再逆 n（去噪），最后逆 k（去模糊）

**改进思路**（v4.2）：先去噪，再去模糊，最后提亮

```
v4.1: y → 逆γ(提亮) → 逆n(去噪) → 逆k(去模糊) → x
v4.2: y → 逆n(去噪) → 逆k(去模糊) → 逆γ(提亮) → x
```

**优势**：
- 去噪在低亮度域操作，噪声未被放大，SNR 虽低但噪声幅度小
- 提亮作用于已去噪的图像，乘法仅放大干净信号，不放大噪声
- 参考 **DarkIR (CVPR 2025)** 的设计理念：先在暗域降噪，再提亮

---

### 2.2 IGRF v4.2 顺序级联融合

```
image_center（低光原始帧）
    ↓ StageBlock_noise(f_noise_out, image_center.detach())  ← 去噪，detach 防止穿透
  img_s1（已去噪但仍然暗）
    ↓ StageBlock_motion(f_motion_out, img_s1.detach())      ← 运动修复
  img_s2（已去噪 + 去模糊，但仍暗）
    ↓ Retinexformer 风格乘法提亮
  res_t = img_s2 × lit_up_map                                ← 提亮，得到最终输出
```

**关键区别**：
- v4.1 的 Stage_illum 是一个 StageBlock（加法残差修复）
- v4.2 的提亮是乘法操作 `img × lit_up_map`，lit_up_map 由 IFPN 特征投影得到

---

## 3. 模块设计详述

### 3.1 lit_up_map 估计（IFPN 改造）

IFPN 已有 IllumExtract 估计光照图 L_t 和邻帧参考 L_ref，并计算 L_ratio。在 v4.2 中，IFPN 不再将光照信息编码进特征空间，而是**直接输出提亮图 lit_up_map**：

```
L_ratio = L_ref / L_t                   ← 光照比率（应提亮多少倍）
lit_up_map = refine_up(L_ratio)         ← 精化提亮图（附加卷积微调）
```

其中 `refine_up` 是一个轻量精化网络：

```python
self.lit_up_refine = nn.Sequential(
    Conv2d(img_channels, 16, 3, 1, 1), GELU(),
    Conv2d(16, img_channels, 1, 1, 0),
)
```

IFPN v4.2 输出：
```python
return {
    "lit_up_map": lit_up_map,     # (B, 3, H, W) 提亮图，值域 > 1
    "f_illum_feat": f_illum_feat, # (B, C, H, W) 光照特征（供 IGRF 用）
    "L_ratio": L_ratio,           # (B, 3, H, W) 原始光照比率
}
```

**为什么 lit_up_map 是图像空间而不是特征空间？**

Retinexformer 的核心思想是：光照图直接作用于图像像素（乘法），物理意义是"每个像素需要提亮多少倍"。将光照信息保留在特征空间（v4/v4.1 的做法）需要 IGRF 再将其解码回图像空间，增加了学习难度。直接输出 lit_up_map 更物理、更直接。

### 3.2 IGRF v4.2 — 去噪→运动→乘法提亮

```python
class BrightenStage(nn.Module):
    """Retinexformer 风格乘法提亮阶段"""
    def __init__(self, channels, img_channels=3):
        super().__init__()
        # 将光照特征编码为条件
        self.feat_proj = nn.Conv2d(channels, img_channels, 3, 1, 1)
        # img_s2 条件编码
        self.img_proj = nn.Conv2d(img_channels, img_channels, 3, 1, 1)
        # 融合后精化 lit_up_map 的残差修正
        self.delta_refine = nn.Sequential(
            nn.Conv2d(img_channels * 3, img_channels, 1, 1, 0),
            nn.GELU(),
            nn.Conv2d(img_channels, img_channels, 3, 1, 1),
        )

    def forward(self, lit_up_map_raw, f_illum_feat, img_dark):
        """
        Args:
            lit_up_map_raw : IFPN 输出的原始提亮图
            f_illum_feat   : IFPN 输出的光照特征
            img_dark       : 已去噪+去模糊但仍暗的图像（detach）
        Returns:
            res_t : (B, 3, H, W) 提亮后的最终输出
        """
        feat_cond = self.feat_proj(f_illum_feat)
        img_cond = self.img_proj(img_dark)
        # 残差修正提亮图：lit_up_map = lit_up_map_raw + delta
        delta = self.delta_refine(torch.cat([lit_up_map_raw, feat_cond, img_cond], dim=1))
        lit_up_map = torch.exp(lit_up_map_raw + delta)  # exp 确保 > 0
        res_t = torch.clamp(img_dark * lit_up_map, 0.0, 1.0)
        return res_t, lit_up_map


class IGRF(nn.Module):
    """IGRF v4.2 — 去噪 → 运动 → Retinex 乘法提亮"""
    def __init__(self, channels=64, out_channels=3):
        super().__init__()
        self.stage_noise  = StageBlock(channels, out_channels)   # 去噪
        self.stage_motion = StageBlock(channels, out_channels)   # 运动修复
        self.brighten     = BrightenStage(channels, out_channels) # 乘法提亮

    def forward(self, f_illum_feat, f_noise_out, f_motion_out,
                lit_up_map_raw, image_center):
        # Stage 1: 去噪（在低光域降噪，噪声幅度小）
        img_s1, delta_s1 = self.stage_noise(f_noise_out, image_center)

        # Stage 2: 运动修复（detach 截断梯度穿透）
        img_s2, delta_s2 = self.stage_motion(f_motion_out, img_s1.detach())

        # Stage 3: Retinexformer 风格乘法提亮
        res_t, lit_up_map = self.brighten(
            lit_up_map_raw, f_illum_feat, img_s2.detach()
        )

        return {
            "res_t":       res_t,
            "img_s1":      img_s1,        # 中间监督（去噪结果）
            "img_s2":      img_s2,        # 中间监督（去噪+去模糊结果）
            "lit_up_map":  lit_up_map,    # 提亮图（可做光照监督）
        }
```

### 3.3 梯度流分析 — `.detach()` 截断

**v4.1 的梯度穿透问题**：
```
img_s2 = img_s1 + delta_2
∂L_s2 / ∂img_s1 = ∂L_s2 / ∂img_s2 × 1  ← 梯度穿透！
```

**v4.2 的 `.detach()` 截断**：
```
img_s2, delta_2 = self.stage_motion(f_motion, img_s1.detach())
                                                 ↑ detach 截断
∂L_s2 / ∂img_s1 = 0  ← 不再穿透到 Stage_noise！
```

每阶段的梯度来源：
- **Stage_noise (去噪)**：仅从 `L_s1 = Charb(img_s1, GT_dark)`（对去噪后暗图的监督）
- **Stage_motion (运动)**：仅从 `L_s2 = Charb(img_s2, GT_dark)`
- **BrightenStage (提亮)**：仅从 `L_final = Charb(res_t, GT)` 和 lit_up_map 的光照监督

三阶段梯度完全隔离，互不干扰。

---

### 3.4 乘法提亮的梯度稳定性

乘法提亮的公式：
```
res_t = clamp(img_dark × exp(lit_up_raw + delta), 0, 1)
```

梯度分析（对 delta 参数）：
```
∂res_t / ∂delta = img_dark × exp(lit_up_raw + delta) = res_t  ← 梯度与输出成正比！
```

**关键**：梯度 ∂res_t/∂delta = **res_t**（已提亮后的图像值），而非 img_dark（暗图像值）。
- 在暗区域：res_t 值适中（已提亮），梯度合理
- 不存在"暗区域梯度消失"问题
- 这是因为 exp 变换将乘法转换为加法（log 空间），梯度自动与输出而非输入成正比

对比 v4 的乘法调制（特征空间）：
```
v4:  f_illum = F_t × (1 + ratio_feat)
     ∂f_illum / ∂ratio_feat = F_t  ← 梯度与输入成正比，暗区域 F_t 小 → 梯度弱

v4.2: res_t = img × exp(lit_up)
      ∂res_t / ∂lit_up = img × exp(lit_up) = res_t  ← 梯度与输出成正比，提亮后值适中
```

## 4. 损失函数 v4.2

中间监督的对象改为**暗域 GT**（因为 img_s1 和 img_s2 是去噪/去模糊后的暗图）：

```
GT_dark = GT / lit_up_map_GT    ← 逆提亮得到暗域参考
```

但 lit_up_map_GT 不容易获取。更实际的方案：**对中间结果不做精确 GT 监督，而是做光照一致性约束**：

```
L_total = L_recon + λ_ssim·L_ssim + λ_perc·L_perc + λ_illum·L_illum + λ_inter·L_inter

L_recon  = Charbonnier(res_t, I_GT) + λ_freq · L1(|FFT(res_t)|, |FFT(I_GT)|)
L_inter  = (1/2) · [L1(img_s1, I_GT/L_ratio_est) + L1(img_s2, I_GT/L_ratio_est)]
           ← 中间监督：去噪/去模糊后应接近"暗域 GT"
L_illum  = edge_aware_smooth(lit_up_map, I_GT)
           ← 提亮图边缘感知平滑（不引入新边缘）
```

或者更简单：中间监督用 **自监督约束**（中间结果提亮后应接近 GT）：

```
img_s1_brightened = img_s1 × lit_up_map   ← 假设提亮图适用所有阶段
L_s1 = Charbonnier(img_s1_brightened, I_GT)

img_s2_brightened = img_s2 × lit_up_map
L_s2 = Charbonnier(img_s2_brightened, I_GT)

L_inter = (1/2) · (L_s1 + L_s2)
```

这种设计的优势：无需估计暗域 GT，用同一个 lit_up_map 对中间结果提亮后监督。
