## 一、数据集与协议

| 项 | 当前口径 | 说明 |
|---|---|---|
| 训练 | SDSD（低光视频，静态/动态场景） | 配置见 `configs/v8_5/`、`configs/v8/` |

**注意**：M 支路的运动修复能力在 SDSD 上未被验证（跨帧变形对齐在 SDSD 上无工作量）。§4 若声称运动修复，必须在有真实动态运动的数据集上验证，或在 limitation 中说明。

## 二、指标

- PSNR / SSIM（与基线同协议）；LPIPS（感知质量，当前协议已含）。
- 可选：NIQE（无参考，真实场景用）。
- 复杂度：Param (M) / FLOPs (G) / Memory (GB) / Latency (ms) / FPS。

## 五、消融设计（已有数据 + 待补）

**已有**（kvmod 配置，30ep）：
- 分支必要性（置零）：N −0.62 dB / L −17.4 dB / M −0.57 dB。
- QRB 变体：cross_rwkv 25.03 → kvmod 25.16（+0.13，LPIPS 0.395）→ qpath 24.95；gatectx 中断不采用。
- 门控健康度：N/L/M 饱和率 ≤2.3%，L 段饱和率从 v9 的 31% 降到 1% 以内。
- 扰动响应（加噪 σ=0.05）：cross_rwkv −6.51 / kvmod −7.85 / qpath −8.42 dB——感知质量与噪声鲁棒性不同向，可写成诚实的讨论点。
- 损失对照：v8.7-nl（纯 L1+MS-SSIM）25.60，分工崩溃；v8.7-ssim 25.90，感知双最。

**建议补**（写 §4 时按实验条件选做）：
- 三源分解必要性：两源合并（如 N+M 同池）的对照——直接支撑 §3.1 的"两源不够"论证。
- 帧数 T 的影响（线性复杂度的直接证据）。
- RWKV 扫描 vs 全注意力（同参数量对照）。
- 门正则 λ_g 的敏感性。
