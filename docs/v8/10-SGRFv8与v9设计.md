# SGRFv8 与 SGRFv9: 分阶段融合的两次实现

> 创建于 2026-10-22
> 代码: `models/golf_v7r/sgrf_v8.py`(基线, 不再修改)、`models/golf_v7r/sgrf_v9.py`
> 配置: `configs/v8_5/a_lite_sgrf_30ep.yaml`、`configs/v8_5/a_lite_sgrf9_30ep.yaml`
> 上一版轻量聚合见 `09-A方案轻量聚合设计.md`

## 一、为什么要做分阶段融合

在此之前的所有融合方式都是**并行**的: N、L、M 三路各自从同一份 F1 特征出发, 各自输出
一张图, 最后由逐像素权重加权求和。三路之间没有任何信息依赖。

TSDR 描述的三类退化有先后关系: 曝光决定了噪声的绝对强度, 噪声与运动都作用在同一个
曝光结果上。并行融合无法表达这种依赖。分阶段融合让每一段以上一段的结果为输入, 使
"先去噪、再定曝光、最后修运动"这个顺序成为结构的一部分。

## 二、SGRFv8: 加性串接

### 2.1 结构

```
X_0 = 0                       (三路频带目标之和等于 GT, 从零累加)
Δ_N = Y_N(F_N)                X_N = X_0 + s_N·Δ_N
F_L = F_L + proj_L(X_N)       X_L = X_N + s_L·Y_L(F_L, X_t)
F_M = F_M + proj_M(X_L)       X_M = X_L + s_M·Δ_M
O_t = clamp(X_M, 0, 1)
```

三条原则: 加性串接 (每段对输出的偏导恒为 `s_k`); 级间不 clamp (只有最终输出截断);
每段输入是上一段累加结果映回特征后加到本段 TCA 特征上。

`proj` 与 `s_k` 都是零初始化或初值 1, 因此训练起点与并行加性融合完全一致
(单测误差 0.0e+00)。

需要记录一个实现时的修正: 最初的版本以中心帧 `X_t` 作为累加起点, 这是错的 ——
三路目标之和已经是 GT, 再加上中心帧会把光照重复计入两次。

### 2.2 30 轮结果

| 轮次 | PSNR | SSIM | LPIPS | 训练 loss |
|:--:|:--:|:--:|:--:|:--:|
| 5 | 21.66 | 0.7022 | 0.5063 | 0.5792 |
| 10 | 23.15 | 0.7772 | 0.4969 | 0.5140 |
| 15 | 24.10 | 0.7836 | 0.4678 | 0.4880 |
| 20 | 24.71 | 0.8101 | 0.4392 | 0.4764 |
| 25 | 24.64 | 0.8016 | 0.4334 | 0.4605 |
| 30 | **24.89** | 0.8097 | 0.4270 | 0.4584 |

曲线形状回答了"学得慢还是学不动": 第 5 到 15 轮每 5 轮涨 1.0 至 1.5 dB, 第 15 到 30 轮
仍涨 0.79 dB, 训练损失从 0.579 单调降到 0.458, 没有平台化也没有回落。结论是**学得慢**。

同预算对比并行版 `a_lite`: 第 10 轮 23.15 对 24.12 (落后 0.97), 第 15 轮 24.10 对 24.65
(落后 0.55), 到第 30 轮反超 (24.89 对 24.65)。串接结构起步慢, 因为第一段没学好时
后面两段拿到的是错误的输入。

### 2.3 分支指标

| 项 | SGRFv8 (ep30) | a_lite (ep15) |
|---|---|---|
| 相对误差 N / L / M | 0.647 / 0.117 / **0.561** | 0.659 / 0.126 / 0.667 |
| 置零代价 N / L / M (dB) | −0.437 / −17.24 / −0.133 | −1.145 / −16.83 / −0.560 |
| 阶段系数 | 1.628 / 1.002 / 0.405 | — |
| 加噪 σ=0.05 | 18.26 | 19.80 |

M 路的相对误差是三组并行融合都没达到的水平 (0.561), 但它的置零代价只有 −0.133 dB,
是三组里最小的。阶段系数显示 N 段被放大到 1.628、M 段被压到 0.405, 与置零代价的
方向不一致 —— 这说明"学得好"与"用得上"在这个结构里脱节了。

## 三、SGRFv9: 门控渐进式恢复

### 3.1 针对 SGRFv8 的三个问题

1. **阶段依赖过强**: L 段置零代价 −17.2 dB, M 段 −0.13 dB, 最终图像几乎完全由 L 决定;
2. **串接误差累积**: 后一段直接接收前一段预测的图像, 没有任何机制抑制误差传播;
3. **贡献机制单一**: 一个全局标量独自决定整段贡献, M 段被压到 0.405 后就没有翻盘机会。

### 3.2 结构

每段改为"读取当前状态 + 预测针对当前状态的修正量 + 空间自适应门控":

```
X_0 = 0
Δ_N = lift_N(Y_N(F_N))                     G_N = σ(gate_N([X_0, F_N]))
X_N = X_0 + s_N · G_N ⊙ b(Δ_N)

F_L' = F_L + proj_L(X_N)
Δ_L = Y_L(F_L', X_t)                       G_L = σ(gate_L([X_N, F_L']))
X_L = X_N + s_L · G_L ⊙ b(Δ_L)

F_M' = F_M + proj_M(X_L)
Δ_M = lift_M(Y_M(F_M', F2))                G_M = σ(gate_M([X_L, F_M']))
X_M = X_L + s_M · G_M ⊙ b(Δ_M)

O_t = clamp(X_M, 0, 1)
```

其中 `b(Δ) = δ·tanh(Δ/δ)` 是软限幅 (δ = 0.5), 在 `|Δ| << δ` 时近似恒等。

### 3.3 五个设计决定

**门控初值 0.5, 不饱和。** 门是两层卷积, 末层权重与偏置均零初始化, 因此初始
`σ(0) = 0.5` —— 每段初始贡献一半, 各处一致。若用大偏置 (如 2.0) 会接近全开而失去
门控意义, 用负偏置会让早期阶段被压制, 正是 v8 的病灶。

**阶段幅度有界。** `s_k = 1 + 0.5·tanh(a_k) ∈ [0.5, 1.5]`, 初值 1。它只调整体幅度,
不承担逐位置的选择职责。这样既不会出现 0.405 那种压制, 也不强制三段等权。

**增量软限幅。** 这一条是冒烟测试暴露问题后加的。三个分支的初始化并不一致: N 与 L
内部有零初始化或 clamp 约束, M 的 `to_rgb` 是普通卷积, 输出幅度不受控。实测加限幅之前,
6 步内 M 段增量从 0.024 涨到 0.431, 而 L 段从 0.097 收缩到 0.017 —— 失衡只是换了个方向。

**阶段专属形式。** N 与 M 的增量各经一次逐通道 3×3 卷积 (恒等初始化), 强调局部结构;
L 直接复用分支自己的 Retinex 重建 (曲线 + 增益), 不额外堆叠通用卷积头。三个分支网络
本身完全不变, 它们各自的归纳偏置 (N 的通道注意力、L 的 Retinex、M 的运动精化) 保留。
没有引入光流, 没有 Conv+PixelShuffle。

**门控正则。** 单测与探针发现: 门在 80 步内饱和到 0.98 以上, 饱和后 sigmoid 导数趋零,
该段就永久失去调节能力。因此在损失里加入 `w_gate_reg · mean((G − 0.5)²)`, 默认权重 0.05,
把门保持在可调区间。这是 SGRFv9 的专用项, 其余融合模式自动忽略。

### 3.4 损失

分支辅助监督与最终重建监督完全不变。新增的只有门控正则一项。没有引入 LPIPS 损失:
现有损失里只有 `w_ssim` 开关, 没有感知项实现; 按"先修复评价与训练接口再引入"的原则,
本轮不加, 以免同时改动两个变量导致无法归因。

### 3.5 参数与计算量

| 项 | SGRFv8 | SGRFv9 |
|---|---:|---:|
| 融合模块 | 195 | 15.57K |
| 全模型 | 1.220M | 1.235M |
| FLOPs (推理) | 95.67 G | 待测 |

新增的 15.4K 来自三个门控网络 (每个约 4.6K)、两个状态投影 (各 96)、两个逐通道卷积
(各 27)。量级可以忽略。

### 3.6 已经发现的结构性事实

用真实损失跑 120 步探针, 测到三个分支目标的幅度本身相差近 10 倍:

| 分支 | 目标名 | 目标平均绝对值 | 同一步的输出幅度 |
|---|---|---:|---:|
| N | noise_target | 0.197 | 0.099 |
| L | illum_target | 0.500 | 0.511 |
| M | motion_target | 0.054 | 0.006 |

L 的目标本身就带有完整的低频能量 (GT 的低频分量), 另外两路是零均值频带, 幅度小一个量级。
因此 L 段主导有其来源, 不是门控的错, 也不是阶段系数选错了。这一点在评估 SGRFv9 时
必须分开看: 如果 L 仍占主导, 需要判断是因为它的目标量级本来就大 (合理), 还是因为
另外两段没有发挥作用 (问题)。

### 3.8 判据

不以 PSNR 的零点几 dB 提升作为成功标准。同时检查:

| 维度 | 希望看到 |
|---|---|
| 重建质量 | PSNR 保持竞争力 (不低于 24.7), LPIPS 相对 SGRFv8 的 0.427 明显改善 |
| 分支分工 | N/M 相对误差维持或改善, 且 N/M 的置零代价不再接近 0 |
| 阶段平衡 | L 的置零代价不再以 15 dB 以上的量级压倒其它两段 |
| 鲁棒性 | 加噪 σ=0.05 不低于 18.3 (SGRFv8 水平), 不出现插值版那种 −11 dB 的崩塌 |
| 效率 | 参数量与延迟在 SGRFv8 的 1.1 倍以内 |

置零代价只是诊断信号, 不能为了提高它就刻意削弱完整模型的重建质量。

## 四、SGRFv9 的验证计划 (训练结束后执行)

这一轮的目标是**验证结构是否有效**, 不是继续叠加模块。因此先固定判据, 再看结果,
避免事后调整标准。

### 4.1 三个需要重点验证的风险

**(1) 门控正则可能限制了空间选择。** 正则是 `0.05·E[(G−0.5)²]`, 它把门拉向 0.5,
有助于避免饱和, 但也可能让门在全图趋近常数 —— 那样"均值健康"并不代表门做了任何
空间选择。因此判据里不能只看门控均值, 必须同时看标准差、分位数、饱和率与变异系数。

**(2) 软限幅可能压制该段真正需要的修正。** `Δ' = δ·tanh(Δ/δ)` (δ = 0.5) 能控制异常
增量, 但较大的修正会进入梯度较弱的区间。因此必须记录限幅前后的 RMS、最大绝对值,
以及进入明显压缩区间的元素比例。只报限幅后的数值无法判断限幅是不是瓶颈。

实测 (未训练模型, 单次前向):

| 段 | RMS 限幅前 | RMS 限幅后 | 最大绝对值 | 压缩比例 |
|---|---:|---:|---:|---:|
| N | 0.0888 | 0.0872 | 0.289 | 0.13% |
| L | 0.3382 | 0.2217 | 1.000 | **31.0%** |
| M | 0.2006 | 0.1898 | 0.425 | 1.0% |

这个结果与预期相反: 被限幅压制的主要是 L 段 (31% 的元素进入压缩区), 而不是 M 段。
原因还是目标量级 —— L 的输出本身就是完整图像量级。若要放宽限幅, 应该针对 L 段,
而不是放宽全局 δ。这一点留到训练后的实测再判断, 本轮不改。

**(3) 目标幅度差不能直接推出"应当均衡输出幅度"。** L/N/M 的目标平均绝对值约
0.500 / 0.197 / 0.054, 但它们的语义不同: L 输出完整图像, N/M 输出零均值频带。
真正要验证的是"每段是否学到了符合自身目标的修正, 以及这种修正是否改善最终重建",
不是三段输出幅度是否相等。

### 4.2 四项判据

| 检查项 | 核心问题 | 通过标准 |
|---|---|---|
| 最终图像质量 | PSNR 是否超过 SGRFv8 的 24.89 dB; LPIPS 是否从 0.427 向并行版的 0.393 改善 | PSNR ≥ 24.89, LPIPS < 0.427 |
| 门控健康度 | 是否饱和; 空间门控是否有实际变化 | 饱和率 < 20%, 变异系数 > 0.05 |
| 阶段有效性 | N/M 的目标拟合改善是否转化成最终重建收益 | N 或 M 的反事实 ΔPSNR 优于 SGRFv8 的 −0.437 / −0.133 |
| 鲁棒性与效率 | 加噪是否稳定; 参数量与延迟是否合理 | 加噪 σ=0.05 ≥ 18.26; 参数 < 1.36M, 延迟 < 55 ms |

比较必须用相同的验证协议与相同的"最佳检查点"选择方式。SGRFv8 的 24.89 是 30 轮结果;
若 v9 只在最后一轮达到相近数值而中途明显更差, 训练效率也要计入判断。

### 4.3 阶段反事实测试

训练结束后, 在不重新训练的前提下分别关闭 N / L / M 一段, 记录 PSNR / SSIM / LPIPS。

需要明确它的边界: 关闭某段后的性能下降只反映**当前已训练模型对该段的依赖程度**,
不能直接证明该段学到了正确的物理退化。串接结构里关闭前序阶段还会改变后续阶段的输入
分布, 因此这是诊断, 不是因果证明。

在 SGRFv8 的 30 轮 checkpoint 上已经跑过一次作为口径验证 (2 段序列):

| 条件 | PSNR | SSIM | LPIPS | ΔPSNR |
|---|---:|---:|---:|---:|
| 完整 | 26.652 | 0.8679 | 0.3410 | — |
| 关闭 N | 25.439 | 0.8608 | 0.3635 | −1.213 |
| 关闭 L | 5.395 | 0.0317 | 0.5966 | −21.257 |
| 关闭 M | 26.183 | 0.8655 | 0.3403 | −0.469 |

注意关闭 L 后输出几乎完全崩坏, 这与 L 段承担完整图像量级的重建一致。

### 4.4 本轮明确不做的事

- 不因为探针里 L 门控饱和就加大门控正则权重;
- 不因为 M 贡献偏小就手动增大 M 的缩放系数;
- 不在训练中途增加 LPIPS 损失或调整阶段顺序;
- 不因为训练 loss 下降就判定分阶段融合成功。

如果 v9 改善了 LPIPS、阶段贡献与鲁棒性, 即使 PSNR 只小幅提升也有研究价值;
如果它只是把 SGRFv8 的阶段失衡换成了门控正则与限幅带来的新约束, 下一步应当针对
融合的参数化方式重新设计, 而不是继续叠加补丁。

### 4.5 诊断工具

`scripts/diag_sgrf_meta.py` 一次输出三类结果: 门控健康度 (均值/标准差/变异系数/
分位数/饱和率)、阶段幅度、阶段反事实 (PSNR/SSIM/LPIPS 与 ΔPSNR)。限幅统计由模型
的 `stage_stats` 提供。训练结束后由链式脚本自动执行。

## 五、SGRFv9 的 30 轮结果 (2026-10-23)

### 5.1 验证曲线

| 轮次 | PSNR | SSIM | LPIPS | 训练 loss |
|:--:|:--:|:--:|:--:|:--:|
| 5 | 21.04 | 0.8027 | 0.4367 | — |
| 10 | 20.76 | 0.7825 | 0.4472 | — |
| 15 | 21.47 | 0.8065 | 0.4203 | — |
| 20 | 22.07 | 0.8111 | 0.4201 | — |
| 25 | 22.19 | 0.8181 | 0.4178 | 0.5223 |
| 30 | **22.26** | 0.8144 | 0.4170 | 0.5192 |

第 10 轮比第 5 轮还低, 之后缓慢回升, 第 25 到 30 轮只涨 0.07 dB, 已经平台化。
训练损失停在 0.519, 比 SGRFv8 的 0.458 高出 0.06 —— 这不是没收敛, 是收敛到了一个更差的解。

### 5.2 按预设判据逐项对照

| 检查项 | 通过标准 | 实测 | 结论 |
|---|---|---|---|
| 图像质量 PSNR | ≥ 24.89 | **22.26** (−2.63) | **不通过** |
| 图像质量 LPIPS | < 0.427 | 0.417 | 通过 (幅度很小) |
| 门控空间选择 | 变异系数 > 0.05 | N 0.117 / L 0.160 / M 0.182 | 通过 |
| 门控不饱和 | 饱和率 < 20% | N 0.1% / **L 31.2%** / M 4.1% | L 不通过 |
| 阶段有效性 | N 或 M 反事实优于 v8 | N −0.300 (v8 −0.437), M −0.260 (v8 −0.133) | N 退步, M 略好 |
| 鲁棒性 | 加噪 σ=0.05 ≥ 18.26 | 18.29 | 通过 (持平) |
| 效率 | 参数 < 1.36M, 延迟 < 55 ms | 1.235M, 49.2 ms | 通过 |

主判据 PSNR 差 2.63 dB, 其余项的通过不足以抵消。

### 5.3 失败原因: 限幅与幅度上界联合卡死了 L 段

决定性证据是**三段幅度全部饱和到上界 1.5** (N 1.496, L 1.500, M 1.500)。这是模型在
与自己的约束对抗的信号: 它需要更大的输出幅度, 但被 `s_k ≤ 1.5` 卡住了。

为什么需要更大幅度: 软限幅 `δ·tanh(Δ/δ)` 在 δ = 0.5 时, 即便 Δ = 1.0, 输出也只有
0.5·tanh(2) ≈ 0.48。L 段的输出是完整图像, 亮区需要到 1.0, 而经过限幅、门控 (均值 0.79)、
幅度 (上界 1.5) 之后, 单段最大可能贡献约 1.5 × 0.79 × 0.48 ≈ 0.57。亮区重建从结构上
就做不到, 这直接对应 2.6 dB 的损失。

这个风险在训练前的探针里已经暴露过 (第四节 4.1 第 (2) 条: 未训练时 L 段 31% 的元素
进入压缩区, N 与 M 分别只有 0.13% 和 1.0%)。当时按"本轮不改"的原则没有调整, 实验如期
执行, 结果证实了那个预警: **限幅压制的是 L 段, 而且这个压制决定了整个实验的上限。**

### 5.4 门控与阶段贡献

门控做了空间选择 (三段变异系数都在 0.12 到 0.18), 这一点 v9 的机制是成立的。但 L 段的门
均值 0.79、饱和率 31%, 说明网络在 L 段想把门全开, 也是在对抗约束。

反事实结果与 SGRFv8 相比: N 段从 −0.437 退到 −0.300, M 段从 −0.133 升到 −0.260。
M 的改善方向正确, 但只有 0.13 dB, 且是在整体 PSNR 低 2.6 dB 的前提下得到的, 不能算
"分工改善转化为重建收益"。L 段仍是绝对主导 (−14.68 dB)。

### 5.5 结论

SGRFv9 不是把 SGRFv8 的阶段失衡解决了, 而是把它换成了限幅与幅度上界带来的新约束,
并且新约束的代价 (−2.63 dB) 远大于旧问题。按第四节 4.4 的预设原则, 这种情况下
**下一步不应该继续叠加补丁 (放宽 δ、提高幅度上界、调门控正则), 而应当针对融合的
参数化方式重新设计。**

有价值的保留项: 空间门控确实在做选择, 门控正则有效防止了 N、M 段饱和, 反事实诊断工具
与限幅统计可以直接复用。需要废弃的: 对三段使用同一个 δ 的软限幅, 以及把幅度上界设在
与目标量级无关的常数上。

|---|---:|---:|---:|---:|---:|
| 验证 PSNR | 24.36 (ep10) | 24.65 (ep15) | 24.75 (ep15) | 24.89 (ep30) | 22.26 (ep30) |
| SSIM | 0.8086 | 0.8167 | 0.8152 | 0.8097 | 0.8144 |
| LPIPS | 0.4101 | 0.3937 | 0.3933 | 0.4270 | 0.4170 |
| 参数量 | 1.175M | 1.236M | 0.956M | 1.220M | 1.235M |
| 相对误差 N / L / M | 0.724/0.142/0.710 | 0.659/0.126/0.667 | 0.697/0.145/0.693 | 0.647/0.117/0.561 | 0.722/0.126/0.662 |

| 融合模式 | 并行加性 | 并行加性 | 并行加性 | 串接加性 | 串接门控 |

三行结论:

1. **SGRFv8 (串接) 的 PSNR 与 M 路分工最好**, 但 LPIPS 最差 (0.427), 且代价是收敛慢。
2. **并行版 (a_lite) 的 LPIPS 与分支置零代价最好**, 是四项指标里最均衡的。
3. **SGRFv9 在两个方向上都没有站住**: PSNR 差 2.63 dB 来自限幅与幅度上界对 L 段的
   结构性压制; 分支指标反而比 SGRFv8 退步。

由此可以下一个更基础的结论: 分阶段串接本身是有价值的 (M 的相对误差 0.561 是它做到的),
但"SGRFv8 的问题"并不在它用了串接, 而在它用一个全局标量决定整段贡献, 又缺少让
某段被合理使用时不被压制的机制。SGRFv9 试图同时改这两点, 结果两点都没改对。

## 七、SGRFv10 设计: 阶段差异化约束的分段融合

> 状态: 已实施, 30 轮训练中 (2026-10-22 启动)。
> 实现落在 `models/golf_v7r/sgrf_v9.py` 的 `fusion_mode="sgrf_v9"` 路径上
> (逐段限幅与幅度范围), 新增 `delta_bound` / `amp_range` 两个按段设置的字典;
> 旧 v9 的统一常数 `delta_bound=0.5`、幅度范围 ±0.5 不再使用。本节的所有参数都取自四组实验的实测数据, 不再引入
> 与已有证据无关的新超参。

### 7.1 从 v9 的失败里提取的三条事实

这三条是实测数据, 不是推测:

1. 三段的目标量级相差近一个数量级: 用真实数据测得 |L| 0.500, |N| 0.197, |M| 0.054。
   其中 L 的输出是完整图像, N 与 M 是零均值频带。
2. SGRFv9 的三段幅度全部饱和到上界 1.5 (N 1.496, L 1.500, M 1.500), 说明模型被卡在上界;
   且 L 段在限幅压缩区的元素占比是 31%, N 与 M 分别为 0.13% 和 1.0%。
3. 门控确实在做空间选择 (变异系数 0.12 至 0.18), 门控正则有效防止了 N/M 饱和。
   这两条机制本身成立, 需要保留。

由此直接推出: 不能对三段使用同一个限幅常数, 也不能把幅度上界设成与目标量级无关的常数。

### 7.2 设计原则

分三段各自使用与其目标量级匹配的限幅与幅度范围, 三段各自独立。顺序仍为 N → L → M,
与 v8/v9 相同, 因为它对应 TSDR 的物理依赖 (曝光在噪声之前、运动最后), 且 v8 的 M 路
分工改善是在这个顺序下得到的。

```
X_0 = 0
Δ_N = lift_N(Y_N(F_N))
G_N = σ(gate_N([X_0, F_N]))
X_N = X_0 + s_N · G_N ⊙ b_N(Δ_N)

F_L' = F_L + proj_L(X_N)
Δ_L = Y_L(F_L', X_t)                       (复用 Retinex 重建)
G_L = σ(gate_L([X_N, F_L']))
X_L = X_N + s_L · G_L ⊙ Δ_L                 (L 段不再限幅)

F_M' = F_M + proj_M(X_L)
Δ_M = lift_M(Y_M(F_M', F2))
G_M = σ(gate_M([X_L, F_M']))
X_M = X_L + s_M · G_M ⊙ b_M(Δ_M)

O_t = clamp(X_M, 0, 1)
```

与 v9 唯一的结构差别是每段的限幅与幅度各自独立, 且 L 段完全去掉限幅。

### 7.3 三段各自的设置

限幅 `b_k(Δ) = δ_k·tanh(Δ/δ_k)`, 取值为各段目标平均绝对值的 3 倍, 留足头部空间;
幅度 `s_k = 1 + (r_k/2)·tanh(a_k) ∈ [1 − r_k/2, 1 + r_k/2]`, 初值 1。

| 段 | 目标量级 (实测) | 限幅 δ_k | 幅度范围 [1−r/2, 1+r/2] | 理由 |
|---|---:|---:|---|---|
| N | 0.197 | 0.60 | [0.75, 1.25] (r=0.5) | 高频残差, 幅度小, 需要限幅防异常尖峰 |
| L | 0.500 | **不限幅** | [0.6, 1.4] (r=0.8) | 完整图像, Retinex 内部已有 clamp(0,1) |
| M | 0.054 | 0.16 | [0.75, 1.25] (r=0.5) | 幅度最小, 最容易被压制, 需要更窄的限幅与幅度范围 |

三处取值都不是新超参: δ 与 r 都来自第二节实测的目标量级, 不是随意挑选。

**L 段不限幅的依据**: 它的输出本来就有 `clamp(0, 1)` (见 `branch_l_simple.py` 的
`Y_L.clamp(0.0, 1.0)`), 在 v9 里再套一层 `tanh` 是重复的, 而且两层非线性的复合
才是把亮区压到 0.48 的直接原因。

**M 段限幅最窄的依据**: 它的目标只有 0.054, 是 N 的四分之一。SGRFv8 里它被阶段系数
压到 0.405 都没学动, 部分原因是它要对抗远大于自己的 L 段。给它一个窄一些的限幅与
幅度范围, 等于给它的梯度留出更明确的余地。

### 7.4 保留与删除

**保留**: 空间门控 `G_k`、门控正则 `w_gate_reg`、状态投影 `proj_L` / `proj_M`、
逐通道增量处理 `lift_N` / `lift_M`、N → L → M 的顺序、分支辅助监督与最终监督。

**删除**: 全局统一限幅 `delta_bound = 0.5`, 幅度上界 1.5, 以及对 L 段的限幅。

### 7.5 新增监控

诊断脚本与统计字段完全复用 (`diag_sgrf_meta.py`、门控健康度、限幅前后统计、反事实
测试), 额外加一个检查项: 三段各自的幅度是否在训练中触及边界。若某段幅度长期停在
`1 ± r_k/2` 的边界上, 说明范围仍然太窄, 该段被再次压制; 此时应调整该段的 r_k,
而不是放宽全局。

### 7.6 参数量与效率

与 v9 完全一致 (1.235M, 49.2 ms)。这一版不引入任何新模块, 只改变限幅与幅度的取值方式。

### 7.7 判据

与 v9 同一套, 阈值按四组实验的实测数字设定:

| 检查项 | 通过标准 |
|---|---|
| PSNR | ≥ 24.89 (SGRFv8 的 30 轮水平) |
| LPIPS | ≤ 0.417 (v9 的水平; 若低于 0.394 则优于并行版) |
| 门控健康度 | 三段饱和率 < 20%, 变异系数 > 0.05 |
| 阶段有效性 | M 的置零代价优于 v8 的 −0.133; N 的置零代价优于 v9 的 −0.300 |
| 鲁棒性 | 加噪 σ=0.05 ≥ 19.0 (并行版水平) |
| 效率 | 与 v9 一致 |

若 v10 在上述判据上仍不能全部通过, 需要回退到 v8 的串接加性形式, 并把"分阶段融合"
这一路线标记为"在当前监督目标与初始化下不优于并行加性", 而不是继续修改融合模块。

### 7.8 明确不做的事

- 不改三分支网络本身;
- 不加 LPIPS 损失;
- 不改阶段顺序 (N → L → M);
- 不放宽 M 段的幅度范围来"补偿"它的偏小 —— 它的目标本来就小, 范围应当随目标而定,
  不应人为撑大。

### 8.4 阶段与门控分析

阶段幅度收敛到 N 1.236 / L 1.317 / M 1.250, 均在各自范围内, 没有任何一段顶到边界。
这与 v9 的三段全饱和到 1.5 形成对照: 逐段约束生效了, 模型没有在与自己的上界对抗。

门控分布: L 段均值 0.734、N 段 0.538、M 段 0.502, 三段的变异系数都在 0.07 到 0.19,
说明门在空间上有选择, 没有退化为常数图。L 段饱和率 0.8%, 远低于 v9 的 31.2%。

反事实测试: 置零 M 段掉 0.923 dB, 是四组实验里最高的; N 段掉 0.491 dB, 接近 a_lite
的 −0.56 但好于 v9 的 −0.300。L 段仍是主导 (−17.35 dB), 这一点在四组里一致,
与"L 的目标是完整图像量级"这一事实相符, 不能单独作为结构缺陷判读。

### 8.5 分项归因

两项改进的贡献需要分开说, 因为它们同时进了这一个 run:

- **TemporalAggregator_G 的贡献**: 参数量不变, 但 PSNR 从 a_lite 的 24.65 提到 25.03,
  且 PSNR 在第 30 轮仍在上升。它的设计把邻帧的 F1/F2 特征从死计算变为被消费,
  使 F1_multi 的语义更接近"窗口均值与中心帧在同一镜头下的差值"。
- **SGRFv10 的贡献**: 限幅与幅度按目标量级分段后, M 路的置零代价从 v9 的 −0.260
  升到 −0.923, 阶段幅度不再顶到边界, 门控不再饱和。相对误差 N/M 为 0.667/0.567,
  M 与 v8 的 0.561 持平, 但贡献不再被压制。

由于两个变量同时动, 这次结果不能单独归因给某一项。若需要单独验证 G, 应再跑一组
`summary_type=g` + 并行加性融合的对照; 若需要单独验证 v10, 应再跑一组
`summary_type=lite` + v10 的对照。这两组目前都没有跑, 是否补跑由你决定。

### 8.6 遗留问题

加噪 σ=0.05 时 17.59 dB, 低于并行版 (19.80) 与 v8 (18.26), 高于插值版 (13.28)。
结合 M 段的反事实代价高, 一个合理的推测是: M 段在噪声条件下被噪声本身激活,
反而干扰了 L 段的曝光估计。这不是新的结构问题, 但如果下一步要继续改进鲁棒性,
这个方向值得看。
