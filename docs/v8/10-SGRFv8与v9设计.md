# SGRFv8 与 SGRFv9: 分阶段融合的两次实现

> 创建于 2026-10-22
> 代码: `models/golf_v7r/sgrf_v8.py`(基线, 不再修改)、`models/golf_v7r/sgrf_v9.py`
> 配置: `configs/v8_5/a_lite_sgrf_30ep.yaml`、`configs/v8_5/a_lite_sgrf9_30ep.yaml`
> 上一版轻量聚合见 `09-A方案轻量聚合设计.md`

## 一、为什么要做分阶段融合

在此之前的所有融合方式都是**并行**的: N、L、M 三路各自从同一份 F1 特征出发, 各自输出
一张图, 最后由逐像素权重加权求和。三路之间没有任何信息依赖。

TSDR 描述的三类退化有先后关系: 曝光决定了噪声的绝对强度, 噪声与运动都作用在同一个
曝光结果上。并行融合无法表达这种依赖。分阶段融合让每一段以上一段的结果为输入, 使
"先去噪、再定曝光、最后修运动"这个顺序成为结构的一部分。

## 二、SGRFv8: 加性串接

### 2.1 结构

```
X_0 = 0                       (三路频带目标之和等于 GT, 从零累加)
Δ_N = Y_N(F_N)                X_N = X_0 + s_N·Δ_N
F_L = F_L + proj_L(X_N)       X_L = X_N + s_L·Y_L(F_L, X_t)
F_M = F_M + proj_M(X_L)       X_M = X_L + s_M·Δ_M
O_t = clamp(X_M, 0, 1)
```

三条原则: 加性串接 (每段对输出的偏导恒为 `s_k`); 级间不 clamp (只有最终输出截断);
每段输入是上一段累加结果映回特征后加到本段 TCA 特征上。

`proj` 与 `s_k` 都是零初始化或初值 1, 因此训练起点与并行加性融合完全一致
(单测误差 0.0e+00)。

需要记录一个实现时的修正: 最初的版本以中心帧 `X_t` 作为累加起点, 这是错的 ——
三路目标之和已经是 GT, 再加上中心帧会把光照重复计入两次。

### 2.2 30 轮结果

| 轮次 | PSNR | SSIM | LPIPS | 训练 loss |
|:--:|:--:|:--:|:--:|:--:|
| 5 | 21.66 | 0.7022 | 0.5063 | 0.5792 |
| 10 | 23.15 | 0.7772 | 0.4969 | 0.5140 |
| 15 | 24.10 | 0.7836 | 0.4678 | 0.4880 |
| 20 | 24.71 | 0.8101 | 0.4392 | 0.4764 |
| 25 | 24.64 | 0.8016 | 0.4334 | 0.4605 |
| 30 | **24.89** | 0.8097 | 0.4270 | 0.4584 |

曲线形状回答了"学得慢还是学不动": 第 5 到 15 轮每 5 轮涨 1.0 至 1.5 dB, 第 15 到 30 轮
仍涨 0.79 dB, 训练损失从 0.579 单调降到 0.458, 没有平台化也没有回落。结论是**学得慢**。

同预算对比并行版 `a_lite`: 第 10 轮 23.15 对 24.12 (落后 0.97), 第 15 轮 24.10 对 24.65
(落后 0.55), 到第 30 轮反超 (24.89 对 24.65)。串接结构起步慢, 因为第一段没学好时
后面两段拿到的是错误的输入。

### 2.3 分支指标

| 项 | SGRFv8 (ep30) | a_lite (ep15) |
|---|---|---|
| 相对误差 N / L / M | 0.647 / 0.117 / **0.561** | 0.659 / 0.126 / 0.667 |
| 置零代价 N / L / M (dB) | −0.437 / −17.24 / −0.133 | −1.145 / −16.83 / −0.560 |
| 阶段系数 | 1.628 / 1.002 / 0.405 | — |
| 加噪 σ=0.05 | 18.26 | 19.80 |

M 路的相对误差是三组并行融合都没达到的水平 (0.561), 但它的置零代价只有 −0.133 dB,
是三组里最小的。阶段系数显示 N 段被放大到 1.628、M 段被压到 0.405, 与置零代价的
方向不一致 —— 这说明"学得好"与"用得上"在这个结构里脱节了。

## 三、SGRFv9: 门控渐进式恢复

### 3.1 针对 SGRFv8 的三个问题

1. **阶段依赖过强**: L 段置零代价 −17.2 dB, M 段 −0.13 dB, 最终图像几乎完全由 L 决定;
2. **串接误差累积**: 后一段直接接收前一段预测的图像, 没有任何机制抑制误差传播;
3. **贡献机制单一**: 一个全局标量独自决定整段贡献, M 段被压到 0.405 后就没有翻盘机会。

### 3.2 结构

每段改为"读取当前状态 + 预测针对当前状态的修正量 + 空间自适应门控":

```
X_0 = 0
Δ_N = lift_N(Y_N(F_N))                     G_N = σ(gate_N([X_0, F_N]))
X_N = X_0 + s_N · G_N ⊙ b(Δ_N)

F_L' = F_L + proj_L(X_N)
Δ_L = Y_L(F_L', X_t)                       G_L = σ(gate_L([X_N, F_L']))
X_L = X_N + s_L · G_L ⊙ b(Δ_L)

F_M' = F_M + proj_M(X_L)
Δ_M = lift_M(Y_M(F_M', F2))                G_M = σ(gate_M([X_L, F_M']))
X_M = X_L + s_M · G_M ⊙ b(Δ_M)

O_t = clamp(X_M, 0, 1)
```

其中 `b(Δ) = δ·tanh(Δ/δ)` 是软限幅 (δ = 0.5), 在 `|Δ| << δ` 时近似恒等。

### 3.3 五个设计决定

**门控初值 0.5, 不饱和。** 门是两层卷积, 末层权重与偏置均零初始化, 因此初始
`σ(0) = 0.5` —— 每段初始贡献一半, 各处一致。若用大偏置 (如 2.0) 会接近全开而失去
门控意义, 用负偏置会让早期阶段被压制, 正是 v8 的病灶。

**阶段幅度有界。** `s_k = 1 + 0.5·tanh(a_k) ∈ [0.5, 1.5]`, 初值 1。它只调整体幅度,
不承担逐位置的选择职责。这样既不会出现 0.405 那种压制, 也不强制三段等权。

**增量软限幅。** 这一条是冒烟测试暴露问题后加的。三个分支的初始化并不一致: N 与 L
内部有零初始化或 clamp 约束, M 的 `to_rgb` 是普通卷积, 输出幅度不受控。实测加限幅之前,
6 步内 M 段增量从 0.024 涨到 0.431, 而 L 段从 0.097 收缩到 0.017 —— 失衡只是换了个方向。

**阶段专属形式。** N 与 M 的增量各经一次逐通道 3×3 卷积 (恒等初始化), 强调局部结构;
L 直接复用分支自己的 Retinex 重建 (曲线 + 增益), 不额外堆叠通用卷积头。三个分支网络
本身完全不变, 它们各自的归纳偏置 (N 的通道注意力、L 的 Retinex、M 的运动精化) 保留。
没有引入光流, 没有 Conv+PixelShuffle。

**门控正则。** 单测与探针发现: 门在 80 步内饱和到 0.98 以上, 饱和后 sigmoid 导数趋零,
该段就永久失去调节能力。因此在损失里加入 `w_gate_reg · mean((G − 0.5)²)`, 默认权重 0.05,
把门保持在可调区间。这是 SGRFv9 的专用项, 其余融合模式自动忽略。

### 3.4 损失

分支辅助监督与最终重建监督完全不变。新增的只有门控正则一项。没有引入 LPIPS 损失:
现有损失里只有 `w_ssim` 开关, 没有感知项实现; 按"先修复评价与训练接口再引入"的原则,
本轮不加, 以免同时改动两个变量导致无法归因。

### 3.5 参数与计算量

| 项 | SGRFv8 | SGRFv9 |
|---|---:|---:|
| 融合模块 | 195 | 15.57K |
| 全模型 | 1.220M | 1.235M |
| FLOPs (推理) | 95.67 G | 待测 |

新增的 15.4K 来自三个门控网络 (每个约 4.6K)、两个状态投影 (各 96)、两个逐通道卷积
(各 27)。量级可以忽略。

### 3.6 已经发现的结构性事实

用真实损失跑 120 步探针, 测到三个分支目标的幅度本身相差近 10 倍:

| 分支 | 目标名 | 目标平均绝对值 | 同一步的输出幅度 |
|---|---|---:|---:|
| N | noise_target | 0.197 | 0.099 |
| L | illum_target | 0.500 | 0.511 |
| M | motion_target | 0.054 | 0.006 |

L 的目标本身就带有完整的低频能量 (GT 的低频分量), 另外两路是零均值频带, 幅度小一个量级。
因此 L 段主导有其来源, 不是门控的错, 也不是阶段系数选错了。这一点在评估 SGRFv9 时
必须分开看: 如果 L 仍占主导, 需要判断是因为它的目标量级本来就大 (合理), 还是因为
另外两段没有发挥作用 (问题)。

### 3.7 实验安排

| 项 | 值 |
|---|---|
| 配置 | `configs/v8_5/a_lite_sgrf9_30ep.yaml` |

| 与 SGRFv8 的差异 | `fusion_mode: sgrf → sgrf_v9`, 损失增加 `w_gate_reg: 0.05` |
| 其余 | 数据划分、优化器、学习率、seed 42、验证流程、分支目标全部相同 |

### 3.8 判据

不以 PSNR 的零点几 dB 提升作为成功标准。同时检查:

| 维度 | 希望看到 |
|---|---|
| 重建质量 | PSNR 保持竞争力 (不低于 24.7), LPIPS 相对 SGRFv8 的 0.427 明显改善 |
| 分支分工 | N/M 相对误差维持或改善, 且 N/M 的置零代价不再接近 0 |
| 阶段平衡 | L 的置零代价不再以 15 dB 以上的量级压倒其它两段 |
| 鲁棒性 | 加噪 σ=0.05 不低于 18.3 (SGRFv8 水平), 不出现插值版那种 −11 dB 的崩塌 |
| 效率 | 参数量与延迟在 SGRFv8 的 1.1 倍以内 |

置零代价只是诊断信号, 不能为了提高它就刻意削弱完整模型的重建质量。

## 四、SGRFv9 的验证计划 (训练结束后执行)

这一轮的目标是**验证结构是否有效**, 不是继续叠加模块。因此先固定判据, 再看结果,
避免事后调整标准。

### 4.1 三个需要重点验证的风险

**(1) 门控正则可能限制了空间选择。** 正则是 `0.05·E[(G−0.5)²]`, 它把门拉向 0.5,
有助于避免饱和, 但也可能让门在全图趋近常数 —— 那样"均值健康"并不代表门做了任何
空间选择。因此判据里不能只看门控均值, 必须同时看标准差、分位数、饱和率与变异系数。

**(2) 软限幅可能压制该段真正需要的修正。** `Δ' = δ·tanh(Δ/δ)` (δ = 0.5) 能控制异常
增量, 但较大的修正会进入梯度较弱的区间。因此必须记录限幅前后的 RMS、最大绝对值,
以及进入明显压缩区间的元素比例。只报限幅后的数值无法判断限幅是不是瓶颈。

实测 (未训练模型, 单次前向):

| 段 | RMS 限幅前 | RMS 限幅后 | 最大绝对值 | 压缩比例 |
|---|---:|---:|---:|---:|
| N | 0.0888 | 0.0872 | 0.289 | 0.13% |
| L | 0.3382 | 0.2217 | 1.000 | **31.0%** |
| M | 0.2006 | 0.1898 | 0.425 | 1.0% |

这个结果与预期相反: 被限幅压制的主要是 L 段 (31% 的元素进入压缩区), 而不是 M 段。
原因还是目标量级 —— L 的输出本身就是完整图像量级。若要放宽限幅, 应该针对 L 段,
而不是放宽全局 δ。这一点留到训练后的实测再判断, 本轮不改。

**(3) 目标幅度差不能直接推出"应当均衡输出幅度"。** L/N/M 的目标平均绝对值约
0.500 / 0.197 / 0.054, 但它们的语义不同: L 输出完整图像, N/M 输出零均值频带。
真正要验证的是"每段是否学到了符合自身目标的修正, 以及这种修正是否改善最终重建",
不是三段输出幅度是否相等。

### 4.2 四项判据

| 检查项 | 核心问题 | 通过标准 |
|---|---|---|
| 最终图像质量 | PSNR 是否超过 SGRFv8 的 24.89 dB; LPIPS 是否从 0.427 向并行版的 0.393 改善 | PSNR ≥ 24.89, LPIPS < 0.427 |
| 门控健康度 | 是否饱和; 空间门控是否有实际变化 | 饱和率 < 20%, 变异系数 > 0.05 |
| 阶段有效性 | N/M 的目标拟合改善是否转化成最终重建收益 | N 或 M 的反事实 ΔPSNR 优于 SGRFv8 的 −0.437 / −0.133 |
| 鲁棒性与效率 | 加噪是否稳定; 参数量与延迟是否合理 | 加噪 σ=0.05 ≥ 18.26; 参数 < 1.36M, 延迟 < 55 ms |

比较必须用相同的验证协议与相同的"最佳检查点"选择方式。SGRFv8 的 24.89 是 30 轮结果;
若 v9 只在最后一轮达到相近数值而中途明显更差, 训练效率也要计入判断。

### 4.3 阶段反事实测试

训练结束后, 在不重新训练的前提下分别关闭 N / L / M 一段, 记录 PSNR / SSIM / LPIPS。

需要明确它的边界: 关闭某段后的性能下降只反映**当前已训练模型对该段的依赖程度**,
不能直接证明该段学到了正确的物理退化。串接结构里关闭前序阶段还会改变后续阶段的输入
分布, 因此这是诊断, 不是因果证明。

在 SGRFv8 的 30 轮 checkpoint 上已经跑过一次作为口径验证 (2 段序列):

| 条件 | PSNR | SSIM | LPIPS | ΔPSNR |
|---|---:|---:|---:|---:|
| 完整 | 26.652 | 0.8679 | 0.3410 | — |
| 关闭 N | 25.439 | 0.8608 | 0.3635 | −1.213 |
| 关闭 L | 5.395 | 0.0317 | 0.5966 | −21.257 |
| 关闭 M | 26.183 | 0.8655 | 0.3403 | −0.469 |

注意关闭 L 后输出几乎完全崩坏, 这与 L 段承担完整图像量级的重建一致。

### 4.4 本轮明确不做的事

- 不因为探针里 L 门控饱和就加大门控正则权重;
- 不因为 M 贡献偏小就手动增大 M 的缩放系数;
- 不在训练中途增加 LPIPS 损失或调整阶段顺序;
- 不因为训练 loss 下降就判定分阶段融合成功。

如果 v9 改善了 LPIPS、阶段贡献与鲁棒性, 即使 PSNR 只小幅提升也有研究价值;
如果它只是把 SGRFv8 的阶段失衡换成了门控正则与限幅带来的新约束, 下一步应当针对
融合的参数化方式重新设计, 而不是继续叠加补丁。

### 4.5 诊断工具

`scripts/diag_sgrf_meta.py` 一次输出三类结果: 门控健康度 (均值/标准差/变异系数/
分位数/饱和率)、阶段幅度、阶段反事实 (PSNR/SSIM/LPIPS 与 ΔPSNR)。限幅统计由模型
的 `stage_stats` 提供。训练结束后由链式脚本自动执行。
