# v8 M 支路重构设计: 单帧 M 支路 + 门控融合

> 日期: 2026-10-16
> 前置结论: `01-设计.md` §六·补 与 §六·补·续 (M 路低迷的归因)
> 参考实现: `reference_repos/PRE-Mamba/pointcept/models/PRE_Mamba/mssm.py` (双流 MSSM 门控)

## 一、为什么要重做 M 支路

### 1.1 走到了哪一步

前面几轮试图让 M 支路"参与进来"的办法都是**改监督目标** —— 给 M 分一块频带、
让 M 学对齐残差。实测都失败,原因一次次指向同一个地方: M 的输入来自跨帧变形对齐
(`FlowEstimator` + `DeformableAlign` + `ConfidenceEstimator`),而在 SDSD 这类数据上,
相邻帧的位移极小,光流估计没有可靠信号,对齐后的特征与中心帧几乎一样。
于是 M 支路拿到的输入本身就与别人高度重合,分什么目标都救不回来。

实测数据 (SDSD indoor GT, 相邻帧与隔整个窗口的平均绝对差):

| 序列 | 相邻帧差 | 隔半个窗口差 |
|------|:--:|:--:|
| pair1 | 4.06 | 32.43 |
| pair11 | 1.75 | 15.72 |
| pair15 | 6.22 | 49.26 |

相邻帧只差几个灰度级。**跨帧位移在这类数据上确实是"慢而小"的**,
一个专门的变形对齐支路没有足够的工作量。这与早先的判断一致:
SDSD 的"运动"更多是手持摄像机的整体缓慢漂移,不是需要光流补偿的局部剧烈运动。

### 1.2 结论

**问题不在 M 路的目标, 而在 M 路的输入构造方式。** 只要 M 靠跨帧对齐拿输入,
它在 SDSD 上就永远与 N、L 重合。所以这一版不再动目标, 而是**换掉 M 的输入来源**。

## 二、M 支路的新定位: 单帧

### 2.1 三条支路的输入分工

| 支路 | 输入 | 依据 |
|------|------|------|
| N (成像噪声) | **多帧** (全部 T 帧) | 噪声帧间独立, 时序聚合是唯一的去噪手段 |
| L (光照) | **多帧** (全部 T 帧) | 光照是帧间的慢变全局量, 必须跨帧才能估计趋势 |
| M (运动) | **仅中心帧** | 局部结构、边缘、运动模糊痕迹只存在于单帧之内 |

这条分工的依据是物理性质, 不是工程折中: 噪声与光照的本质都是"帧间关系",
必须跨帧; 而运动在单帧里表现为**局部结构的偏移与模糊**, 本身就带在中心帧里。

### 2.2 为什么这能同时解决"重合"与"塌缩"

- **不重合**: M 只吃单帧特征, 多帧聚合会把它的输入平均掉, 从数据流上就与 N、L 分开。
  这是结构层面的分离, 不依赖损失函数逼出差异。
- **不塌缩**: M 不再需要靠一个零均值小残差去争取存在感。它直接重建中心帧的纹理,
  目标就是中心帧 GT, 有明确的学习信号 (输出接近 GT 时误差下降), 不存在"输出零即下界"。

## 三、门控融合 (参考 PRE-Mamba 的双流 MSSM)

### 3.1 PRE-Mamba 的做法

PRE-Mamba 处理"多帧 (multi) + 单帧 (single)"两条流, 在 `MultiScaleStateSpaceModel.forward`
里用一行完成融合 (mssm.py 第 322 行):

```python
mgafeat = self.act(torch.mul(multi_conv1d_out_weight, single_feat) + multi_conv1d_out)
ssm_out = self.ssm(conv1d_out=mgafeat, ...)
out = ssm_out + local_feat     # local_feat 是不经 SSM 的局部残差通路
```

其中 `multi_conv1d_out_weight = self.multi_act(multi_conv1d_out)`, `multi_act = nn.Sigmoid()`。

翻译成直白的话: **多帧流算出一个逐通道的门 (0–1), 用它去调制单帧流的内容,
再与多帧流本身相加。** 多帧告诉网络"这里该保留多少单帧细节", 单帧提供"保留什么"。

### 3.2 对应到本模型

现模型的三路输出是 `Y_N`、`Y_L`、`Y_M` (各 [B,3,H,W]), 融合在 `V7RFusion`。
M 改成单帧后, N、L 是多帧流、M 是单帧流, 正好对上门控融合:

```
门     g = sigmoid( W_g · [Y_N, Y_L, X_center] )     ← 多帧 (N、L) + 中心帧输入算门
内容   Y_M                                            ← 单帧流提供的细粒度纹理
基线   Y_base = W_b · [Y_N, Y_L, X_center]            ← 多帧流本身
输出   O = refine( g ⊙ Y_M + Y_base )
```

- 门由**多帧流**算: 只有多帧能看到"帧间是否一致", 一致处该多留单帧细节 (欠曝光区),
  不一致处 (真运动、遮挡) 该少留。这正对应 PRE-Mamba 让多帧算门的动机。
- 内容由**单帧流**提供: 单帧的局部纹理没有被时序聚合抹平, 是 N、L 给不出的东西。
- 加性基线保留: 与现有 `additive` 融合的 `Σw_k·Y_k` 一致, 改动最小。

**门控融合相对当前加性融合的关键区别**: 现在 `w_M` 是一个逐像素的标量权重,
乘在 `Y_M` 上; 新方案里门 `g` 是逐通道的, 且**以 N、L 的输出去算**, 二者产生交互 ——
M 的输出不再被单独加权, 而是由另外两路"决定要不要用"。这让 M 的贡献取决于 N、L 的状态,
而不是一个可被压到 0 的独立权重。

### 3.3 与 v7.5 定稿的关系

v7.5 定稿的是"频带划分目标 + 加性融合", 那是**监督层面**的结论。
本节改的是 M 的**输入与融合算子**, 属 v8 的结构整理范围。
为避免同时改多个变量, 实施时保留一个开关: `fusion_mode="gated"` 与旧模式并存,
可与 `additive` 直接对照。

## 四、三源解耦部分的重新设计

### 4.1 现状问题

现在三源解耦在 `TripleQueryTCA` 里完成: 三路 Query 都从同一个 `feat_spatial` 生成,
共享同一个 `kv_shared`, 只在最后的 LayerScale 残差与输出归一化上分开。
这决定了三路**输入完全相同**, 只能靠 Query 权重与注意力头的参数差异分化 ——
在共享目标时这就是"三路同质化的正确解", 在差异化目标时又容易被主损失拉回。

### 4.2 新设计: 按输入来源分流

把"统计先验 KV"按支路拆分, 让三路从源头拿到不同的东西:

| 支路 | KV 来源 | 说明 |
|------|---------|------|
| N | `ctx_mean` (帧间均值) | 帧间平均是对 i.i.d. 噪声的最优估计, 与去噪任务直接对应 |
| L | `ctx_smooth` (低频平滑) | 光照的慢变趋势, 与光照校正对应 |
| M | `feat_center` (中心帧特征) | 单帧特征, 不经任何时序聚合 |

这样三路的 attention 输入 (Q 与 KV 的组合) 从第一步就不同, 分工发生在**数据流**上,
而不是靠损失函数参数化地逼出来。逐支路的 KV 投影仍保留一组共享的可学习参数,
只是送入的内容不同, 以便对照"输入不同"与"参数不同"哪个更起作用。

### 4.3 MatrixRWKV 门控的去向

现在的 `rwkv_inject` 用 MatrixRWKV 的帧级上下文给三路 KV 做逐通道门控 (方案 B, 已实测有效:
gate 从 0 长到 3–9)。M 支路改单帧后仍需要这个门控, 但 M 的门控应改由**中心帧**的
帧级上下文给出 (而不是整个窗口), 否则又引入跨帧信息。这是实施时的一处细节。

## 五、最小实验验证方案 (排在 B1 之后)

原则与 v8 一致: 每个 run 单变量, 5 epoch, 用机制判据而不是 PSNR。

### 5.1 三个 run

| 编号 | 变量 | 对照 | 目的 |
|:--:|------|------|------|
| M1 | M 支路改为**仅中心帧**输入 (去掉 flow/deform/conf), 融合仍用 `additive` | Mfix (M 跨帧对齐) | 单独验证"单帧输入"是否让 M 活起来 |
| M2 | 在 M1 基础上, 融合改 `gated` (PRE-Mamba 式门控) | M1 | 单独验证门控融合的边际作用 |
| M3 | 在 M2 基础上, 三源 KV 按 §4.2 分流 | M2 | 单独验证解耦部分的重设计 |

三个 run 串行, 单卡不并发。M1 是枢纽: 若 M1 的 M 路 bstd 与空间方差仍上不去,
说明问题不在输入构造, 需要回到 `01-设计.md` §六·补 重判。

### 5.2 判据

| # | 判据 | 达标线 |
|:--:|------|--------|
| 1 | M 路输出的空间方差 | 明显高于常数图水平 (1e-11), 与 N 路同量级 |
| 2 | 三路与各自目标的误差 | 随训练下降 |
| 3 | 消融去掉 M 路 | 有明显代价 (加性口径: 直接置零, 不归一化) |
| 4 | 三路输出余弦 | 显著低于 0.99 (辅助判据, 单独看会被常数图误导) |

**判据 1 是主判据** —— 前几轮的教训是"输出余弦低"与"消融掉指标"都能被常数图伪造,
只有空间方差能直接区分"这一路在输出内容"还是"这一路在输出常数"。

### 5.3 若 M 支路仍无法生效

按用户提出的备选判断: 若 M1–M3 全部失败, 则**在 SDSD 数据集上可能确实不存在
可供 M 支路发挥的有效运动成分**。届时应在论文中据实说明:
三源解耦在 SDSD 上退化为两源 (光照 + 噪声), M 支路为保持理论完整性而保留但不参与,
并在有真实动态运动的数据集 (如 SDSD 之外的夜间行车/手持剧烈晃动数据) 上验证 M 支路。
这条结论需要实验证据支撑, 不能仅凭本轮推断下结论。

### 实施细节与实测

- **M1**: 单帧模式下 `BranchMSimple` 参数量 804.4K → 569.2K (去掉 flow/deform/conf);
  全模型 3.7510M → 3.5158M。单测确认"换掉 F2_seq 后输出不变", 即真的不读邻帧。
- **M2**: gated 融合的初始化经实测为 `g = sigmoid(2) ≈ 0.881` (门接近常开),
  `Y_base = Y_N + Y_L` (基线是两路直通), 因此初始输出 `≈ Y_N + Y_L + 0.88·Y_M`,
  与加性融合起点同量级, 不丢多帧信息。全模型 3.5150M。
  单测确认"门只由多帧流决定, 改变 Y_M 不改变门值"。
- **M3**: KV 分流后三个专属投影 (kv_proj_N/L/M), 全模型 3.5653M。
  单测确认分流前后三路 KV 的关系 (关闭时两两相同, 开启时两两不同)。

### 关于开关默认值

三个开关默认全部关闭 (`branch_m_single_frame=False`, `fusion_mode` 默认 `softmax`,
`kv_split=False`), 因此现有配置与历史 checkpoint 的行为不受影响。
M1/M2/M3 三份配置分别显式打开对应的开关。

M1 只需第一项 (改 M 输入), 融合保持 `additive`; 这样 M1 与 Mfix 的唯一差别
就是"M 的输入来源", 可以干净归因。M2、M3 依次叠加。
