# v8.7-nl: 纯 L1 + MS-SSIM 损失的对照实验 — 结果

> 创建于 2026-10-30
> 基础: v8.7 结构 (三分支改动) 不变, 只改损失
> 配置: `configs/v8_5/v8_7_nl_30ep.yaml`
> 输出: `outputs/v8_7_nl_30ep`
> 目的: 验证去掉全部分支监督后, 模型能否只靠最终重建损失学到三路分工

## 一、损失设置

| 项 | v8.7 | v8.7-nl |
|---|---|---|
| L1 (final vs GT) | 1.0 | 1.0 |
| MS-SSIM (final vs GT) | 关闭 | **1.0 (启用)** |
| 分支监督 N/L/M | 各 0.3 (频带目标) | **0.0 (关闭)** |
| 特征层正交 | 0.01 | 0.0 |
| 门控正则 | 0.05 | 0.0 |

实施备注: `pytorch_msssim` 包原本未安装, 损失代码静默回退纯 L1; 已安装并验证
MS-SSIM 在 256 裁剪尺寸下正常 (该包要求边长 > 160)。

## 二、30 轮结果

| 轮次 | PSNR | SSIM | LPIPS |
|:--:|:--:|:--:|:--:|
| 5 | 24.54 | 0.8339 | 0.3535 |
| 10 | 24.69 | 0.8345 | 0.3518 |
| 15 | 25.24 | 0.8419 | 0.3544 |
| 20 | **25.60** | **0.8414** | **0.3533** |
| 25 | 25.47 | 0.8393 | 0.3529 |
| 30 | 25.46 | 0.8394 | 0.3584 |

best 在 ep20。与 v8.7 (25.94/0.8381/0.3651) 相比: PSNR −0.34, SSIM +0.003,
**LPIPS −0.012 (0.3533, 历史最低)**。与 v8.6 (25.95/0.8370/0.3697) 相比:
PSNR −0.35, SSIM +0.004, LPIPS −0.016。

MS-SSIM 进入损失后, 验证 SSIM 与 LPIPS 明显改善, PSNR 略降 —— 符合感知损失
与像素损失此消彼长的已知规律。

## 三、鲁棒性 (相对 v8.7 的关键优势)

| 条件 | v8.7-nl | v8.7 | v8.6 |
|---|---:|---:|---:|
| 干净 | 25.98 | 25.90 | 25.55 |
| 加噪 σ=0.02 | **23.61** | 18.76 | 22.89 |
| 加噪 σ=0.05 | **20.32** | 13.89 | 19.95 |
| 压暗 ×0.5 | 14.92 | 15.17 | 14.86 |
| 模糊 9px | 25.33 | 25.33 | 24.91 |

加噪 σ=0.05 达到 **20.32 dB, 全部实验最高**, 修复了 v8.7 的 −6.06 dB 退化,
甚至超过 v8.6 的 19.95。压暗与模糊持平。

## 四、但分支分工完全崩溃

| 项 | v8.7-nl | v8.7 |
|---|---|---|
| 空间方差 N / L / M | 0.143 / 0.040 / **0.518** | 1.6e-3 / 4.3e-2 / 1.1e-3 |
| 单独 PSNR N / L / M | 10.78 / 16.30 / **−20.87** | 6.28 / 20.68 / 6.26 |
| 相对误差 N / M | 35.6 / **752.5** | 0.596 / 0.537 |
| 置零代价 N / L / M (dB) | −14.52 / −5.45 / −5.16 | −3.55 / −18.52 / −0.27 |

没有分支监督后, N 与 M 的输出完全脱离频带目标:

- M 的相对误差 752 (目标本身量级只有 0.054, 输出幅度失控到数百倍),
  单独 PSNR 为负 (−20.87 dB), 空间方差 0.518 比有监督时大约 500 倍;
- N 的相对误差 35.6, 同样失控;
- 只有 L 还保持形状 (相对误差 0.352), 因为 SGRF 串接里 L 是重建主体,
  最终损失的梯度天然流向它。

置零代价的分布也变了: 三段都非零 (−14.5/−5.5/−5.2), 表面上"三路都有贡献",
但这是三路输出幅度失控后的伪平衡, 不是分工。

## 五、结论

1. **感知质量与鲁棒性**: 纯 L1 + MS-SSIM 损失给出了历史最好的 LPIPS (0.3533)
   与最好的加噪鲁棒性 (20.32 dB)。MS-SSIM 作为损失项有效。
2. **但三分支分工不存在**: 去掉分支监督后, N 与 M 的输出与频带目标完全脱钩,
   "三源解耦"的设计目标失败。频带监督不是可选项, 是分工成立的前提。
3. **归属**: 本实验同时改了损失 (关监督、开 SSIM) 与 v8.7 的分支结构,
   但 v8.7 结构在 v8.7 主实验里分支指标正常, 因此分工崩溃归因于损失侧,
   证据充分。

## 六、后续建议

- 若追求感知指标: 在 v8.6/v8.7 的完整损失上**追加**低权重 MS-SSIM
  (如 w_ssim=0.1), 而不是替换。既保留分支监督, 又获得 SSIM 的感知收益。
- v8.7-nl 不作为候选模型; 其价值是证明了频带监督的必要性, 以及 MS-SSIM
  对感知与鲁棒性的正贡献。
