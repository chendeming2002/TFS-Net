## 一句话概括本版本

v7.5 已定稿三分支的**融合方式与监督目标**; v8 处理它上游的 **TCA 与编码器的 RWKV 实现**
—— 把混杂的来源整理成规范结构, 补上缺失的机制, 并厘清我们的创新点边界。

## 四条工作主线

| # | 内容 | 关键点 |
|:--:|------|--------|
| 1 | 整理简化 RWKV 基线 | 以 Vision-RWKV / Restore-RWKV 为主要参考; 用 Omni-Shift 替代当前的"无局部上下文" |
| 2 | 探索 RWKV 编码器 | 把 `FrameEncoder` 内部的 NAFBlock 换成 RWKV block |
| 3 | 引入 RWKV-7 与 Value Residual | 先期直接搬运原始实现, 不做小修小改 |
| 4 | 厘清"只有 Spatial Mix"的原因 | 结论: 历史沿革造成, 无技术理由, 应当补回 Channel Mix |

## 已核实的关键事实

以下都已直接从代码或本地参考实现确认, 不是推测:

| # | 事实 | 依据 |
|:--:|------|------|
| 1 | 当前衰减 `w` 是逐通道可学习常量 | `pure_rwkv_sace.py::BiWKV`, `w = -softplus(self.spatial_decay)` |
| 2 | **Vision-RWKV 的衰减也是可学习常量** | `reference_repos/Vision-RWKV/.../vrwkv.py:164,219` —— 两者一致, 不是缺口 |
| 3 | TCA 空间头无 Channel Mix | `RWKVSpatialHead.forward`, `proj_out` 后直接 `post_norm` |
| 4 | 当前**没有**循环次数参数 M | MatrixRWKV 用"堆 2 个 block"; Re-WKV 的 M 是同一模块串行循环, 两者不同 |
| 5 | Omni-Shift 本地已有完整实现 | `reference_repos/EvRWKV/egllie/models/Cross_Restore_RWKV.py:103` |
| 6 | 2D 四方向扫描来自 RSRWKV | 该论文不针对 low-level vision, 属需要重新评估的部分 |

第 2 条尤其重要: 我最初认为当前实现丢掉了"数据相关衰减"这一 RWKV 核心机制, 查证
Vision-RWKV 源码后发现它的 `spatial_decay` 同样是 `nn.Parameter`, 两者做法一致。
**这个纠正避免了按错误前提去改代码。**

- **R1 归因完成**: N 路塌缩来自 v8 空间头; M 路低迷来自 residual 目标本身。据此 A 组必须做单变量。
- **`outputs/v8_readout/v8_ablation.log` 里 phase1 的消融数字作废** (旧口径错误)。
- **WKV 实现已修正并加速**: 调研确认我们的双向组合方式 (两方向各自归一化再平均) 与官方
  Vision-RWKV 定义 (双向贡献进同一分子分母, 只除一次) 不一致; 已按官方定义重写并接入官方
  CUDA 算子, 前向从 109 ms 降到 25 ms。详见 `04-训练加速调研.md`。
- **M 支路重构设计完成并已实施** (`03-M支路重构设计.md`): 单帧 M + PRE-Mamba 式门控融合 + 三源 KV 分流。
- **合并实验已完成** (20.30 dB): 三路里 N、M 都是常数图, gated 融合的门降到 0.000,
  属于结构性自锁 (`∂O/∂Y_M = g`)。详见 `01-设计.md` 与 `02-实验计划.md`。
- **U-Net 式重构已实施并开始 15ep 实验** (`configs/v8/unet_refactor_15ep.yaml`):

  参数量 4.19M → 1.10M, 前向耗时不变。详见 `05-UNet重构设计.md`。
- 单测全绿 (含 U-Net 单帧旁路、帧权重分布、KV 分流、F1 直出分支、循环次数不改参数)。
- 分支健康度诊断脚本 `scripts/diag_branch_health.py` 已就位, 并在上一轮合并实验的
  checkpoint 上验证过口径: N=2.1e-09、M=7.9e-10 (常数图), L=1.4e-02 (有结构),
  与当时的归因一致。判据 3 的消融脚本也已支持新架构 (`arch: v8`)。

**U-Net 15ep 已完成**: 验证 PSNR 24.12 dB (第 10 轮 23.12, 第 5 轮 20.66), 尚未收敛。
三路都有结构, 但融合结果几乎全部来自 L 路 (置零 L 掉 15.9 dB, 置零 N 或 M 只掉约 0.3 dB);
N、M 与自身频带目标的相对误差约 0.7 至 0.9, 学得不充分。扰动测试显示 L 对压暗、M 对运动模糊
有方向性的响应, N 对噪声的专属性不成立。详见 `02-实验计划.md` 的 U-Net 最终结果一节。

**KV 全带 15ep 已完成** (`configs/v8/fullkv_15ep.yaml`): 取消 K/V 上的固定滤波,
N 的 K/V 取多帧聚合, L 与 M 取中心帧, L 的残差基同步改为中心帧。验证 PSNR 24.36 dB
(第 10 轮, 第 15 轮 24.03), LPIPS 0.4101, 是三次 15 轮实验里最好的一次;
N 路的置零代价从 +0.02 dB 变为 −0.62 dB, 加噪 σ=0.05 时 N 的变化量重新成为三路最大,
噪声专属性第一次成立。但 N、M 与自身目标的相对误差仍在 0.71 附近, 没有达到 0.5 的判据。
详见 `07-KV全带与输出侧频带约束设计.md` 第九节。

**Cross RWKV Gate 15ep 已完成**: 验证 PSNR 23.32 dB, 比 U-Net 基线低 0.80 dB。
第 10 到 15 轮只涨 0.13 dB (基线同期涨 1.00 dB), 训练损失在第 5 轮出现一次明显
上冲 (0.8238) 后才回落, 最终仍高于基线。三路空间方差与基线基本相同, 但 N、M 与
自身目标的相对误差从 0.73 / 0.71 升到 0.775 / 0.761, 置零它们对最终 PSNR 的影响
从 −0.3 dB 变成 +0.02 dB, 即已经完全不被融合采用。结论是新的 Q 机制本身可以正常工作,
但没有解决 N、M 不学的问题, 瓶颈不在查询机制。详见 `02-实验计划.md` 第七节的最终结果。
后续方向由用户决定, 尚未启动新的训练或消融。
