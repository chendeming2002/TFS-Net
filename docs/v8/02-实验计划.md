#### 扰动响应测试 (`scripts/diag_perturbation_response.py`, 最终权重, 10 段序列中心 256 裁剪)

三类退化只作用于输入, GT 与各路目标保持干净版本不变。"变化"是该路输出的平均绝对变化量除以该路
目标的平均绝对值 (与输入无关的尺度, 三路可比)。"相对误差"是该路输出与自身目标的平均绝对误差
除以目标平均绝对值, 1.0 等于输出全零, 越小说明学到的内容越多。"置零代价"是把该路置零 (不重新
归一化) 后最终 PSNR 的变化量。

| 条件 | 最终 PSNR | 变化 N / L / M | 相对误差 N / L / M | 置零代价 dB N / L / M |
|:--|:--:|:--:|:--:|:--:|
| 干净输入 | 23.42 | — | 0.73 / 0.16 / 0.71 | −0.26 / −15.9 / −0.33 |
| 压暗 ×0.5 | 14.96 | 0.25 / **0.36** / 0.23 | 0.79 / 0.41 / 0.76 | −0.08 / −7.5 / −0.12 |
| 压暗 ×0.25 | 11.04 | 0.43 / **0.63** / 0.41 | 0.88 / 0.65 / 0.85 | −0.01 / −3.7 / −0.04 |
| 加噪 σ=0.02 | 22.82 | 0.22 / 0.06 / **0.26** | 0.78 / 0.18 / 0.79 | −0.33 / −15.3 / −0.39 |
| 加噪 σ=0.05 | 20.10 | **0.62** / 0.18 / 0.45 | 1.02 / 0.25 / 0.88 | −0.50 / −12.6 / −0.24 |
| 运动模糊 5 像素 | 23.38 | 0.07 / 0.01 / **0.10** | 0.73 / 0.16 / 0.72 | −0.28 / −15.9 / −0.36 |
| 运动模糊 9 像素 | 23.23 | 0.14 / 0.02 / **0.17** | 0.74 / 0.16 / 0.73 | −0.29 / −15.7 / −0.39 |

判读:

1. 压暗: L 路的变化量最大, 与"L 管光照"的设计一致。
2. 运动模糊: M 路的变化量最大, N 路居中, L 路几乎不变。M 对运动有反应, 但幅度只比 N 略大。
3. 加噪: 强噪声下 N 路变化最大, 弱噪声下 M 路反而更大。N 对噪声的专属性不成立。
4. 融合结果几乎全部来自 L 路: 置零 L 掉 15.9 dB, 置零 N 或 M 只掉 0.3 dB 左右。
5. N、M 与自身目标的相对误差在 0.7 至 0.9 之间, 只比全零输出好一点; L 为 0.16, 学得充分。
6. 本次测试只有 10 段序列、一个中心裁剪位置, 没有统计区间。退化是合成的, 与真实低光差别
   仍在。上述数字应当读作方向性证据, 不能当作定论。

### 合并实验 (已完成) 的结论

| 项 | 数值 | 判读 |
|----|------|------|
| 验证 PSNR | 20.30 dB (epoch 10) | 低于 v7.5 定稿的 24.55, 但 WKV 定义已更换, 不可直接比 |
| 训练损失 | 0.288 → 0.854 (ep5), 之后 0.847 停滞 | 模型不再学习 |
| N 输出空间方差 | 2.1e-09 | **常数图** |
| M 输出空间方差 | 7.9e-10 | **常数图** |
| L 输出空间方差 | 1.4e-02 | 唯一在输出内容的分支 |
| 门 g 均值 | **0.000** | 门完全关闭 |

**门控融合存在结构性自锁**: `O = g·Y_M + Y_base`, 因此 `∂O/∂Y_M = g`。
门学到"不该用 M"后 g→0, M 路从此拿不到梯度, 再也学不动 —— 与本项目早期修掉的
softmax 融合塌缩是同一类问题。所以 U-Net 实验改用 additive 融合, 先验证聚合结构本身。

## 三、运行编排

每个正式 run 用 5 epoch (约 6.8 h), 判据沿用机制判据 (不与任何 run 比较 PSNR 数值):

| # | 判据 | 达标线 |
|:--:|------|--------|
| 1 | 三路与各自频带的误差 | 随训练下降 |
| 2 | 三路输出的**空间方差** | 明显高于常数图水平 (1e-11); 不能只看余弦 |
| 3 | 三路单独 PSNR | 都正常, 无常数图 |
| 4 | 消融: 去掉任一路 | 明显变差 (加性口径: **直接置零, 不归一化**) |

**⚠️ 判据 2 与判据 4 的口径已在本轮修正**, 原判据(用输出余弦低 + 旧的归一化消融)会给出错误结论:

- 判据 2 原为"三路输出余弦显著低于 0.99"。余弦低只说明"三路输出不像",
  常数图与正常图的余弦同样很低 —— 必须补看**空间方差**才能区分。
- 判据 4 原用"凸组合归一化"口径算消融代价, 对**加性融合**是错的: 它把剩余两路放大 1.8 倍,
  制造约 10 dB 的假衰减 (实测: 旧口径 -8.11 dB vs 正确口径 +0.08 dB)。

**⚠️ 前提: BranchM 的尺度缺陷必须先修。** 该修复已完成 (LayerNorm2d + LeakyReLU),
但实测表明它只改善了现象, 未让 M 路获得功能贡献; 真正的阻塞点是 M 路的目标设计 (见 §四)。

## 四、判读规则

**R1 是本轮的枢纽。** 它决定两个问题:

1. N 路塌成常数图, 是残差目标的锅还是 v8 空间头的锅?
   - 若 R1 的 N 路也塌 (空间方差降到 1e-11 量级) → 目标是主因, 空间头无罪, A 组按原计划合并实施;
   - 若 R1 的 N 路正常、只有 phase1 塌 → 空间头是主因, A 组必须拆成单变量先查 OmniShift 与 Channel Mix。

2. M 路为什么始终贡献低?
   - 无论 R1 结果如何, R1 的 M 列 (0.0003–0.003) 与 v7.5 定稿 (0.0011) 同量级,
     说明 **M 路低迷不是本轮引入的**, 而是残差目标与频带目标共同的性质: M 的目标都不含直流分量。
   - 若要真正救 M 路, 目标必须含有**其他两路无法提供的成分** (明显的直流分量或低频结构),
     不能是一块零均值高频残差。这属于下一次设计迭代, 不在本轮编排内。

**B1 是探索性的。** 编码器换 RWKV 属于结构统一, 收益不确定。判据放宽: 只要指标不明显变差
(落在 seed 方差内) 且参数量可控, 即可采纳。要与 NAFBlock 版比较, 必须各跑多个 seed —— 单 run 无法比。

**全部实验不与 v7.5 的定稿配置比较 PSNR** —— 本机 5 epoch 的 seed 间方差达 2.4–3.2 dB。

## 五、明确不做的事

## 七、Cross RWKV Gate 实验 (2026-10-18 启动)

设计见 `06-CrossRWKVGate-Q重构设计.md`。这是与 U-Net 基线之间的单变量对照:
除 `model.q_mode: cross_rwkv` 外, 配置 (`configs/v8/crossrwkv_gate_15ep.yaml`) 与
`unet_refactor_15ep.yaml` 逐项相同, 同一 seed。

改动内容一句话: 三路任务查询从 `sigmoid(q) * wkv` 的单门改为论文式 (2)–(4) 的
R/G 双查询。R 是带符号线性投影, 与 WKV 输出相乘后接逐头 LayerNorm; G 经 SiLU 门控。
R/G 的输入按支路分工: L 用多帧聚合特征, M 用中心帧特征, N 用 `F1_single − F1_multi`
(帧间不一致量, 物理上是噪声估计)。K/V 取各支路自己的频带: L 为多帧的大核低通,
M 为单帧高频残差, N 为单帧中高频 (单帧减去大核低通)。四个投影 (R、G、K、V) 的输入
各配一个 OmniShift, 作为论文 Q-Shift 的图像替代物。Channel Mix 按其式 (6)–(8) 重构。
参数量 1.100M → 1.175M (TCA 0.048M → 0.123M), 前向耗时 149 ms → 151 ms
(batch 1, 256×256)。

N 路的输入在第一次启动后按分支频带核对的结果作过一次修正: 最初 R/G 与 KV 都取自
多帧聚合的低通, 而 N 的目标是 0.5 中频 + 0.8 高频, 键值里几乎没有该频带的内容,
方向相反。首次启动只跑到第 600 步, 没有产生可用的验证结果, 修正后重新从头训练。

判据与 U-Net 实验完全相同, 直接对照:

| 判据 | U-Net 基线 (15ep) |
|------|------------------|
| 验证 PSNR | 24.12 dB |
| 三路空间方差 | N 1.1e-3, M 7.3e-4, L 4.8e-2 |
| 相对自身目标的误差 | N 0.73, M 0.71, L 0.16 |
| 置零某路的 PSNR 代价 | N/M 约 0.3 dB, L 15.9 dB |

训练完成后的步骤: 先跑 `scripts/diag_branch_health.py` 看三路方差与相对误差, 再跑
`scripts/diag_perturbation_response.py` 看压暗、加噪、运动模糊三类扰动下的响应,
两者都与上表逐项对比。只有 N、M 的相对误差下降、消融代价上升才算 Q 机制带来了
实质改进; 若 PSNR 持平而 N、M 仍然不学, 则瓶颈不在 Q。

判读:

1. R/G 双查询没有改善 N、M 两路。两路与自身目标的相对误差从 0.73 / 0.71 升到
   0.775 / 0.761, 置零它们对最终 PSNR 的影响从 −0.3 dB 变为 +0.02 dB, 即已经
   完全不被融合采用。
2. 训练损失在第 5 轮冲到 0.8238 (基线同期 0.6128), 随后才回落, 最终仍比基线高
   0.03。验证在 ep10 之后只涨 0.13 dB, 而基线涨 1.00 dB, 说明新查询机制让模型更快
   进入平台, 上限也更低。
3. 三路空间方差与基线基本相同, 说明分支没有塌成常数图; 问题不是"没输出", 而是
   "输出的内容与目标频带不匹配"。
4. 压暗条件下 L 路变化最大 (0.369、0.650), 与"L 管光照"一致, 这条分工是稳定的。
5. 运动模糊下 M 的变化仍大于 N (0.116 对 0.086, 0.198 对 0.175), 方向正确但幅度
   很小。加噪下 M 的变化反而大于 N (0.499 对 0.432), N 的噪声专属性依然不成立,
   且与基线的 σ=0.05 结果 (N 0.62 大于 M 0.45) 相反, 说明 N 路的响应比基线更弱。
6. 在 23 dB 的最终 PSNR 下, 去掉 N 或 M 反而略好 (+0.017、+0.018 dB)。这两路
   目前是纯冗余项, 不是有效分工。

结论: 新的任务 Q 机制本身可用 (三路有输出、训练正常完成、L 路功能未受影响), 但它
没有解决 N、M 不学的问题。改变 Q 的来源与门控形式之后, N、M 的相对误差与消融代价
都没有改善, 说明瓶颈不在查询机制。文档 §六 记录的"目标必须是其他两路无法提供的
成分"这一判断仍然成立, 且现在有了第二个独立证据点。
