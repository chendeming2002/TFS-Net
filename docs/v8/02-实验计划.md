## 二、实验分组

分三组, 按"先补齐机制, 再改结构, 最后引入新机制"的顺序。每组单变量。

### 组 0: 归因补测 (在 A 组之前必须先做)

phase1 同时改了分支目标与空间头, 结果无法归因。用 legacy 头固定, 只换 residual 目标跑 R1,
与 phase1 (v8 头 + residual 目标) 对比, 即可判断塌缩来自目标还是空间头。

| 编号 | 变量 | 对照 | 目的 |
|:--:|------|------|------|
| **R1** | residual 目标 + legacy 头 | phase1 (residual + v8 头) | 分离"目标"这个变量 |

**R1 的早期信号 (epoch 1, 未经完整训练确认)**: N 列 bstd 在 0.005–0.095 之间波动 (全程有活性),
M 列稳定在 0.0003–0.003 (与 v7.5 定稿的 0.0011 同量级)。
对照 phase1 的 N、M 两列都是 0.0002 (且空间方差降到 1e-18 量级)。

⇒ **初步判断**: "N 路塌成常数图"是 **v8 空间头**带来的; "M 路低迷"则是**两种头都复现**的现象,
更可能来自残差目标本身缺直流分量。R1 跑完 (epoch 5) 后用空间方差与消融口径复核, 才能定论。

### 组 A: 空间 RWKV 头的重建

**代码已完成, 但编排需要等待 R1 的结论。** 原计划是把 OmniShift 与 Channel Mix 两项一起上,
再由 A-impl / A-cm 两个 run 分离; 现在 phase1 显示空间头可能与 N 路塌缩有关, 因此:

- 若 R1 证明 N 路塌缩来自空间头 → A 组必须先做**单变量**的 A-impl (只加 OmniShift) 与 A-cm (只加 Channel Mix),

## 三、运行编排

每个正式 run 用 5 epoch (约 6.8 h), 判据沿用机制判据 (不与任何 run 比较 PSNR 数值):

| # | 判据 | 达标线 |
|:--:|------|--------|
| 1 | 三路与各自频带的误差 | 随训练下降 |
| 2 | 三路输出的**空间方差** | 明显高于常数图水平 (1e-11); 不能只看余弦 |
| 3 | 三路单独 PSNR | 都正常, 无常数图 |
| 4 | 消融: 去掉任一路 | 明显变差 (加性口径: **直接置零, 不归一化**) |

**⚠️ 判据 2 与判据 4 的口径已在本轮修正**, 原判据(用输出余弦低 + 旧的归一化消融)会给出错误结论:

- 判据 2 原为"三路输出余弦显著低于 0.99"。余弦低只说明"三路输出不像",
  常数图与正常图的余弦同样很低 —— 必须补看**空间方差**才能区分。
- 判据 4 原用"凸组合归一化"口径算消融代价, 对**加性融合**是错的: 它把剩余两路放大 1.8 倍,
  制造约 10 dB 的假衰减 (实测: 旧口径 -8.11 dB vs 正确口径 +0.08 dB)。

**⚠️ 前提: BranchM 的尺度缺陷必须先修。** 该修复已完成 (LayerNorm2d + LeakyReLU),
但实测表明它只改善了现象, 未让 M 路获得功能贡献; 真正的阻塞点是 M 路的目标设计 (见 §四)。

## 四、判读规则

**R1 是本轮的枢纽。** 它决定两个问题:

1. N 路塌成常数图, 是残差目标的锅还是 v8 空间头的锅?
   - 若 R1 的 N 路也塌 (空间方差降到 1e-11 量级) → 目标是主因, 空间头无罪, A 组按原计划合并实施;
   - 若 R1 的 N 路正常、只有 phase1 塌 → 空间头是主因, A 组必须拆成单变量先查 OmniShift 与 Channel Mix。

2. M 路为什么始终贡献低?
   - 无论 R1 结果如何, R1 的 M 列 (0.0003–0.003) 与 v7.5 定稿 (0.0011) 同量级,
     说明 **M 路低迷不是本轮引入的**, 而是残差目标与频带目标共同的性质: M 的目标都不含直流分量。
   - 若要真正救 M 路, 目标必须含有**其他两路无法提供的成分** (明显的直流分量或低频结构),
     不能是一块零均值高频残差。这属于下一次设计迭代, 不在本轮编排内。

**B1 是探索性的。** 编码器换 RWKV 属于结构统一, 收益不确定。判据放宽: 只要指标不明显变差
(落在 seed 方差内) 且参数量可控, 即可采纳。要与 NAFBlock 版比较, 必须各跑多个 seed —— 单 run 无法比。

**全部实验不与 v7.5 的定稿配置比较 PSNR** —— 本机 5 epoch 的 seed 间方差达 2.4–3.2 dB。
