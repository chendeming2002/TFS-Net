## 一、一个必须先确认的事实

在安排实验之前, 有三件事需要先查清 (都是零训练成本):

| # | 事实核查 | 方法 |
|:--:|---------|------|
| C1 | ~~当前衰减与 Vision-RWKV 不一致~~ → **核实后: 两者都是逐通道可学习常量, 相符** | 已核对 `reference_repos/Vision-RWKV/.../vrwkv.py:164,219` |
| C2 | TCA 空间头**没有 Channel Mix** | 已从代码确认 (`proj_out` 后直接 `post_norm`) |
| C3 | 当前实现**没有循环深度参数 $M$** | 已确认: MatrixRWKV 用"堆 2 个 block", 无 $M$ |

**C1 经核实不成立**: 我最初以为当前实现丢掉了"数据相关衰减", 直接查阅本地 Vision-RWKV 源码后
发现它的 `spatial_decay` 同样是逐通道可学习的 `nn.Parameter` (第 164/178/184 行),
forward 中直接以 `self.spatial_decay / T` 传入 CUDA 核 (第 219 行), 与输入无关。
**当前实现的做法与 Vision-RWKV 一致**, 这不是缺口。
(RWKV-4 及之后的语言模型版本用数据相关衰减, 但 Vision-RWKV 为效率改回了可学习常量;
若将来要补数据相关衰减, 那是"增强"而非"补齐"。)

## 二、实验分组

分三组, 按"先补齐机制, 再改结构, 最后引入新机制"的顺序。每组单变量。

> **2026-10-16 进度更新**: BranchM 修复与 phase1 探针已跑完, 结果见 `01-设计.md` §六·补。
> 裁决: b 方案 (residual 目标) 不推进; phase1 因为同时改了两个变量无法归因,
> 若要继续必须按下面的"单变量补测"重新编排。

### 补测 (在组 A 之前先做, 用于归因)

phase1 同时改了分支目标与空间头, 结果无法归因。用 legacy 头固定, 只换 residual 目标跑一次,
与 phase1 (v8 头 + residual 目标) 对比, 即可判断塌缩来自目标还是空间头。

| 编号 | 变量 | 对照 | 目的 |
|:--:|------|------|------|
| R1 | residual 目标 + legacy 头 | phase1 (residual + v8 头) | 分离"目标"这个变量 |

### 组 A: 空间 RWKV 头的重建 (最高优先级)

当前空间头有 C1、C2 两个缺口, 且有 RSRWKV 的混杂来源。本组把它重建为规范的
Vision-RWKV / Restore-RWKV 形态。

| 编号 | 变量 | 对照 | 目的 |
|:--:|------|------|------|
| A1 | (已取消, 见 §一的核对结论) | — | — |
| A2 | **Restore-RWKV 的 Omni-Shift** | 无局部上下文 (当前) | 补上低层视觉需要的局部归纳偏置 |
| A3 | **Channel Mix** | 无 (当前) | 补齐经典 block 的两段式结构 |

A1 取消后, A 组的实际内容是 **Omni-Shift** 与 **Channel Mix** 两项:

- **A-impl**: 空间头加入 Restore-RWKV 的 Omni-Shift, 保留我们的三路 Q
- **A-cm**: 在 A-impl 基础上加 Channel Mix

### 组 B: 编码器改造

| 编号 | 变量 | 对照 | 目的 |
|:--:|------|------|------|
| B1 | Encoder 内部 NAFBlock → RWKV block | NAFBlock (当前) | 结构统一, 看是否掉指标 |

只做 **1 个 run**。接口保持 `SharedEncoder` 不变 (输出三层金字塔), 便于直接替换。

### 组 C: 新机制引入 (先期探索)

| 编号 | 变量 | 说明 |
|:--:|------|------|
| C-rwkv7 | RWKV-7 的广义 delta 规则 | 直接搬运原始实现 |
| C-vres | Value Residual (来自 FEAT) | 第一层 value 残差接入所有后续层 |

**先期只做搬运 + 冒烟测试, 不做完整训练**。确认能跑通、参数正常、反传正常之后,
再决定是否纳入正式对照。

## 三、运行编排

每个正式 run 仍用 5 epoch (约 6.8 h), 判据沿用 v7.5 的机制判据 (不比较 PSNR):

| # | 判据 | 达标线 |
|:--:|------|--------|
| 1 | 三路与各自频带的误差 | 随训练下降 |
| 2 | 三路输出余弦 | 显著低于 0.99 |
| 3 | 三路单独 PSNR | 都正常, 无常数图 |
| 4 | 消融: 去掉任一路 | 明显变差 |

**⚠️ 前提: BranchM 的尺度缺陷必须先修** (见 `../v7.5/03-design定稿.md` §三)。
该缺陷与本轮改动无关, 但它使判据 3 无法通过、判据 4 无法解释。修复后再开始 v8 对照,
否则所有 run 都会被同一个已知缺陷污染。

| 组 | run 数 | 耗时 |
|:--:|:--:|:--:|
| BranchM 修复验证 | 1 | 6.8 h |
| A (空间头重建) | 2 | 13.6 h |
| B (编码器) | 1 | 6.8 h |
| C (新机制冒烟) | 0 (仅代码) | 0.5 h |
| **合计** | **4** | **约 28 h** |

### 执行顺序

```
0. 修 BranchM 尺度缺陷 → 复测判据 3  (是否达标决定后续 basline 是否可用)
1. A-impl   (规范空间头)              ← 关键: 这一步决定后续所有对照的起点
2. A-cm     (加 Channel Mix)
3. B1       (RWKV 编码器)
4. C        (RWKV-7 / Value Residual 冒烟测试, 只验代码)
```

## 四、判读规则

**A 组是本轮的核心。** 若 A-impl 的判据 1/2/3 都明显优于当前实现, 说明补齐机制是对的,
后续以它为新基线; 若没有改善, 说明问题不在机制缺失, 需要重新审视空间头的设计。

**B 组是探索性的。** 编码器换 RWKV 属于结构统一, 收益不确定。判据放宽: 只要指标不明显
变差 (落在 seed 方差内) 且参数量可控, 即可采纳。

**全部实验不与 v7.5 的定稿配置比较 PSNR** —— 本机 5 epoch 的 seed 间方差达 2.4–3.2 dB。
