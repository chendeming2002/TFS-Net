# Cross RWKV Gate 迁移: 任务 Q 机制的重构

> 创建于 2026-10-18
> 来源论文: Video Action Recognition Based RWKV (arXiv 2411.05636), 其中的 LCR 模型
> 涉及代码: `models/golf_v7r/cross_rwkv_head_v8.py`、`models/golf_v7r/triple_query_tca_v9.py`

## 一、为什么要改

现在 `SpatialRWKVHeadV8` 里对 Q 的使用只有一行:

```
out = sigmoid(q) * wkv
```

其中 `q = proj_q(pre_norm(center_feat))`。这个写法的实质是: 取一个线性投影, 过
sigmoid 压到 0 到 1 之间, 再逐元素乘到 WKV 的输出上。它对应 RWKV 里的 R (receptance)
门, 只是在"由哪一路特征产生 R"上做了支路分工。换句话说, 我们的"任务查询"并没有引入
任何 RWKV 之外的机制, 它只是 R 的一个使用方式。

这带来两个实际限制:

1. R 被 sigmoid 限制在正区间。RWKV 的 R 是可以取负值的, 负值相当于对 WKV 的某些
   通道做反相, 这是它表达力的一部分。sigmoid 把这一半表达力丢掉了。
2. 只有一个门。WKV 的输出没有任何归一化步骤就直接被乘, 而门本身也只由一路输入决定,
   门和值之间没有第二个独立信号来调节。

论文 2411.05636 的 Cross RWKV gate 提供了一种不同的组织方式: 用两路不同来源的输入,
一路产生 R 和 G 两个投影, 另一路产生 K 和 V。R 先与 WKV 的输出做逐元素乘并接归一化,
再由 G 通过 SiLU 做门控。这样门控信号来自与键值不同的来源, 门控发生在归一化之后,
且 R 是带符号的线性投影, 不受 sigmoid 限制。

本次改动的目标就是把这一套结构移植进来, 替换掉 `sigmoid(q) * wkv`。

## 二、论文里这个 gate 的原始结构

论文第 3.2 节给出的输入是: 当前帧 `x_t`、当前帧的边缘图 `x_t^e`、LSTM 的隐状态
`h_{t-1}` 与细胞状态 `c_{t-1}`。它先做因果卷积, 再用 Q-Shift 和线性层产生 R、G、K、V:

```
R = Q-Shift_R( Cauconv(x_t, h_{t-1}) ) · W_R          (2)
G = Q-Shift_G( Cauconv(x_t, h_{t-1}) ) · W_G          (2)

K = Q-Shift_K( x_t^e ) · W_K                          (3)
V = Q-Shift_V( x_t^e ) · W_V                          (3)
```

R 与 G 来自同一路输入 (当前帧与过去隐状态合并后的结果), K 与 V 来自另一路输入
(当前帧的边缘图)。随后:

```
a_t = concat( SiLU(G_t) ⊙ LN( R_t · Bi-wKV_t ) ) · W_a   (4)

wKV_t = diag(u)·K_tᵀ·V_t + Σ_{i<t} diag(w)^{t-1-i}·K_iᵀ·V_i   (5)
w = exp(-exp(ω)),  ω 为逐头的可学习参数                      (5)
```

式 (4) 是这次迁移的核心。它包含三个动作, 按顺序:

1. `R_t · Bi-wKV_t`: R 与双向 WKV 的结果逐元素相乘。R 是带符号的, 可以放大也可以翻转。
2. `LN(...)`: 对每个头分别做 LayerNorm。注意归一化在乘法之后, 这意味着 R 改变的是
   各通道的相对比例, 而不是整体幅度 (整体幅度被 LN 抹掉)。
3. `SiLU(G_t) ⊙ ...`: G 过 SiLU 之后做逐元素门控。SiLU(x) = x·sigmoid(x), 取值范围
   是 (-0.278, +∞), 可以取负, 也可以在 x 较大时近似恒等。

论文随后进入 Channel Mix, 与我们的旧实现也不同:

```
R' = Q-Shift_{R'}( a_t ) · W_{R'}                     (6)
K' = Q-Shift_{R'}( a_t ) · W_{K'}                     (6)

V' = ReLU( K' )² · W_{V'}                             (7)
A' = σ( R' ) ⊙ V'                                     (8)
```

注意这里的门控形式与 Spatial Mix 相反: Spatial Mix 里是 `SiLU(G) ⊙ LN(R·wKV)`,
Channel Mix 里是 `σ(R') ⊙ ReLU(K')²`。论文原文如此, 我们没有把它统一。

## 三、论文结构到我们模型的映射

论文是视频动作识别, 输入是帧和边缘图; 我们是低光增强, 输入是五帧的低光片段,
输出是三分支各自的频带分量。逐项对应如下。

### 3.1 R 与 G 的输入: 这就是新的任务 Q 机制

迁移后, R 和 G 取代原来的 Q, 成为三路各自的任务查询。它们的输入按支路分工:

| 支路 | R 与 G 的输入 | K 与 V 的输入 |
|------|----------------|----------------|
| N (噪声带) | `F1_multi` (多帧聚合特征) | `kv_N`, 即多帧特征的低通 |
| L (光照带) | `F1_multi` (多帧聚合特征) | `kv_L`, 即多帧特征的更大核低通 |
| M (运动带) | `F1_single` (中心帧特征) | `kv_M`, 即中心帧的高频残差 |

这与论文"R/G 来自一路、K/V 来自另一路"的二分完全对应。区别在于我们不用边缘图作为
第二路, 而是用每个支路自己的频带来源。原因很直接: 我们的三个分支是按频带划分的,
KV 必须携带该频带的内容, 否则分支的物理分工在数据流上就不成立了。若把 KV 换成 Canny
边缘图, 三路 KV 会变成同一张图的三种投影, 分支差异就只剩投影矩阵的初始随机性。

论文里 R/G 的输入是 `Cauconv(x_t, h_{t-1})`, 即当前帧与过去隐状态合并。我们没有
LSTM, 也没有隐状态。这里用各支路自己的特征来代替:

- N、L 的 `F1_multi` 本身就是五帧按权重聚合的结果, 帧间时序信息已经包含在里面,
  等价于"当前帧与过去信息的合并"。
- M 的 `F1_single` 只有中心帧。这是刻意的: M 支路要建模的是单帧内的局部结构偏移,
  不引入任何跨帧运算 (见 `03-M支路重构设计.md`)。因此 M 路没有"过去"这一项,
  R 与 G 的输入就是当前帧本身。

### 3.2 Q-Shift 的实现: 用 OmniShift

论文只写了 Q-Shift 这个名字, 没有给出具体实现。这类 shift 在时序 RWKV 里是把相邻
时刻的通道按一定比例混入当前时刻; 图像没有时间轴, 对应物是空间邻域的混合。
我们采用已有的 `OmniShift`, 它是四个分支的加权和:

```
OmniShift(x) = α0·x + α1·DWConv1x1(x) + α2·DWConv3x3(x) + α3·DWConv5x5(x)
```

四个分支感受野不同 (0、1、3、5), 权重 α 可学习, 初始化为 1/√4 使初始输出尺度与
输入同量级。它在推理时可以用一个 5×5 深度卷积等价表示, 不增加推理开销。

论文的式 (2) 与式 (3) 一共有四个 Q-Shift, 分别作用在 R、G、K、V 的输入上。
我们的做法是四个都保留:

```
r_src = OmniShift_R( center_feat )
g_src = OmniShift_G( center_feat )
k_src = OmniShift_K( context_feat )
v_src = OmniShift_V( context_feat )
```

R 与 G 各自一个独立的 OmniShift (不共享), 与论文的两个独立 Q-Shift 对应;
K 与 V 也各自一个, 与式 (3) 的两个 Q-Shift 对应。

需要单独说明式 (5) 里的衰减 `w`。在这一篇论文里 `w = exp(-exp(ω))`, 其中 ω 是
逐头的可学习参数, 是一个与位置无关的标量, 式 (5) 没有对它做 Q-Shift。我们同样
把它保持为逐通道参数。这不是设计取舍, 而是当前 WKV 算子的约束: 衰减在核里以
[B, C] 的形状参与计算, 每个通道一个值, 不接受逐 token 的衰减。要支持逐 token 衰减
需要重写 CUDA 核, 本次不做。

### 3.3 逐头 LayerNorm

式 (4) 的 LN 是"对每个头分别做"。我们的通道被均分成 4 个扫描方向, 每个方向
`head_dim = C/4` 通道。实现上对每个 token, 在 head_dim 维度上做 LayerNorm。
换方向扫描相当于把同一批 token 换了个顺序, 不影响逐 token 的归一化结果。

### 3.4 Channel Mix

按式 (6) 到 (8) 实现。R' 与 K' 从 a 产生, V' 由 ReLU(K')² 产生, 输出由 σ(R') 门控。
这一段的输出以残差加回 a。

论文的 `ReLU(K')²` 有两个已知问题, 在我们这里会导致参数永久冻结:

- 负半轴梯度严格为零。K' 的某个通道一旦整体落进负区间, 该通道永远收不到梯度。
- 与残差结构配合时, 若 K' 的初值偏负, 整个 Channel Mix 分支在第一轮就停住。

本项目在此之前已经因同类问题吃过一次亏 (BranchM 的 GELU 导致权重梯度恒为零,
见 `01-设计.md`)。因此默认使用 `LeakyReLU(0.01)²` 代替 `ReLU²`, 保留负半轴的微小
梯度通道。开关 `cm_act="relu_sq"` 可以切回论文原样, 用于对照。

## 四、新旧 Q 的差别对照

| 项 | 旧实现 (`SpatialRWKVHeadV8`) | 新实现 (`CrossRWKVHeadV8`) |
|----|------------------------------|----------------------------|
| Q 的数量 | 1 个 (`proj_q`) | 2 个 (`proj_r` 与 `proj_g`) |
| Q 的取值 | sigmoid 压到 (0, 1) | R 为带符号线性投影; G 过 SiLU 后门控 |
| 乘法位置 | 直接乘 WKV 输出 | 乘后接逐头 LayerNorm, 再乘 SiLU(G) |
| 归一化 | 无 | 逐头 LayerNorm |
| 门的信号来源 | 与 K/V 同源的支路特征 | 与 K/V 不同源 (中心帧 vs 频带特征) |
| Channel Mix | `sigmoid(r') ⊙ Linear(LeakyReLU(Linear(a)))` | `σ(R') ⊙ W_V'(LeakyReLU(K')²)` |

最后一行需要说明: 旧实现的 Channel Mix 是一个普通 MLP 加 sigmoid 门, 门和值都从
同一份归一化特征线性投影出来, 结构上相当于论文式 (6) 到 (8) 的一个退化版本。
新实现按论文拆分出 R'、K'、V' 三个投影, 值不再走完整 MLP, 而是"负半轴保留的平方
激活之后线性投影"。

## 五、初始化

有三个位置需要特别处理, 否则模块在第一步就没有梯度或者输出幅度失控。

1. `proj_g` 的偏置初始化为 1.0。SiLU(0) = 0, 如果 G 的初值全零, 整个 WKV 通路
   在第一步的输出为零, K、V、w、u 的梯度全部为零。偏置设 1 后 SiLU(1) ≈ 0.731,
   门控处于开启状态, 梯度一开始就能流下去。这是与论文原文唯一的初始化差异,
   论文没有交代 G 的初始化。
2. `proj_r` 用均匀分布 ±0.5/√C。层归一化会抹掉 R 的幅度, 因此这里不需要很小的
   初始化, 只需要避免初始步的数值过大。
3. Channel Mix 的输出投影 `proj_out2` 零初始化。它与 TCA 里 `scale_*` 的零初始化
   不同: `scale_*` 在残差外层, 零初始化会让整个注意力分支初始恒等; 这里是
   Channel Mix 的残差, 零初始化让该残差初始为零, 梯度在第一步就能到达末层, 从第二步
   起到达上游。这个两步过程在旧测试 `test_channel_mix_gradient_reaches_upstream`
   里已经固化过, 不是双零死锁。

## 六、参数量与计算量

每个头的变化:

- 删去 `proj_q` (C×C)。
- 增加 `proj_g` (C×C)。
- 增加 4 个 OmniShift (每个约 3 个 C×C depthwise 卷积)。
- Channel Mix 由"两个线性层"变为"三个线性层", 参数量从 2·C·(4C) 变为 3·C·(4C)
  左右, 具体取决于实现。
- 增加逐头 LayerNorm (4·head_dim)。

总体参数量会小幅上升, 具体数字在实现后由 `count_params` 打印, 不需要现在推算。

计算量方面, 主要增量是 OmniShift 的深度卷积。在 F1 尺度 (256×256, C=32) 上,
每个 3×3 深度卷积约 2000 万次乘加, 四个 shift 乘三个支路约 2.4 亿次, 相对整个
前向 (约 5 秒每步、每步五千多个样本) 可以忽略。WKV 扫描次数不变。

## 七、明确的取舍与不迁移的部分

| 论文组件 | 是否迁移 | 理由 |
|----------|----------|------|
| Cross RWKV gate (式 2–4) | 迁移 | 本次目标 |
| Channel Mix 的式 (6)–(8) | 迁移 | 同一模块内的配套结构, 拆开用会失去原论文的完整形态 |
| Q-Shift | 迁移, 用 OmniShift | 论文未给出实现, 图像任务需要空间替代物 |
| LSTM 的隐状态与细胞状态 | 不迁移 | 用户明确排除; 且我们的输入是固定五帧, 不存在跨样本的长序列状态 |
| 式 (10)(11) 的细胞状态更新 | 不迁移 | 属于 LSTM 的递推部分 |
| 边缘信息作为遗忘门 | 不迁移 | 没有 LSTM 的遗忘门可以接; 分支的频带来源已经承担了"什么该进 KV"的分工 |
| Canny + Otsu 边缘提取 | 不迁移 | 见 3.1 节: KV 必须是各支路自己的频带内容 |
| Tube masking | 不迁移 | 视频分类的正则化手段, 与增强任务的输入形式无关 |
| 3D 卷积的 patch embedding | 不迁移 | 我们沿用逐帧 2D 编码器 |

## 八、实验安排与判据

配置: `configs/v8/crossrwkv_gate_15ep.yaml`, 输出目录 `outputs/v8_crossrwkv_gate_15ep`。
除 `model.q_mode: cross_rwkv` 之外, 其余超参与 `configs/v8/unet_refactor_15ep.yaml`
完全一致, 保证与 U-Net 基线可比。

判据沿用 U-Net 实验的同一套, 不新增软性指标:

1. 验证 PSNR 与基线的差值。基线是 U-Net 15ep 的 24.12 dB。
2. 三路输出的空间方差 (主判据)。常数图约 1e-9, 有结构约 1e-4 或以上。
   基线: N = 1.1e-3, M = 7.3e-4, L = 4.8e-2。
3. 各支路相对自身频带目标的误差 (1.0 表示输出全零)。基线: N 0.73, M 0.71, L 0.16。
4. 消融代价: 把某一路权重置零后 PSNR 的下降。基线: 置零 N 或 M 约 0.3 dB,
   置零 L 约 15.9 dB。
5. 压暗、加噪、运动模糊三类扰动下各路的变化量与相对误差, 与基线对比。

如果新 Q 机制有效, 预期的现象是 N 与 M 两路的相对误差下降, 消融代价上升。
如果只是 PSNR 不变而 N、M 仍然不学, 说明瓶颈不在 Q 机制, 需要回到监督目标或
数据流本身找原因。
