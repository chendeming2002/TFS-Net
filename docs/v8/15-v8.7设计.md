# v8.7: 三分支的退化专门化改进

> 创建于 2026-10-28
> 基础: v8.6 (25.95 dB / 0.8370 / 0.3697, 见 `14-v8.6设计.md`)
> 性质: **已实施, 30 轮训练中** (2026-10-28 启动)。三项改动都进入同一个实验,
> 与设计稿的单变量原则不同, 原因是三项的作用域不重叠 (分别在 N/L/M 三个分支内部)。
> 若结果不好, 归因时需要分别回退验证。

## 一、起点

v8.6 的三个分支指标:

| 分支 | 相对误差 | 置零代价 | 融合权重 |
|---|---:|---:|---:|
| N | 0.609 | −3.945 dB | 1.248 |
| L | 0.099 | −18.16 dB | 1.330 |
| M | 0.552 | −0.246 dB | 0.775 |

三个分支的输出都是完整图像, 分别监督到频带目标。N 的置零代价最高, 但它的相对误差
并不最低; M 的相对误差最低, 但置零代价最小, 融合权重也最低。这说明"学得好"与"用得上"
在三路里脱节的程度不同。

## 二、三项改进, 按风险与收益排序

### 改进 1 (NBranch): 残差去噪形式 —— 优先级最高

**现状问题**: N 路直接预测完整图像 `Y_N`, 没有区分干净信号与噪声残差。它的归纳偏置
与 L、M 相同, 都是"从特征到图像", 没有表达"预测的是噪声"这一物理含义。

**改动**: 把输出从直接预测图像改为预测噪声残差, 再从输入锚点减去:

```
Y_N = X_anchor - n_hat
```

其中 `X_anchor` 是 N 路的输入对应的图像 (中心帧), `n_hat` 是分支预测的噪声分量。
分支网络本身不变 (2×NAFBlock + 通道注意力 + 两层卷积), 只改最后一层的输出语义。

**与外部建议的差别**: 外部建议让分支输出修正量, 由融合层做减法。我们这里在分支内部
完成, 输出仍是完整图像, 融合接口不变。这样 SGRFv10 的三段串接不需要改动。

**风险**: 残差形式要求分支输出的是"噪声", 而 `noise_target` 是零均值频带, 不是
带符号的噪声。如果训练目标与残差形式不匹配, 会出现符号漂移。需要先验证:
`Y_N = X_t - n_hat` 与 `noise_target` 的 L1 是否比当前形式更低。

### 改进 2 (LBranch): 对数域光照图 —— 风险最低

**现状问题**: `L_t = sigmoid(illum_head(x))`, 值域 (0,1), 在 0 和 1 附近饱和。
实测训练后 gamma 从 2.0 降到 1.584, 说明模型在主动对抗初始的压暗趋势, 但这个对抗
是被动的, 不是结构上的。

**改动**: 把光照图改为对数域预测:

```
L_t = exp(illum_head(x))
```

值域 (0, +∞), 避免 sigmoid 在两端饱和。`illum_head` 的零初始化保留, 初始
`exp(0) = 1`, 与 sigmoid 的初始 0.5 不同, 但 Retinex 的 `R_t = X_t / L_t` 在
`L_t=1` 时给出 `R_t = X_t`, 是恒等起点, 比 0.5 更接近"不改变输入"。

**风险**: `exp` 在输入偏大时会爆炸, 需要 clamp 或限幅。建议 `L_t = exp(clamp(illum_head(x), -3, 3))`, 范围 [0.05, 20], 足够覆盖光照变化。

### 改进 3 (MBranch): 多尺度局部去模糊 —— 风险中

**现状问题**: M 的输入只有 `F_M`, 与 N、L 的输入在数据流上没有差异。它的置零代价
从 −0.923 降到 −0.246, 说明它的贡献被 N 路接走了。这不是 M 学坏, 是它的输入没有
携带足够的运动特异性。另一个更根本的问题是: M 在单帧模式下没有任何跨帧模块,
它实际上是一个单帧修复分支, 不是显式的运动补偿模块。

**改动**: 保留单帧约束, 不引入光流、不跨帧匹配, 只在特征域插入一个零初始化的
多尺度局部残差单元:

```
F_M
 ├─ 1×1 Conv + LayerNorm2d          (现有 fusion_conv, 通道保持 32)
 ├─ 多尺度局部特征提取 (并行):
 │    ├─ 3×3 DWConv (dilation=1)     局部边缘与细纹理
 │    ├─ 3×3 DWConv (dilation=2)     中等邻域
 │    └─ 3×3 DWConv (dilation=3)     更宽的局部结构退化
 ├─ 拼接 → 1×1 Conv 融合 → 零初始化残差注入
 └─ 2×NAFBlock → LayerNorm2d → to_rgb (不变)
```

零初始化的残差注入使新增模块起步时不改变主干特征, 与现有系统里已验证过的稳定
初始化思路一致。

**为什么选这个而不是邻帧差分或光流**:

- 邻帧差分会把帧间独立的噪声也带进来, 差分放大噪声, 这在加噪条件下是已知的
  风险;
- 光流与跨帧匹配在 SDSD 上已被证明无效 (邻帧位移太小, 对齐结果与中心帧几乎相同),
  且会引入已知的塌缩风险;
- 多尺度卷积在空间域扩展局部感受野, 不引入跨帧依赖, 与单帧约束兼容。

**风险**: 三种感受野可能学到冗余特征; 膨胀卷积可能出现栅格效应。这两个风险都
需要在训练后检查: 若三个分支的输出高度相关, 说明冗余; 若输出出现规则网格状伪影,
说明栅格效应。

**与外部建议的差别**: 外部建议的 M-A 路线与本方案一致, 但外部还提了 DWT 与 FFT 作为
后续候选。我们把 DWT 与 FFT 都推迟: 先验证多尺度卷积是否有效, 再决定是否引入频域模块。
第一轮不做 FFT 与 DWT。

**判据**: M 置零代价优于 −0.246, 运动模糊 9px 不低于 24.91, 加噪 σ=0.05 不低于 19.95
(不能比 v8.6 更差, 因为多尺度卷积可能放大噪声)。

## 三、不做的事

按外部建议与我们的实测, 以下三项本轮不做:

- **不增加 NAFBlock 数量**。三路的分支容量已经足够, 瓶颈在归纳偏置, 不在深度。
- **不给 LBranch 加平滑损失**。这是训练目标的改动, 需要单独验证, 且当前 L 的
  相对误差 0.099 已经很好, 改动风险大于收益。
- **不恢复 MBranch 的多帧模式, 也不引入光流或跨帧匹配**。多帧模式已被实验证明无效
  (docs/v8/03), MBranch 的改动严格限定在单帧、局部、多尺度。
- **不同时加入 FFT 与 DWT**。频域模块作为后续候选, 第一轮只做空间域的多尺度卷积。

## 四、验证顺序

三项都是单变量, 不叠加:

| 实验 | 改动 | 基线 | 判据 |
|---|---|---|---|
| v8.7-N | NBranch 残差去噪 | v8.6 | N 相对误差 < 0.609, 加噪 σ=0.05 不低于 19.95 |
| v8.7-L | LBranch 对数域光照图 | v8.6 | L 相对误差 < 0.099, 压暗 ×0.5 不低于 14.86 |
| v8.7-M | MBranch 多尺度局部去模糊 | v8.6 | M 置零代价优于 −0.246, 模糊 9px ≥ 24.91, 加噪 σ=0.05 ≥ 19.95 |

每个实验 30 轮, 与 v8.6 同配置。若某一项没有收益, 回退到 v8.6 的对应分支,
不影响其他两项的独立验证。

MBranch 的诊断额外加一项: 分别比较模糊区域与静态区域的指标变化, 不能只靠整图 PSNR
判断 M 是否在工作。这一项由诊断脚本在置零前后分别计算, 不需要修改训练流程。

## 五、gamma 的核查结果

外部建议指出 `gamma_init=2.0` 与当前公式 `Y_L = X_t·L_t^(γ−1)` 的组合倾向于压暗。
实测训练后 gamma = 1.584, 从 2.0 下降了 0.42, 方向与断言一致: 模型在主动往
"提亮"方向调整。这支持对数域改进的动机, 但不构成"必须改"的证据, 因为模型已经
通过调整 gamma 补偿了初始化问题。是否改, 由实验结果决定。
