# v8.7: 三分支退化专门化改进 — 结果

> 创建于 2026-10-29
> 基础: v8.6 (25.95 dB / 0.8370 / 0.3697)
> 配置: `configs/v8_5/v8_7_30ep.yaml`
> 输出: `outputs/v8_7_30ep`

## 一、改动

三项分支改动同时进入同一个实验 (与设计稿的单变量原则不同, 三项作用域不重叠):

| 分支 | 改动 |
|---|---|
| NBranch | 残差去噪: `Y_N = X_t − n_hat` |
| LBranch | 对数域光照图: `L_t = exp(clamp(illum_head(x), −3, 3))` |
| MBranch | 多尺度局部残差单元: 三路膨胀深度卷积 (d=1/2/3) + 1×1 融合, 零初始化 |

## 四、扰动响应: 加噪严重退化

| 条件 | v8.7 | v8.6 | 差值 |
|---|---:|---:|---:|
| 干净 | 25.90 | 25.55 | +0.35 |
| 压暗 ×0.5 | 15.17 | 14.86 | +0.31 |
| 压暗 ×0.25 | 11.32 | 10.56 | +0.76 |
| 加噪 σ=0.02 | 18.76 | 22.89 | **−4.13** |
| 加噪 σ=0.05 | **13.89** | **19.95** | **−6.06** |
| 模糊 5px | 25.60 | 25.36 | +0.24 |
| 模糊 9px | 25.33 | 24.91 | +0.42 |

干净、压暗、运动模糊都略好, 但加噪 σ=0.05 掉 6.06 dB, σ=0.02 掉 4.13 dB。
这不是随机波动: 同一 checkpoint 上可复现, 且与插值版的 −11 dB 崩塌是同一类问题的
较轻形式。

## 五、原因分析

三项改动同时进入, 无法单独归因。但有一处结构性线索:

N 路的残差去噪 `Y_N = X_t − n_hat` 把 N 的输出从"预测噪声"变成了"从输入减去噪声"。
当输入本身含噪时, `X_t` 也含噪, `n_hat` 如果预测的是"干净输入里的噪声", 那么
`X_t − n_hat` 会把输入噪声原样保留。这与插值版的缺陷同源: 噪声没有被抑制, 而是被
保留或放大。

L 路的对数域光照图与 M 路的多尺度单元不太可能单独造成这个退化, 因为它们的输入
与噪声的关系不变。最可能的解释是 N 路的残差形式改变了它对噪声的响应方式。

## 六、结论

v8.7 的干净指标与 v8.6 持平, LPIPS 略好, 但加噪鲁棒性明显退化。按"不能仅凭 PSNR
单一指标宣称成功"的原则, v8.7 **不能作为当前最佳**, v8.6 仍然是。

下一步若要继续: 单独验证 N 路的残差去噪形式, 与 v8.6 的其他两项不变, 看加噪退化
是否来自这一项。若确认, 回退 N 路, 保留 L 与 M 的改动。
