# v8.6: 跳跃连接 + SPAB 增强 R

> 创建于 2026-10-28
> 代码: `models/golf_v7r/spatial_rwkv_head_v8.py`、`models/golf_v7r/cross_rwkv_head_v8.py`
> 配置: `configs/v8_5/v8_6_30ep.yaml`
> 基线: `configs/v8_5/g_sgrf10_qrb_cross_rwkv_30ep.yaml` (25.03 dB)

## 一、改动

两处, 都在代码里, 配置与上游完全不变:

1. **跳跃连接**: `SpatialRWKVHeadV8` 与 `CrossRWKVHeadV8` 的 Spatial Mix 输出加输入残差。
   `EncoderRWKVBlock` 继承基类, 自动获得同样的残差。QueryRWKVBlock 的残差来自
   Q 输入 (`center_feat`), 与 Restore-RWKV 的 `x + att(LN(x))` 一致。
2. **SPAB 增强 R**: `CrossRWKVHeadV8` 的 R 路径改为 `shift_r → SPAB → proj_r`,
   G 路径不变。SPAB 是 SPAN (CVPR 2024) 的参数无关注意力块: 三个 3×3 卷积 +
   `sigmoid(out)−0.5` 对称激活 + 残差 `(out3 + x) * sim_att`。末层 bias 初始化为 1,
   保证初始门接近开启。

## 四、分支指标

| 项 | v8.6 | 基线 (G + SGRFv10) |
|---|---:|---:|
| 空间方差 N / L / M | 1.47e-3 / 4.44e-2 / 1.04e-3 | 1.32e-3 / 4.32e-2 / 1.09e-3 |
| 相对误差 N / L / M | 0.609 / 0.099 / 0.552 | 0.647 / 0.117 / 0.561 |
| 置零代价 N / L / M (dB) | −3.945 / −18.16 / −0.246 | −0.491 / −17.35 / −0.923 |
| 阶段幅度 N / L / M | 1.248 / 1.330 / 0.775 | 1.236 / 1.317 / 1.250 |

三点值得记录:

1. **N 路的置零代价从 −0.49 升到 −3.95 dB**, 是六组实验里最高的。这主要来自跳跃连接:
   Q 输入直接加到 Spatial Mix 输出上, N 路的内容不再只经过门控才能影响输出。
2. **M 路的置零代价从 −0.92 降到 −0.25**, 方向相反。M 的融合权重从 1.250 降到 0.775,
   说明它的贡献被重新分配给了 N。这与 M 的相对误差仍最低 (0.552) 并存,
   与 v8 的"学得好但用不上"不同, 是"贡献被转移"。
3. **LPIPS 明显改善** (0.427 → 0.370), 是所有实验里最低的。这与 SPAB 的局部特征提取
   一致: R 的方向选择更准, 感知质量随之提高。

## 七、结论

v8.6 是当前最佳模型。两项改动都按设计生效: 跳跃连接让 Q 的内容直接进入输出,
N 路的贡献大幅提升; SPAB 增强的 R 让方向选择更准, LPIPS 降到所有实验最低。

需要说明的两点:

- **不能归因**: 跳跃连接与 SPAB 同时进入, 无法单独判断哪一项贡献更大。
  若需要归因, 应各跑一组对照: 只加残差、只加 SPAB。
- **M 路的贡献转移**: M 的融合权重从 1.25 降到 0.78, 置零代价下降, 但相对误差仍最低。
  这不是 M 学坏了, 是 N 路的残差通路把一部分工作接走了。若需要 M 恢复更高的贡献,
  需要单独分析, 不在本轮范围内。

## 八、三个分支的组成与实现

三个分支 (NBranch / LBranch / MBranch) 在 `GolfNet_v8` 里以 `at_f1=True` 运行:
输入是 F1 全分辨率特征 `[B, 32, H, W]`, 输出是 3 通道图像 `[B, 3, H, W]`, 不做上采样。

### 8.1 NBranch: 成像噪声去除

结构: 2 个 NAFBlock → 通道注意力 (SE-like) → 两层 3×3 卷积出图。

```python
class NBranch(nn.Module):
    def __init__(self, channels=32, num_blocks=2, out_channels=3, at_f1=True):
        self.denoise_blocks = nn.Sequential(*[
            NAFBlock(channels) for _ in range(num_blocks)])
        self.channel_attn = ChannelAttention(channels)
        # at_f1=True 时不上采样
        self.to_rgb = nn.Sequential(
            nn.Conv2d(channels, 32, 3, 1, 1),
            nn.LeakyReLU(0.01, inplace=True),
            nn.Conv2d(32, out_channels, 3, 1, 1),
        )

    def forward(self, F_N):
        x = self.denoise_blocks(F_N)
        x = self.channel_attn(x)
        Y_N = self.to_rgb(x)
        return {"Y_N": Y_N}
```

参数量 26.8K。通道注意力是全局平均池化后接两个 1×1 卷积与 sigmoid,
对通道做逐通道缩放。

### 8.2 LBranch: 光照校正 (Retinex)

结构: 2 个 NAFBlock → LayerNorm2d → 光照图预测 → Retinex 重建。

```python
class LBranch(nn.Module):
    def __init__(self, channels=32, num_blocks=2, gamma_init=2.0,
                 out_channels=3, at_f1=True):
        self.refine_blocks = nn.Sequential(*[
            NAFBlock(channels) for _ in range(num_blocks)])
        self.refine_norm = LayerNorm2d(channels)
        # 光照图: 零初始化 → 初始 L_t ≡ 0.5
        self.illum_head = nn.Sequential(
            nn.Conv2d(channels, channels // 2, 3, 1, 1),
            nn.GELU(),
            nn.Conv2d(channels // 2, 1, 3, 1, 1),
        )
        nn.init.zeros_(self.illum_head[-1].weight)
        nn.init.zeros_(self.illum_head[-1].bias)
        self.log_gamma = nn.Parameter(torch.tensor(float(gamma_init)).log())
        self.residual_conv = nn.Conv2d(channels, out_channels, 3, 1, 1)
        nn.init.zeros_(self.residual_conv.weight)
        nn.init.zeros_(self.residual_conv.bias)

    def forward(self, F_L, X_t):
        x = self.refine_norm(self.refine_blocks(F_L))
        L_map = torch.sigmoid(self.illum_head(x))     # [B,1,H,W]
        L_t = F.interpolate(L_map, size=X_t.shape[-2:], mode='bilinear',
                            align_corners=False)
        eps = 1e-4
        R_t = (X_t / L_t.clamp(min=eps)).clamp(max=10.0)
        gamma = self.log_gamma.exp()
        Y_L = R_t * L_t.pow(gamma)
        Y_L = Y_L + self.residual_conv(x)
        Y_L = Y_L.clamp(0.0, 1.0)
        return {"Y_L": Y_L, "L_t": L_t, "R_t": R_t}
```

参数量 22.1K。Retinex 的三要素都在: 光照图 `L_t` (sigmoid 归一化)、
反射率 `R_t = X_t / L_t`、可学习 gamma。`residual_conv` 是零初始化的补偿项。

### 8.3 MBranch: 运动补偿 (单帧模式)

v8 的 `single_frame=True`, 完全去掉光流/变形/置信度, 只用中心帧特征。

```python
class MBranch(nn.Module):
    def __init__(self, channels=32, num_frames=5, num_blocks=2,
                 out_channels=3, single_frame=True, at_f1=True):
        # single_frame=True: 不做跨帧, 只有中心帧一路输入
        self.fusion_conv = nn.Sequential(
            nn.Conv2d(channels, channels, 1, bias=True),
            LayerNorm2d(channels),
        )
        self.refine_blocks = nn.Sequential(*[
            NAFBlock(channels) for _ in range(num_blocks)])
        self.to_rgb_norm = LayerNorm2d(channels)
        self.to_rgb = nn.Sequential(
            nn.Conv2d(channels, 32, 3, 1, 1),
            nn.LeakyReLU(0.01, inplace=True),
            nn.Conv2d(32, out_channels, 3, 1, 1),
        )

    def forward(self, F_M, F2_seq):
        aggregated = self.fusion_conv(F_M)          # 单帧: 不做跨帧
        x = self.refine_blocks(aggregated)
        x = self.to_rgb_norm(x)
        Y_M = self.to_rgb(x)
        return {"Y_M": Y_M}
```

参数量 27.7K。`fusion_conv` 在单帧模式下是 1×1 卷积加归一化, 不做拼接。

### 8.4 三分支的共同结构

| 项 | 三者共有 |
|---|---|
| 主体 | 2 个 NAFBlock |
| 归一化 | N: 无; L: LayerNorm2d; M: LayerNorm2d (两处) |
| 激活 | LeakyReLU(0.01) (to_rgb), GELU (L 的 illum_head) |
| 末层 | 3×3 卷积出 3 通道, 无 clamp (N、M), clamp(0,1) (L) |
| 上采样 | 无 (at_f1=True) |

差异在各自的归纳偏置: N 有通道注意力, L 有 Retinex, M 在单帧模式下没有任何
跨帧模块。参数量都在 22 至 28K 之间, 与上游模块相比很小。

## 九、后续检查: L 路加宽与 Channel Mix 激活

### 9.1 L 路 NAFBlock 加宽 (dw_expand 2 → 3)

已实施: `models/golf_v7r/branch_l_simple.py` 的两个 NAFBlock 改为
`dw_expand=3, ffn_expand=3`。参数量从 22.1K 升到 31.7K (+43%), 其余不变。
前向正常, 输出形状不变。

理由: 三路的任务负载不同 (L 的目标量级 0.500, N 0.197, M 0.054), 同样的深度对 L
是欠载。加宽不改深度, 只让 L 的每层容量更大。

### 9.2 Channel Mix 换回经典形式的可行性

**结论: 不可行, 但原因不是 ReLU² 本身。**

实测 (GolfNet_v8, relu_sq 开关):

| 项 | 数值 |
|---|---|
| LayerNorm 后输入的负值占比 | 49.9% |
| ReLU 后非零占比 | 50.0% |
| 首步梯度 | 全部为零 (cm_r / cm_k / cm_v / cm_out) |
| 5 步后梯度 | cm_r 3.6e-5, cm_k 3.3e-4, cm_v 7.4e-4 |

首步梯度为零的直接原因不是 ReLU² 清零, 而是 `cm_out` 零初始化: `cm_out` 的输出
恒为 0, 上游梯度乘以零。这与 BranchM 的 GELU 死锁是同一类问题的不同表现:
ReLU² 在负半轴无梯度, 加上零初始化末层, 形成"双零"起点。

参考实现 (Restore-RWKV) 能用 ReLU², 是因为它的 `value` 层有 bias 且不是零初始化,
`key` 的输入来自 OmniShift 而不是 LayerNorm, 初始分布不集中在负半轴。我们的
`cm_out` 零初始化是设计好的恒等起点, 与 ReLU² 的负半轴无梯度叠加, 导致首步阻断。

因此: 换回经典形式在当前结构下不可行, 除非同时改掉 `cm_out` 的零初始化,
而那又会破坏我们已验证过的恒等起点。两个约束不能同时满足, 保留 LeakyReLU²。
