## 版本定位

v9 不以继续堆叠恢复模块为目标，而是在 v8.8-B 的有效结构上完成两件事：

1. 以 CoReg-QRB 检验 N/L/M 查询关系建模是否能够改善退化鲁棒性；
2. 重新界定 SGRF 的职责，使其成为严格服从 TSDR 固定顺序的轻量状态更新器。
3. 根据 CoReg 30ep 的角色终值，把交叉 RWKV 收敛为无 Spatial-Mix G 的 Core-QRB。

当前保留两个参照版本：

- **v8.8-B**：干净集指标、LPIPS 和效率参照；
- **v9 CoReg-QRB**：噪声鲁棒性和关系机制参照，也是 SGRFv10 的默认上游基线。

## 已锁定的设计约束

1. SGRF 融合顺序固定为 **N→L→M**，不学习顺序，也不做顺序消融。
2. 原始中心帧 `X_t` 只作为 N 阶段的显式修复锚点；L/M 只接收上一阶段状态。
3. SGRF 不新增暗区、频带、边缘、噪声图、光流置信度等手工特征。
4. 三分支统一输出相对当前状态的有符号 RGB 修正量。
5. Gate 只估计修正的空间接纳比例，不承担退化识别或颜色恢复。
6. 初版只监督最终输出，不构造不可观测的中间阶段标签。

## 命名说明

本文档从 v9 开始把本轮新设计统一称为 **SGRFv10**。当前代码中的
`models/golf_v7r/sgrf_v9.py::SGRFv9` 以及历史文档中偶尔出现的“SGRFv10”称呼，
统一视为 **legacy SGRFv9**，避免与本轮设计混淆。只有完成本文结构后，才应在代码中
新增真正的 `SGRFv10`。
