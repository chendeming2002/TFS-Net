# SGRFv10：TSDR 固定顺序下的轻量状态更新器

> 日期：2026-11-05
> 状态：设计与代码已完成，尚未进行 30 epoch 训练
> 默认上游：Core-QRB `current`
> 固定顺序：**N→L→M**

## 1. 设计结论

SGRFv10 的核心定位只有一句话：

> N/L/M 分支分别提出源特异的图像修正量，SGRF 按照 TSDR 规定的 N→L→M 顺序，
> 决定每个修正量在当前位置写入多少，并维护逐阶段恢复状态。

SGRF 是最终修复发生的图像状态载体，但不是第二套退化分析网络。它不重新识别噪声、
光照和运动，也不比较三个分支的高维特征。分支回答“改什么”，Gate 只回答“写入多少”，
SGRF 负责“按什么顺序写入”。

本设计不改变 TSDR 顺序，不引入动态路由、跨分支竞争、全局退化向量或额外手工先验。

## 2. 为什么需要重写当前 SGRF 接口

legacy SGRFv9 当前从零状态开始：

\[
x_0=0,
\qquad
x_k=x_{k-1}+a_k g_k\,\operatorname{bound}_k(Y_k).
\]

这个设计依赖“人工频带目标之和等于 GT”，因此把三路输出当成可加分量。但实际分支输出
已经出现三种不同语义：

- N 路在 legacy SGRFv9 中实际输出 `n_hat`（调用时未传 `X_t`），而在普通分支调用中又可输出
  `X_t - n_hat`，同一接口存在两种语义；
- L 路输出 Retinex 重建结果，是完整增强候选图；
- M 路输出 RGB 修正，更接近残差。

SGRF 因而不得不再用 `stage_amp`、逐段软限幅、N/M lift 和 Gate 中心正则补偿语义差异。
这些机制提高了工程复杂度，却没有来自 TSDR 的直接推导。

SGRFv10 首先修正接口，而不是继续扩大 Gate：

1. 图像恢复从观测中心帧开始，即 \(S_0=X_t\)；
2. 三分支统一输出相对于当前状态的有符号修正量 \(\Delta_k\)；
3. Gate 只对修正量做空间接纳；
4. 中间阶段不 clamp，避免截断级间梯度。

## 3. 职责边界

| 模块       | 唯一主要职责                 | 明确不负责              |
| -------- | ---------------------- | ------------------ |
| N/L/M 分支 | 从本路特征和当前图像状态预测 RGB 修正量 | 决定融合顺序、与其他分支竞争     |
| Gate     | 估计当前修正的空间接纳比例          | 生成修复内容、识别退化类型、恢复颜色 |
| SGRF     | 固定 N→L→M 更新图像状态        | 动态排序、重新提取退化特征、手工限幅 |
| 训练损失     | 监督最终恢复结果               | 构造不可观测的中间阶段伪标签     |

这一边界意味着 SGRFv10 不接收三路特征拼接、不接收 DPE 图、不接收频带、梯度、暗区或
光流置信度等额外输入。每一阶段只使用本阶段特征、上一阶段图像状态和本阶段修正量。

## 4. 总体结构

令三个上游任务特征为 \(F_N,F_L,F_M\)，中心帧为 \(X_t\)，恢复状态为 \(S_k\)。

### 4.1 初始状态

\[
S_0=X_t.
\]

这一步确定了 SGRF 是图像修复器而不是从零开始的图像合成器。

### 4.2 N：以原始观测为锚点去噪

\[
\Delta_N=B_N(F_N,S_0),
\]

\[
G_N=\sigma\!\left(\mathcal G([S_0,\Delta_N])\right),
\]

\[
S_N=S_0+G_N\odot\Delta_N.
\]

其中 \(S_0=X_t\)。这是唯一显式读取原始中心帧的阶段。若保留噪声预测形式，可令
\(\Delta_N=-\hat n\)，但 SGRF 接口只接收统一的 \(\Delta_N\)，不关心分支内部实现。

### 4.3 L：在去噪状态上校正光照

\[
\Delta_L=B_L(F_L,S_N),
\]

\[
G_L=\sigma\!\left(\mathcal G([S_N,\Delta_L])\right),
\]

\[
S_L=S_N+G_L\odot\Delta_L.
\]

L 不再直接读取原始 \(X_t\)，只读取 TSDR 链条自然产生的 \(S_N\)。若 L 分支内部继续采用
Retinex，可先得到候选 \(P_L\)，再统一转换为 \(\Delta_L=P_L-S_N\)。这属于接口换算，
SGRF 不额外构造照明图或暗区掩码。

### 4.4 M：在光照校正状态上修复运动影响

\[
\Delta_M=B_M(F_M,S_L),
\]

\[
G_M=\sigma\!\left(\mathcal G([S_L,\Delta_M])\right),
\]

\[
S_M=S_L+G_M\odot\Delta_M.
\]

M 只使用自己的 TCA 特征和上一阶段状态。运动信息由 \(F_M\) 表达，SGRF 不再重复输入
手工运动图或配准置信度。

### 4.5 输出

\[
\hat Y=S_M.
\]

训练图中不对 \(S_N,S_L,S_M\) 做 clamp。仅在推理输出、保存图像或计算要求合法动态范围的
指标时使用：

\[
Y_{\mathrm{eval}}=\operatorname{clamp}(\hat Y,0,1).
\]

## 5. Gate：只做修正接纳

### 5.1 输入选择

Gate 不再读取高维分支特征 \(F_k\)，而读取：

- 修正前的 RGB 状态 \(S_{k-1}\)；
- 分支提出的 RGB 修正量 \(\Delta_k\)。

这与 Gate 的问题完全一致：在当前图像内容下，这个修正应当写入多少？

不显式拼接 \(\Delta_k\) 的绝对值、梯度、频带或其他手工统计；小卷积可以直接从
\([S_{k-1},\Delta_k]\) 学习所需关系。

### 5.2 默认结构

```text
concat(state, delta)       [B, 6, H, W]
  -> Conv 3x3, 6 -> 8
  -> GELU
  -> Conv 1x1, 8 -> 1
  -> Sigmoid               [B, 1, H, W]
```

Gate 只输出单通道空间图，并广播到 RGB：

\[
G_k\in[0,1]^{B\times1\times H\times W}.
\]

RGB 修正方向和颜色由三通道 \(\Delta_k\) 决定；Gate 不应再通过三通道权重承担颜色恢复。

该网络约 449 个参数。默认 N/L/M 共享同一个 \(\mathcal G\)，因为三阶段执行的是同一种
“修正接纳”操作。共享 Gate 也能减少分支特异的自由度，使职责更容易解释。

只有在共享 Gate 明显限制性能时，才进行三个同构独立 Gate 的单变量对照；不在基础版本中
加入阶段编码、全局向量或跨分支输入。

### 5.3 初始化

- N/M 的最终残差头零初始化；L 的照明头末层和补偿卷积零初始化，使
  \(\Delta_N=\Delta_L=\Delta_M=0\)；
- Gate 最后一层权重与偏置零初始化，使初始 \(G_k=0.5\)；
- 因为初始修正量为零，整个模块严格满足 \(\hat Y=X_t\)。

分支先获得非零修正梯度，随后 Gate 才根据已经形成的修正学习空间接纳。无需另设阶段解锁、
幅度参数或 Gate 中心损失。

## 6. 从 legacy SGRFv9 删除的组件

SGRFv10 不包含：

1. `x = zeros_like(X_t)` 的零起点；
2. `proj_L/proj_M` 形式的 SGRF 内部状态特征注入；
3. `lift_N/lift_M` 阶段专属修正；
4. `delta_bound` 和 `tanh` 软限幅；
5. `stage_amp`；
6. 三通道、特征条件化的 StageGate；
7. 把 Gate 拉向 0.5 的饱和惩罚；
8. 中间阶段 clamp；
9. 顺序搜索和动态路由。

状态如何进入分支由统一分支接口 `branch(F_k, state)` 处理。实现时可在分支入口使用一个
可学习的 `Conv1x1(3,C)`，但不在 SGRF 内制造新的手工特征。

## 7. 损失函数

### 7.1 基础损失

SGRFv10 初版只监督最终输出：

\[
\mathcal L_{\mathrm{final}}
=
\lVert \hat Y-Y\rVert_1
+0.1\left(1-\operatorname{MS\text{-}SSIM}(\hat Y,Y)\right).
\]

保持现有训练代码的最终 L1 与 MS-SSIM 口径，避免在结构实验中同时引入 Charbonnier、
感知损失或频率损失。

### 7.2 明确删除的损失

初版设置：

```yaml
loss:
  w_branch_N: 0.0
  w_branch_L: 0.0
  w_branch_M: 0.0
  branch_specific_targets: false
  branch_target_normalize: false
  w_gate_reg: 0.0
  lambda_ortho: 0.0
  w_ssim: 0.1
```

删除理由如下：

- **频带分支目标**：它们是人为构造的可加频带，不是真实 N/L/M 中间恢复标签；
- **中间状态对 GT 的监督**：要求 N 阶段提前完成提亮和运动修复，会破坏 TSDR 分工；
- **Gate 中心正则**：Gate 接近 0 或 1 可能就是正确接纳决策，不应预设饱和为错误；
- **单调改善约束**：不可观测中间状态没有必要被手工规定为逐段接近最终 GT；
- **额外正交或频域约束**：不属于 SGRF 的主要任务，初版不引入。

最终损失通过三个加性状态更新直接回传。只要 Gate 不以接近零的偏置初始化，便不存在必须依靠
深监督解决的结构性梯度中断。

## 8. 诊断只记录，不进入损失

为了判断职责是否成立，每阶段记录：

\[
\operatorname{mean}(G_k),\quad
\operatorname{sat}(G_k),\quad
\lVert\Delta_k\rVert_1,\quad
\lVert G_k\odot\Delta_k\rVert_1.
\]

并保留 N/L/M 置零诊断。上述量只用于观察：

- Gate 是否真正根据空间位置变化；
- 分支是否提出非零修正；
- Gate 是否长期拒绝某个分支；
- 某阶段的实际写入量是否异常。

不对这些统计量设置阈值损失。出现异常时先归因分支输出和接口，再决定是否需要结构修改。

## 9. 实验顺序

所有实验固定 N→L→M，禁止把顺序作为变量。

### S0：残差接口基线

- \(S_0=X_t\)；
- 三分支统一输出 \(\Delta_k\)；
- 固定 \(G_k=1\)；
- 只使用最终 L1+SSIM；
- 不压缩分支。

目的：先验证“从观测图像递进修复 + 统一修正语义”本身是否成立。

### S1：共享单通道 Gate

在 S0 上只加入本文共享 Gate。若 S1 优于 S0，才能说明“修正接纳”是有价值的独立任务。

### 9.1 已实现配置

| 实验 | 配置 | 与另一组的唯一结构差异 |
|---|---|---|
| S0 | `configs/v9/v9_sgrfv10_s0_fixed_30ep.yaml` | `sgrf_v10_gate: fixed`，固定 \(G=1\) |
| S1 | `configs/v9/v9_sgrfv10_s1_shared_30ep.yaml` | `sgrf_v10_gate: shared`，增加一个共享 Gate |

S0/S1 除 `output_dir` 与 `sgrf_v10_gate` 外完全相同。二者均使用 Core-current 上游、
固定 N→L→M、原分支容量和最终 L1+0.1 MS-SSIM；不使用分支监督、正交损失或 Gate 正则。

### S2：独立 Gate 对照（条件实验）

仅当共享 Gate 的统计显示明显阶段冲突时，改为三个同构独立 Gate。除此之外不增加输入或约束。

### S3：三分支轻量化

在 S1/S2 中胜出的结构上，将每个分支的 NAFBlock 从 2 个减为 1 个。该实验后置，避免把
SGRF 接口收益与分支容量变化混在一起。

## 10. 对照与验收口径

| 对照 | PSNR | SSIM | LPIPS | 噪声 σ=0.05 | Latency |
|---|---:|---:|---:|---:|---:|
| v8.8-B | 26.05 | 0.8432 | 0.3426 | 14.70 | 50.9 ms |
| v9 CoReg | 26.01 | 0.8433 | 0.3504 | 16.52 | 53.4 ms |

SGRFv10 首轮成功标准：

1. SDSD PSNR/SSIM 不低于 v9 CoReg 的正常波动范围；
2. 不丢失 CoReg 在高噪声下获得的主要鲁棒性收益；
3. 三路均产生可测的非零写入量，且 M 置零代价不回退到不可用状态；
4. Gate 参数和延迟显著低于 legacy StageGate；
5. 训练不依赖频带分支目标、Gate 正则或阶段软限幅才能稳定。

## 11. 与推理瓶颈的关系

v9 profiling 显示 encoder 占 63.1%，TCA 占 26.0%，WKV 扫描核占全部 GPU 时间 51.2%；
SGRF/融合约 0.1 ms。SGRFv10 的首要目标因此是语义正确、职责清楚和参数精简，而不是宣称
它能够显著提升整网 FPS。

真正的推理加速应在独立路线中处理 WKV 通道组织、重复 LayerNorm 和逐元素算子融合，
不应通过削弱 SGRF 的 TSDR 状态链条来换取有限收益。

## 12. 文稿一致性

本版本固定使用以下描述：

> SGRF progressively updates the observed center frame in the fixed
> denoise → illumination correction → motion restoration order (N→L→M).

现有论文草稿中“denoise → deblur → brighten”（N→M→L）的表述与当前实现和本轮确认不一致，
后续修改论文时必须统一为 N→L→M；这属于文稿修正，不再安排顺序消融。

### 13.1 验证曲线

| 轮次 | PSNR | SSIM | LPIPS |
|:--:|:--:|:--:|:--:|
| 5 | 24.22 | 0.8119 | 0.3952 |
| 10 | 25.15 | 0.8228 | 0.3924 |
| 15 | 25.45 | 0.8288 | 0.3756 |
| 20 | 25.64 | 0.8306 | 0.3648 |
| 25 | 25.75 | 0.8319 | 0.3710 |
| 30 | **25.81** | 0.8344 | **0.3687** |

### 13.2 与基线对照

| 项 | CoReg | Core-QRB | **SGRF-S0** |
|---|---:|---:|---:|
| PSNR | 26.01 | 25.81 | 25.81 |
| SSIM | 0.8433 | 0.8390 | 0.8344 |
| LPIPS | 0.3504 | 0.3530 | 0.3687 |
| 加噪 σ=0.05 | 16.52 | 16.99 | 16.84 |
| Param (M) | 1.342 | 1.328 | **1.312** |
| Latency (ms) | 53.4 | 50.2 | **~49** |

S0 用最少的参数 (1.312M) 和无分支监督的纯最终损失, 达到与 Core-QRB 持平的
PSNR (25.81) 与相当的噪声鲁棒性 (16.84)。SSIM/LPIPS 略差。

### 13.3 S0 特有的诊断信号 (分支语义已变)

S0 的分支输出是 Δ (修正量), 不再是图像; 旧口径的"相对误差"不再可比
(N 的 4.7 / M 的 26.6 是修正量对频带目标的比值, 无参考意义)。
置零代价成为主要判据:

| 条件 | N | L | M |
|---|---:|---:|---:|
| 干净 | −4.02 | −13.43 | **−9.29** |

M 的置零代价从 SGRFv9 的 −0.17 升到 **−9.29 dB**: 接口统一后 M 首次成为
实质贡献者。压暗/加噪下 N 置零反而变好 (+1.8/+1.1) — N 在退化输入上
过度修正, 这正是 S1 的 Gate 应当学会抑制的模式。

### 13.4 S0 判定

按第 10 节标准:
1. PSNR/SSIM: 25.81 与 CoReg 26.01 差 0.20 dB, 在正常波动边缘 — 勉强通过;
2. 噪声鲁棒性 16.84, 未丢失 CoReg 收益 — 通过;
3. 三路均非零写入 (N/L/M 置零代价 −4.0/−13.4/−9.3) — 通过, 且 M 历史最佳;
4. Gate 参数 0 (S0 无 Gate) — 通过;
5. 不依赖频带目标/门控正则/软限幅 — 通过 (损失里全部为 0)。

**结论: S0 通过, 残差接口基线成立。"从 X_t 出发 + 统一 Δ 语义 + 纯最终损失"
本身可行。启动 S1 (共享单通道 Gate)。**
