# v7.5 实验验证计划

> 日期: 2026-10-14
> 模型设计见 `01-模型设计.md`
> 目标: 在最短时间内判定三分支融合能否定稿。**结果只要不太差劲即定稿**为 SGRF 的最终版。

## 一、总体安排

分两段, 每段只看关键指标。**不做完整 3v3 双臂对比** —— 本版本的目的不是证明某个改动带来
的指标提升 (本机方差 2.4–3.2 dB, 任何小效应都测不出), 而是确认三分支**已经形成分工**、
结构可用。

| 段 | 内容 | run 数 | 耗时 | 判据 |
|:--:|------|:--:|:--:|------|
| 1 | 基础配置 5ep 探针 | 1 | 6.8 h | 判据 1 / 3 |
| 2 | 关键结构变量扫描 5ep | 3 | 各 6.8 h | 判据 1 / 2 / 3 |
| 2' | **四个 run 的消融实验** | 4 次诊断 | 各约 30 min | 判据 4 |

总计约 28 h 训练 + 2 h 诊断。

**不设 40ep 训练段。** 本阶段的目标是给结构定稿、确认三路形成了分工, 5ep 的机制判据足以
回答这个问题; 40ep 只是把同一结论在更长训练下重复一遍, 不带来新的结构决策依据。
需要长训练的完整结果时再从 5ep 检查点续训。

## 三、第 2 段: 关键结构变量扫描

只扫**真正影响结构决策**的三个变量, 每个 5ep。全部基于第 1 段的配置, 单变量改动。

| 编号 | 变量 | 取值 | 想回答的问题 |
|:--:|------|------|--------------|
| S1 | 共享比例 $b$ (运动路占高频) | 0.2 → **0.5** | 高频在 M、N 之间是否需要更均匀的分摊 |
| S2 | 残差门 | 冻结 → **开启** | 残差门是否有助于收敛, 或只是掩盖问题 |
| S3 | 频带核 | 31/5 → **15/5** | 低频带过宽 (占 98% 能量) 是否压制了另两路 |

**S1 与 S3 只跑 5ep 并只看判据 2 (输出余弦) 与 1 (各带误差)**, 不比较 PSNR。

**S2 的意义**: 第 1 段冻结残差门是诊断性选择。S2 用来确认"冻结是否牺牲了实际收敛能力";
若 S2 的判据 1/3 明显更好且没有掩盖退化 (输出余弦仍低、三路 PSNR 都正常), 则允许在最终版
保留残差门。

**择优规则**: 综合判据 1/2/3, 选**三路分工最清晰且无退化**的一组作为定稿候选。
不按 PSNR 选 (方差过大)。该选择在第 2 段收尾的消融实验之后一并确认。

## 四、第 2 段收尾: 四个 run 的消融实验 (判据 4)

第 2 段的三个扫描 run 完成后**不再训练**, 直接对第 1 段与 S1/S2/S3 共四个 run 各做一次
消融, 用来确认"三路是否真的不可自由替代"。这是本次定稿唯一的判据 4 来源。

**为什么不再跑长训练**: 5ep 的机制判据已经足以判定分工是否形成。40ep 只是把同一结论在
更长训练下重复一遍, 不产生新的结构决策依据, 因此取消。

**为什么消融要覆盖全部四个 run**: 四个配置的差异就在频带划分方式与残差门上, 而这两者正好
影响"某路是否携带了大块直流分量"——判断据 4 数值的主要干扰。四个 run 一起看, 才能把
"分工"与"直流分量"区分开。

| run | 配置 | 预注册输出目录 |
|:--:|------|----------------|
| #1 | 第 1 段基础配置 (核 31/5, b=0.2, 门冻结) | `outputs/golf_v7r_v3_phaseF_band_targets/` |
| S1 | 运动路占高频 0.2 → 0.5 | `outputs/v7_5_scan/S1_share_high/` |
| S2 | 残差门冻结 → 开启 | `outputs/v7_5_scan/S2_gate_on/` |
| S3 | 低频截止核 31 → 15 | `outputs/v7_5_scan/S3_kernel_15_5/` |

**每个 run 跑两条命令**:

```bash
# 判据 1/2/3: 三路形态、输出余弦、单独 PSNR
PYTHONPATH=. python scripts/diag_v7r_v3_branches.py \
    --ckpt <run>/best.pth --config <run>/_cfg.yaml

# 判据 4: 去掉任一路后指标是否明显变差
PYTHONPATH=. python scripts/diag_v7r_v3_branch_ablation.py \
    --ckpt <run>/best.pth --config <run>/_cfg.yaml --n_seqs 24
```

本轮四个 run 的消融由 `scripts/run_v75_ablation.sh` 串行执行 (单卡须串行, 否则 OOM)。

**判据 4 的读法 (重要)**: 它单独看会被误导 —— 一个塌成常数的分支消融代价同样大。
只有当判据 1 (各带误差在降)、判据 2 (输出余弦低)、判据 3 (三路单独 PSNR 都正常) 同时成立时,
判据 4 的"去掉任一路明显变差"才能解释为分工。

## 五、定稿条件

四个 run 中任选其一 (或取综合最好者) 满足:

| # | 条件 |
|:--:|------|
| 1 | 三路与各自频带的误差随训练下降 |
| 2 | 三路输出余弦显著低于 0.99 |
| 3 | 三路单独 PSNR 都在合理区间, 无某路塌成常数 (空间标准差不为 0) |
| 4 | 消融: 去掉任一路后指标明显变差 |

即可定稿为 SGRF 最终版。**不要求最终 PSNR 超过任何历史配置** —— 本机 5ep 的 seed 间方差
达 2.4–3.2 dB, 该指标无法区分方案优劣。

## 七、明确不做的事

| 项 | 原因 |
|----|------|
| 完整 3v3 双臂对比 | 方差 2.4–3.2 dB 远超效应量, 测不出差异; 本阶段目标是定稿不是证明提升 |
| §6.6 极暗增广训练验证 | **与三分支结构决策无关**, 是大效应量场景的独立课题, 延后 |
| §6.9 感知损失训练验证 | 同上, 延后 |
| R2 position 重训 | 属评估协议问题, 不关系结构, 延后 |
| ε 权重下限消融 | 已由加性融合取代, 不再需要 |
| 输出层去相关项 | 已否定, 不再尝试 |

## 八、风险与应对

| 风险 | 应对 |
|------|------|
| 第 1 段三路中仍有一路塌缩 | 优先查共享比例 (该路的频带是否太窄); 若 $S_N$ 或 $S_M$ 的幅度仍远低于 $S_L$, 调 $k_1$ |
| 加性融合导致输出整体偏亮/偏暗 | 检查 `refine` 卷积是否退化为缩放; 必要时给 $w_k$ 加一个更紧的初始化范围 |
| 训练不收敛 (损失震荡) | 分支权重 0.3 降到 0.15; 或把按频带归一化关掉做对照 |
| 四个 run 的分工都不清晰 | 转结构级分工: 加性顺序级联 (去噪 → 去模糊 → 提亮), 把顺序写进网络连通性 |
