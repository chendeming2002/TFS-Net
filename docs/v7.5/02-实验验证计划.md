# v7.5 实验验证计划

> 日期: 2026-10-14
> 模型设计见 `01-模型设计.md`
> 目标: 在最短时间内判定三分支融合能否定稿。**结果只要不太差劲即定稿**为 SGRF 的最终版。

## 一、总体安排

分三段, 每段只看关键指标, 段间设明确的继续/调整判据。**不做完整 3v3 双臂对比** ——
本版本的目的不是证明某个改动带来的指标提升 (本机方差 2.4–3.2 dB, 任何小效应都测不出),
而是确认三分支**已经形成分工**、结构可用。

| 段 | 内容 | run 数 | 单个耗时 | 判据 |
|:--:|------|:--:|:--:|------|
| 1 | 基础配置 5ep 探针 | 1 | 6.8 h | 判据 1 / 3 |
| 2 | 关键结构变量扫描 5ep | 3 | 各 6.8 h | 判据 1 / 2 / 3, 择优 |
| 3 | 最优配置 40ep | 1 | 41 h | 判据 1 / 2 / 3 / 4 |

总计约 69 h (约 3 天)。**正在运行的 Phase F 探针即第 1 段, 无需重复启动。**

## 二、第 1 段: 基础配置探针 (运行中)

**配置**: `configs/golf_v7r_v3_phaseF_band_targets.yaml`
- 频带核 $k_1 = 31$, $k_2 = 5$
- 共享比例 $a = 0.5$ (运动路占中频), $b = 0.2$ (运动路占高频)
- 融合 `additive`, 残差门**冻结**
- 分支权重 0.3, 按频带归一化

**启动**: 2026-10-14 16:12, pid 770236, 输出 `outputs/golf_v7r_v3_phaseF_band_targets/`

**这一段的检查命令** (跑完后执行):

```bash
# 判据 1 与 3: 三路输出形态、单独 PSNR、输出余弦
PYTHONPATH=. python scripts/diag_v7r_v3_branches.py \
    --ckpt outputs/golf_v7r_v3_phaseF_band_targets/best.pth \

```

**继续条件 (宽松)**: 三路单独 PSNR 都落在合理区间、**没有任何一路塌成常数图**
(常数图的标志: 空间标准差接近 0)。这是硬性底线——塌陷意味着分区没有生效。

**不达标时的调整顺序**:
1. 调共享比例 (第 2 段的内容提前);
2. 调频带核 $k_1$/$k_2$;
3. 检查分支权重 0.3 是否过高或过低。

## 三、第 2 段: 关键结构变量扫描

只扫**真正影响结构决策**的三个变量, 每个 5ep。全部基于第 1 段的配置, 单变量改动。

| 编号 | 变量 | 取值 | 想回答的问题 |
|:--:|------|------|--------------|
| S1 | 共享比例 $b$ (运动路占高频) | 0.2 → **0.5** | 高频在 M、N 之间是否需要更均匀的分摊 |
| S2 | 残差门 | 冻结 → **开启** | 残差门是否有助于收敛, 或只是掩盖问题 |
| S3 | 频带核 | 31/5 → **15/5** | 低频带过宽 (占 98% 能量) 是否压制了另两路 |

**S1 与 S3 只跑 5ep 并只看判据 2 (输出余弦) 与 1 (各带误差)**, 不比较 PSNR。

**S2 的意义**: 第 1 段冻结残差门是诊断性选择。S2 用来确认"冻结是否牺牲了实际收敛能力";
若 S2 的判据 1/3 明显更好且没有掩盖退化 (输出余弦仍低、三路 PSNR 都正常), 则允许在最终版
保留残差门。

**择优规则**: 综合判据 1/2/3, 选**三路分工最清晰且无退化**的一组进入第 3 段。
不按 PSNR 选 (方差过大)。

## 四、第 3 段: 最优配置 40ep

用第 2 段选出的配置跑 40 epoch, 约 41 h。

**为什么要 40ep 而不是 60ep**: 40ep 足以让分工稳定下来并给出可用的最终模型, 而 60ep 会
多花约 20 h。本阶段的目的是"给结构定稿", 不是刷指标。若最终需要 60ep 的完整结果, 可从
40ep 的检查点续训。

**这一段的四条判据全部要跑** (含消融):

```bash
# 判据 1/2/3: 三路形态、输出余弦、单独 PSNR
PYTHONPATH=. python scripts/diag_v7r_v3_branches.py \
    --ckpt <最优配置>/best.pth --config <最优配置>/_cfg.yaml

# 判据 4: 去掉任一路后指标是否明显变差
PYTHONPATH=. python scripts/diag_v7r_v3_branch_ablation.py \
    --ckpt <最优配置>/best.pth --config <最优配置>/_cfg.yaml --n_seqs 24
```

**判据 4 的读法 (重要)**: 它单独看会被误导——一个塌成常数的分支消融代价同样大。
只有当判据 1 (各带误差在降)、判据 2 (输出余弦低)、判据 3 (三路单独 PSNR 都正常) 同时成立时,
判据 4 的"去掉任一路明显变差"才能解释为分工。

**定稿条件**: 判据 1、2、3 成立, 且判据 4 显示三路不可自由替代。**不要求最终 PSNR 超过
任何历史配置** —— 本机 5ep 的 seed 间方差达 2.4–3.2 dB, 该指标无法区分方案优劣。

## 五、判据定义

| # | 判据 | 达标线 | 工具 |
|:--:|------|--------|------|
| 1 | 三路与各自频带的误差 | 随训练下降 | 训练日志 + 分支诊断 |
| 2 | 三路输出余弦 | 显著低于 0.99 | `diag_v7r_v3_branches.py` |
| 3 | 三路单独 PSNR | 都在合理区间, 无常数图 | 同上 (看空间标准差) |

**改进前的基线读数** (供对照):
- 三路输出余弦 0.996–0.999;
- 消融去掉 L 路 +0.111 dB、20 好 / 4 差 (即三路可自由替代, 无分工可言)。

## 六、明确不做的事

| 项 | 原因 |
|----|------|
| 完整 3v3 双臂对比 | 方差 2.4–3.2 dB 远超效应量, 测不出差异; 本阶段目标是定稿不是证明提升 |
| §6.6 极暗增广训练验证 | **与三分支结构决策无关**, 是大效应量场景的独立课题, 延后 |
| §6.9 感知损失训练验证 | 同上, 延后 |
| R2 position 重训 | 属评估协议问题, 不关系结构, 延后 |
| ε 权重下限消融 | 已由加性融合取代, 不再需要 |
| 输出层去相关项 | 已否定, 不再尝试 |

## 七、风险与应对

| 风险 | 应对 |
|------|------|
| 第 1 段三路中仍有一路塌缩 | 优先查共享比例 (该路的频带是否太窄); 若 $S_N$ 或 $S_M$ 的幅度仍远低于 $S_L$, 调 $k_1$ |
| 加性融合导致输出整体偏亮/偏暗 | 检查 `refine` 卷积是否退化为缩放; 必要时给 $w_k$ 加一个更紧的初始化范围 |
| 训练不收敛 (损失震荡) | 分支权重 0.3 降到 0.15; 或把按频带归一化关掉做对照 |
| 40ep 后分工仍不清晰 | 转结构级分工: 加性顺序级联 (去噪 → 去模糊 → 提亮), 把顺序写进网络连通性 |
