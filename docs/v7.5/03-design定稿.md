## 二、核心结论: 加性融合 + 频带划分成功, 但 BranchM 未参与

### 2.1 判据 2 (输出余弦): 大幅改善

三路输出余弦从改进前的 0.996–0.999 降到:

| run | N-L | N-M | L-M |
|:--:|:--:|:--:|:--:|
| stage1 | 0.047–0.088 | 0.002–0.009 | **0.005–0.061** |
| S1 | 0.054–0.102 | 0.001–0.007 | 0.558–0.595 |
| S2 | 0.033–0.056 | 0.005–0.009 | 0.390–0.415 |
| S3 | 0.037–0.067 | 0.010–0.012 | 0.770–0.830 |

stage1 的三对余弦全部低于 0.09, 是四者中分化最彻底的。该判据**达标**。

### 2.2 判据 4 (消融): 三路均不可替代

| run | 去掉 N | 去掉 L | 去掉 M |
|:--:|:--:|:--:|:--:|
| stage1 | −6.008 dB (22/24 差) | −15.576 dB (24/24) | −10.706 dB (24/24) |
| S1 | −6.790 dB (23/24) | −15.390 dB (24/24) | −10.810 dB (24/24) |
| S2 | −7.118 dB (23/24) | −14.601 dB (24/24) | −9.998 dB (24/24) |
| S3 | −13.971 dB (24/24) | −14.862 dB (24/24) | −7.232 dB (23/24) |

对比改进前的基线读数: 去掉 L 路 **+0.111 dB**、20 好 / 4 差 (即三路可自由替代)。
现在去掉任意一路都掉 6–15 dB, 该判据**达标**。

### 2.3 判据 3 (三路单独有效): BranchM 不达标

这是本轮唯一未通过的判据, 且四个 run 全部如此。

| run | branch_N std | branch_L std | **branch_M std** |
|:--:|:--:|:--:|:--:|
| stage1 | 0.0289 | 0.2199 | **0.0001** |
| S1 | 0.0271 | 0.2209 | **0.0001** |
| S2 | 0.0280 | 0.2193 | **0.0001** |
| S3 | 0.0153 | 0.2391 | **0.0001** |

BranchM 的输出是常数图。其归一化分支损失恰好等于 **1.000**, 而"输出全零"时该值正是 1.000
—— 即 M 路**什么都没学到**。对照 N 路 0.545、L 路 0.067, 两者都在正常学习。

**判据 4 因此不能解释为完整的三路分工**: 去掉 M 路掉 10 dB, 但那不是因为它学到了运动,
而是因为它输出的常数被加性融合计入了总和, 拿掉就丢失了一块直流分量。这正是实验计划
预先警告过的误读方式 —— 判据 4 必须与判据 3 一起读。

## 三、BranchM 失效的根因: GELU 死亡

### 3.1 逐层追踪

在 stage1 的 BranchM 内部逐层测量激活:

| 层 | std | absmean | max | min |
|------|:--:|:--:|:--:|:--:|
| refine_blocks 输出 | 1.844 | 1.339 | +6.493 | −6.025 |
| upsample 输出 | 28.57 | 22.99 | +90.82 | −64.87 |
| to_rgb 第一层卷积 | 54.14 | 148.9 | **−6.483** | −343.1 |
| to_rgb 的 GELU | **0.000** | **0.000** | −0.000 | −0.000 |
| Y_M | 0.0001 | — | — | — |

GELU 的输入**全部为负** (最大值 −6.483, 正值占比 0.0%), 因此输出恒为零。
零输出使得其后的末层卷积**权重梯度恒为 0**, 实测:

```
branch_M.to_rgb.2.weight   |w|=2.274e-02   |grad|=0.000e+00
branch_M.to_rgb.2.bias     |w|=1.006e-04   |grad|=6.666e-01
```

只有 bias 还能收到梯度, 所以 Y_M 退化为一个由 bias 决定的常数图。

### 3.2 为什么只有 M 路出问题

三路的 `to_rgb` 结构完全相同 (`Conv(64→32) → GELU → Conv(32→3)`), 差别在它的**输入尺度**:

| 分支 | upsample 输出 std | upsample 输出 absmean | to_rgb 首层输出 max | 正值占比 |
|------|:--:|:--:|:--:|:--:|
| BranchN | 0.012 | 0.007 | +0.324 | 50.2% |
| BranchM | **28.570** | **22.990** | **−6.483** | **0.0%** |

BranchM 上采样输出的尺度是 BranchN 的 **2400 倍**。首层卷积的权重与偏置都在正常范围
(|W|≈0.022, bias ∈ [−0.069, +0.014]), 问题出在输入幅度太大 —— 卷积输出被推到 −148.9 的
均值, 远离 GELU 的激活区。

**上游原因**: BranchM 的 `_align_and_aggregate` 把中心帧特征与两个 `warped × conf` 拼接后过
`fusion_conv`, 再经 `refine_blocks` 与 `upsample`。这条通路没有任何归一化约束输出尺度,
而 BranchN 的输入 `F_N` 来自 TripleQueryTCA 的 `out_norm_N` (LayerNorm2d), 尺度被约束住。

### 3.3 四个 run 全部复现

| run | to_rgb 首层输出 max | GELU 是否死 | Y_M std |
|:--:|:--:|:--:|:--:|
| stage1 | −6.483 | 是 | 0.00011 |
| S1 | −9.976 | 是 | 0.00010 |
| S2 | −5.186 | 是 | 0.00012 |
| S3 | −10.110 | 是 | 0.00013 |

这是一个与本轮改动无关的**既有实现缺陷** —— 频带划分与加性融合只是让它第一次暴露出来。
此前 M 路也在输出常数, 但共享监督目标下三路输出本来就近乎相同, 这个问题被掩盖了。

## 四、定稿选择: stage1 基准配置

### 4.1 选择依据

| 判据 | stage1 | S1 | S2 | S3 |
|------|:--:|:--:|:--:|:--:|
| 2. L-M 输出余弦 | **0.005–0.061** | 0.558–0.595 | 0.390–0.415 | 0.770–0.830 |
| 4. 三路消融均衡性 | −6.0 / −15.6 / −10.7 | −6.8 / −15.4 / −10.8 | −7.1 / −14.6 / −10.0 | −14.0 / −14.9 / −7.2 |
| 残差门 tanh(γ) | **0.0 (冻结)** | 0.0 | 0.379 | 0.0 |
| PSNR | 24.55 | 24.11 | 23.97 | 23.22 |

三条理由:

1. **分化最彻底**。stage1 的 L-M 余弦在 0.005–0.061, 其余三者都在 0.39 以上, S3 甚至
   达到 0.83。提高高频共享比例 (S1) 或缩小低频截止核 (S3) 都让 L 与 M 的输出变得更像,
   与分工的目标相反。
2. **残差门应当保持冻结**。S2 开启残差门后 tanh(γ) 长到 0.379, 即最终输出有近四成直接来自
   输入中心帧, 而 L-M 余弦同时从 0.005 升到 0.39 —— 残差通路确实会掩盖分支层的问题,
   冻结是正确的选择。
3. **S3 的频带失衡**。核 31 → 15 后低频带变窄, 消融显示去 N 路的代价 (−13.97 dB) 变得和
   去 L 路 (−14.86 dB) 几乎相同, 三路职责反而混在一起。

### 4.2 定稿配置

`configs/golf_v7r_v3_phaseF_band_targets.yaml`, 检查点
`outputs/golf_v7r_v3_phaseF_band_targets/best.pth`。

| 项 | 值 |
|------|------|
| 融合模式 | `additive` (加性加权, 权重 softplus 不归一化) |
| 中心帧残差门 | 冻结为 0 |
| 频带核 | $k_1 = 31$, $k_2 = 5$ |
| 高频共享比例 | $a = 0.5$ (中频), $b = 0.2$ (高频) |
| 分支权重 | 0.3, 按频带归一化 |

## 五、已确立的结论

| # | 结论 | 证据 |
|:--:|------|------|
| 1 | **加性融合是频带划分目标的正确配套** | 零初始化时三路之和精确还原 GT (误差 6e-8); 凸组合会差 3 倍 |
| 2 | **频带划分成功建立了 N 与 L 的分工** | 输出余弦从 0.996–0.999 降到 0.047–0.088; 两路的分支损失都在下降 (N: 0.545, L: 0.067) |
| 3 | **残差门必须冻结** | 开启后 tanh(γ)=0.379, L-M 余弦同时从 0.005 升到 0.39 |
| 4 | **低频截止核 31 优于 15** | 核 15 时 L-M 余弦升到 0.83, 三路职责混淆 |
| 5 | **高频共享比例 0.2 优于 0.5** | b=0.5 时 L-M 余弦从 0.005 升到 0.56 |
| 6 | **BranchM 存在既有实现缺陷** | 四个 run 的 GELU 全部死亡, 与本轮改动无关 |
| 7 | 判据 4 必须与判据 3 一起读 | 去掉 M 路掉 10 dB, 但 M 路实际什么都没学到 |

## 六、BranchM 的修复方向 (下一步)

缺陷已定位到具体位置: `models/golf_v7r/branch_m_simple.py` 的 `to_rgb` 之前缺少尺度约束。
三个候选, 按改动量排序:

| 方案 | 改动 | 评估 |
|------|------|------|
| A | 在 `upsample` 之后、`to_rgb` 之前插入 `LayerNorm2d(64)` | 最小改动, 与 TCA 的 `out_norm_*` 做法一致 |
| B | 给 `fusion_conv` 之后补归一化 (该处已有 LayerNorm2d, 需查为何未生效) | 需先确认归一化后的尺度为何在 refine/upsample 后放大了 20 倍 |
| C | 把 `to_rgb` 的 GELU 换成 LeakyReLU 或 GELU 前加 BatchNorm | 治标; 不解决尺度失配本身 |

**这三条不能靠零成本的单次前向来筛选。** 我实测过方案 A: 在 `upsample` 与 `to_rgb` 之间插入
`LayerNorm2d(64)` 后重跑前向, `Y_M` 的 std 从 0.0001 升到 0.0059 (略有改善), 但 `to_rgb`
首层输出的正值占比仍是 **0.0%**, GELU 依然死亡。

原因是 M 路的 `to_rgb` 权重**从未收到过梯度** (实测 |grad| = 0), 它们停留在初始化附近的
随机取值上。用这样的权重配上任何输入, 卷积输出都可能整体偏负。也就是说: **当前检查点无法
用来判断某个修复方案是否有效**, 因为它本身的故障部分从来没有被学习过。

因此修复必须通过重训验证, 判断标准是训练后判据 3 是否达标 (Y_M 的空间标准差回到
0.01 以上、归一化分支损失明显低于 1.000)。方案 A 仍是最小改动的候选, 但它的有效性只能由
训练结果回答。

**这个修复不改变本文档的定稿选择** —— 加性融合、频带划分、残差门冻结、核 31/5、共享比例
0.2 这五项结论都已由实验确立。M 路修复后应在同一配置上复测判据 3, 若达标则三路分工完整。

## 七、与 TSDR 理论的关系

本轮未改动 TSDR 的任何论断。频带划分是实现层面的对应关系, 依据是文档中已有的物理描述:
光照低频主导、运动表现为结构边界 (中高频)、噪声全频段且高频显著。

三分支结构保留。本轮首次证明了**三路可以形成真实分工** (N 与 L 已经分开,
输出余弦从 0.998 降到 0.05), 这是此前四轮实验都没有达到的。M 路的问题是实现缺陷,
不是结构问题。

## 八、后续实测对本章结论的两处更正 (2026-10-16)

BranchM 的修复与"对齐残差"目标都已在 v8 阶段实现并各跑了一轮 5 epoch, 结果是
本章的结论 6、7 需要更正。记录在 `../v8/01-设计.md` §六·补, 此处只列要点。

第一, **本章结论 2 需要收窄**。当时用"输出余弦从 0.998 降到 0.05"判定 N 与 L 建立了分工,
这个判据不充分。后续在**相同的融合口径**下重测三路输出的空间方差, 发现 N 与 M 两路都接近常数图
(N 的空间方差 7.6e-04), 去掉它们中任意一路, 最终 PSNR 的变化只有十分之一 dB 量级;
真正承担恢复的只有 L 路 (去掉它掉 12 dB)。余弦低只说明"三路输出不像", 不等于"三路都在出力"。
**判据 4 (消融) 的旧数字同样不可用**: 当时的消融把加性融合的权重做了归一化, 使剩余两路被放大,
制造出约 10 dB 的假衰减; 用加性融合的正确口径 (直接置零) 重算, 常数分支的消融代价接近零。

第二, **本章结论 6 描述的"GELU 死亡"是现象, 不是根因**。修复后 (BranchM 的 `to_rgb` 前插入
`LayerNorm2d`、激活换成 LeakyReLU) M 路在训练日志里的输出幅度确实回升了一个量级,
但改用空间方差与消融口径复核, M 路的输出仍是常数图, 对最终结果没有贡献。
根因是**M 路的目标与 N 路重叠, 融合损失不需要它** (v7.5 频带划分里两路共享中频, 实测
corr = +0.93); 本轮把 M 路目标改成"对齐残差" (v8 的 b 方案) 后相关性降到 0, 但两路一起
塌成了常数图。原因见 v8 文档: 残差目标没有直流分量, 在按带归一化的损失下, "输出常数 0"
几乎就是该目标的最优解, 该路因此失去学习动力。

**对三分支结论的影响**: "三路可以形成真实分工"这句话目前只对 N 与 L 成立, 且还需要用
"消融代价"而不是"输出余弦"来确认。M 路要真正参与, 必须让它的目标含有另外两路无法提供的成分
(例如明显的直流分量或低频结构), 而不是一块零均值的高频残差。这一条留待 v8 继续。
