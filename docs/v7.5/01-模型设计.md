# v7.5 模型设计: 三分支融合定稿 (SGRF)

> 日期: 2026-10-14
> 前置文档: `../v7/03-v7r-v3-design.md` (全部实验与裁决)、`../v7/04-model-architecture.md` (结构总览)
> 本版本目标: 给三分支融合部分定稿, 作为 **Stage-wise Guided Restoration and Fusion (SGRF)** 的最终版
> 实验计划见 `02-实验验证计划.md`

## 一、本版本要解决的问题

三个分支都输出 RGB 图, 由融合层加权合成最终结果。长期以来三路没有形成分工: 它们都对同一张
GT 做 L1 回归, 因此 `Y_N = Y_L = Y_M = GT` 就是该目标的全局最优解——输出相同不是缺陷,
而是这个目标的正确答案。实测三路输出余弦 0.996–0.999, 且去掉任意一路后最终指标几乎不变。

四条补救路线均已在 `../v7/03` 中训练验证并否定: 输出层去相关项 (两 seed 退化)、
融合算子权重下限 (结构有效但无功能收益)、调整 LayerScale 初始化 (曲线非单调, 训练主动
选择高余弦)、用输入片段构造三个目标 (三目标实际重合, 比共享目标差 1.828 dB)。

**本版本的做法: 让三路各自负责 GT 的一个频带, 并把融合算子从加权平均改为加权求和。**

## 二、三分支各自的职责

设 `GT` 为真值, `P / Q / R` 为低 / 中 / 高频带:

$$P = \mathrm{LPF}_{k_1}(GT),\quad Q = \mathrm{LPF}_{k_2}(GT) - P,\quad R = GT - \mathrm{LPF}_{k_2}(GT)$$

其中 $k_1 = 31$、$k_2 = 5$ (均为奇数核), 由构造 $P + Q + R \equiv GT$。

三个分支的监督目标:

$$S_L = P,\qquad S_M = a\,Q + b\,R,\qquad S_N = (1-a)Q + (1-b)R$$

$P + Q + R \equiv GT$ 保证 $\sum_k S_k \equiv GT$, 与 $a$、$b$ 的取值无关。

| 分支 | 监督目标 | 频带占用 | 物理含义 (与 TSDR 对齐) |
|------|----------|----------|------------------------|
| BranchL | $S_L = P$ | 纯低频 | 光照: 慢变、全局分布、低频主导 |
| BranchM | $S_M = aQ + bR$ | 中频为主, 含部分高频 | 运动: 位移表现为结构边界, 属中高频 |
| BranchN | $S_N = (1-a)Q + (1-b)R$ | 覆盖中频到高频 | 成像噪声: 全频段存在, 高频最显著 |

默认 $a = 0.5$、$b = 0.2$, 即 BranchN 承担高频的 80% 与中频的 50%, BranchM 承担中频的
50% 与高频的 20%。

**为什么中频和高频由两路共享, 而不是各占一个频带。** 三个退化源对频带的占用本来就不互斥:
光照是低频的、全局的、慢变的; 运动表现为物体边界的位移, 边界处在中高频; 而加性噪声是
全频段存在的, 只是高频更显著。若把 BranchN 限制在最细高频 ($S_N = R$), 它在真实数据上的
幅度远低于低频带, 该路等于拿到一张空图, 学不到"去噪"——这与 TSDR 中"噪声全频段但高频
显著"的描述直接矛盾。按比例分摊既保留了物理上的重叠, 又让两路都能获得可学习的内容。

$a$ 与 $b$ 是共享比例的调节旋钮, 也是实验计划中要扫描的对象。

## 三、融合算子: 加性加权 (SGRF)

$$O_t = \mathrm{refine}\Big(\sum_k w_k \odot Y_k\Big),\qquad
w_k = \mathrm{softplus}(\mathrm{logit}_k + \ln(e-1))$$

其中 $\mathrm{logit}_k$ 由一个小卷积网络从 $[Y_N, Y_L, Y_M, X_{\text{center}}]$ 四路拼接预测,
`refine` 是一个恒等初始化的 3×3 卷积。

**为什么必须是加性求和, 而不是加权平均。** 三路目标满足 $\sum_k S_k = GT$, 这是**求和**
性质; 而 softmax 凸组合 ($\sum_k w_k = 1$) 给出的是**加权平均**。两者放在一起相差一个
3 倍因子:

| 量 | 实测值 |
|------|:--:|
| 三路都完美拟合时的 $\sum_k S_k$ | = GT (均值 0.6886) |
| softmax 等权融合输出 | **0.2295 = GT/3** |
| additive 融合输出 | 0.6886 = GT |

也就是说, 凸组合永远只能还原 GT 的三分之一。因此本版本采用加性加权。

**加性融合的三条性质。**

1. **初始化即正确**: 末层零初始化使得 $\mathrm{softplus}(\ln(e-1)) = 1$, 权重 $w_k = 1$,
   于是 $O_t = \sum_k Y_k$。三路都拟合到各自目标时, 初始输出就等于 GT (实测最大误差 6e-8)。
   融合层从一个正确的解出发, 不需要靠残差通路兜底。
2. **权重恒正**: softplus 严格大于零, 任何一路的权重都无法被压到零。这替代了此前尝试过的
   权重下限方案 (那个方案结构上有效但无功能收益, 见 `../v7/03` §6.16)。
3. **分区本身即抗塌缩机制**: 若某一路塌缩, 它负责的那一段频带在输出中就缺失了, 误差陡增,
   梯度会把这一路推回来。梯度 $\partial O_t / \partial Y_k = w_k$ 与其他路不耦合, 不存在
   "竞争挤出"的正反馈。

**中心帧残差门。** 历史上融合层还带一个中心帧残差 $\tanh(\gamma) \cdot X_{\text{center}}$,
实测 $\tanh(\gamma)$ 会长到 0.47–0.60, 即最终输出有近一半直接来自输入中心帧。这会掩盖
三分支的问题 (退化分支正是因此"最终 PSNR 看不出异常")。本版本默认冻结该门
(`fusion_residual_freeze=true`), 使融合输出必须由三分支自己承担, 任何退化都会立刻暴露。
这是诊断性的设计取舍, 不是性能优化; 该门是否保留也是实验计划中的扫描对象。

## 四、损失函数

$$\mathcal{L} = \underbrace{\|O_t - X_t\|_1}_{\text{融合输出}} +
\sum_{k} w_k^{b} \underbrace{\frac{\|Y_k - S_k\|_1}{\overline{|S_k|}}}_{\text{各分支对自己频带}} +
\lambda_o \underbrace{\mathcal{L}_{\text{ortho}}(F_N, F_L, F_M)}_{\text{特征层正交}}$$

对融合输出的监督保持原样 ($\ell_1$)。分支监督做了两处调整:

- **按频带归一化** ($\overline{|S_k|}$ 是该带自身的平均绝对值)。三个频带的幅度相差约 30 倍
  (实测 $L \approx 0.70$, $M \approx 0.032$, $N \approx 0.118$), 直接相加会让低频路独占分支
  梯度。除以自身尺度后三路贡献可比, 实测归一化前后的损失比值从 11.7 变为 1.000。
- **分支权重 $w_k^b = 0.3$**, 高于历史的 0.1。此前三路共享目标时分支损失与主损失方向一致,
  0.1 就足够; 现在各路有专属目标, 需要更强的信号才能对抗"把提亮全部推给融合层"的捷径。

不引入的项: 输出层去相关项 (已否定)、权重下限 (已证无功能收益)。

## 八、与 TSDR 理论的一致性

本版本未改动 TSDR 的任何论断: 三源分解 (光照 / 成像噪声 / 运动)、它们的时空统计差异、
三源不可再合并的论证、ISPN / NDPN / MCPN 的分工, 全部保留。

新增的只是**一个实现层面的对应关系**: 三个源在频域上的主导区间不同 (光照低频、运动边界
中高频、噪声全频段且高频显著), 因此可以用 GT 的频带划分作为监督目标。这与文档既有的物理
描述一致, 只是把这些描述用作监督信号的构造依据。

## 九、定稿判据

本版本一旦通过实验计划的验证, 即作为 **SGRF 的最终版**定稿。验证标准不是"最终 PSNR 是否
更高"(本机 5 epoch 训练的 seed 间方差实测达 2.4–3.2 dB, 远超任何可能的效应量), 而是四条
机制判据:

| # | 判据 | 达标线 |
|:--:|------|--------|
| 1 | 三路与各自频带的误差随训练下降 | 确认每路在学该学的东西 |
| 2 | 三路输出余弦 | 显著低于 0.99 |
| 3 | 三路单独 PSNR | 都在合理区间, 无某路塌成常数 |
| 4 | 消融: 去掉任一路后指标 | 明显变差 |

四条必须一起读: 判据 4 单独看会被误导——一个塌成常数的分支消融代价同样大。
