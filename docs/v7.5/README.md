## 一句话概括本版本

三个分支不再对同一张 GT 回归, 而是**各自负责 GT 的一个频带** (低频归光照路、中高频由
运动路与噪声路按比例共享), 融合算子从**加权平均**改为**加权求和**, 使初始化时三路之和
即精确还原 GT。

依据: 共享目标下 `Y_N = Y_L = Y_M = GT` 是全局最优解, 三路同质化不是缺陷而是该目标的正确
答案; 四条补救路线 (输出层去相关、权重下限、调 LayerScale、用输入片段构造目标) 均已训练
验证并否定, 详见 `../v7/03-v7r-v3-design.md`。

## 定稿条件

四条机制判据中, 判据 1 (各带误差下降) / 2 (输出余弦低) / 3 (三路单独 PSNR 正常且无常数图)
成立, 且判据 4 (消融去掉任一路明显变差) 显示三路不可自由替代。

**不要求最终 PSNR 超过任何历史配置** —— 本机 5ep 训练的 seed 间方差达 2.4–3.2 dB,
该指标无法区分方案优劣。结果只要不太差劲即定稿。
