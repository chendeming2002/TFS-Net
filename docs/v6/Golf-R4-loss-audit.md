## 二、三项根因（独立缺陷）

### 缺陷 1：`L_prior` 平方发散（主因）

**证据**：

| epoch | total | final | **L_prior** | λ·L_prior |
|-------|-------|-------|-------------|-----------|
| 1 | 0.517 | 0.244 | 1.15 | 0.012 |
| 2 | 0.455 | 0.202 | 1.70 | 0.017 |
| 3 | 1.916 | 0.196 | **152.4** | 1.52 |
| 4 | 6.242 | 0.193 | **587.0** | 5.87 |

**机制**（尺度不变性测试）：

| prior 项 | 公式 | 缩放律 | 危险性 |
|---------|------|:---:|------|
| prior_N | `F.mse_loss(feat, src)` | **k²** | 平方爆炸（10×→100×）|
| prior_L | 空间 TV | k¹ | 线性增长 |
| prior_M | L1(diff_proj) | k⁰ | 安全 |

**正反馈环**：`L_ortho` 等项把特征量级推大 → `MSE` 随量级平方增长 → `L_prior` 爆炸 → 梯度更大 → 量级继续膨胀。

**修复**（全部改为尺度不变 k⁰）：
```python
# prior_N: MSE → 余弦相似度
cos = F.cosine_similarity(feat.flatten(1), src.detach().flatten(1), dim=1, eps=1e-6)
prior_loss = (1.0 - cos).mean()          # ∈ [0,2], 尺度不变

# prior_L: TV → 归一化 TV (rms detach)
prior_loss = (gx + gy) / (feat.pow(2).mean().sqrt().detach() + 1e-6)

# prior_M: L1 → L1/rms (稀疏性度量 ∈ (0,1])
prior_loss = d.abs().mean() / (d.pow(2).mean().sqrt().detach() + 1e-6)
```

### 缺陷 2：`L_ortho` 卡死在理论最大值（修改引入的回归）

**证据**：R2 的 ortho 在 ep1→ep5 降至 0.005；R4（修复前）卡在 **3.000**（理论最大）。

**根因**：R4 把 `prior_N/L/M` 的 scale 改为**零初始化** → 三路 prior 初始恒等；配合 `scale_N/L/M=0` → `raw_k = center`（三路同源）→ `F_N=F_L=F_M` 完全相同 → **正交损失落在鞍点**（梯度仅 1e-8）。

```python
# 实测: 三路 TCA 特征完全相同
|F_N - F_L| = 0.000000e+00
|F_N - F_M| = 0.000000e+00
ortho_loss = 3.000001   # 三个余弦都为 1
```

**修复**：`prior` scale 恢复非零初始化（0.1/0.1/0.5，R2 风格）提供对称破缺。
**验证**：ortho 2.93 → 0.02（100 步），恢复正常下降。

### 缺陷 3：`L_temp` 语义倒挂（用户问题 2 的验证）

**证据**（真实 pair45 数据 100-104 帧）：

| 输出 | L_temp_N 旧式 | 判读 |
|------|:---:|------|
| 不处理 `X_c`（低光原图）| **0.0000** | 最小 |
| 理想 `GT`（正确提亮）| **0.4109** | 被惩罚 ✗ |
| 含噪 `GT+noise` | 0.4247 | 与理想同罚 |

**这是最反直觉的发现**：旧 `L_temp = |HF(Y) - HF(x̄)|` **惩罚正确的提亮**。

**机制**：提亮按比例放大高频幅度（实测 GT/X̄ 的 HF 能量比 = **3.06×**），L1 差被"亮度差异"而非"噪声差异"主导。`Y_L` 同理（`Y_L = X_t·L_t^(γ-1)`，光照校正本就改变低频）。

**修复**（统一为**亮度不变的帧间噪声去相关**）：
```python
# L_temp_N: 输出 HF 不应与帧间噪声分量相关 (覆盖 Read+Shot)
noise_hf = hf(x_c - x̄)                      # 帧间噪声估计
L_temp_N = |cos(HF(Y_N), noise_hf)|           # 余弦对亮度缩放不变

# L_temp_L: 光照图不得携带帧间噪声 (防闪烁)
L_temp_L = |cos(HF(L_t), noise_hf)|
```

**验证**（真实数据判别力）：

| 项 | 含噪输出 | 理想输出 | 判别力 |
|----|:---:|:---:|:---:|
| L_temp_N | 0.857 | 0.062 | 14× |
| L_temp_L | 0.857（含噪光照）| 0.0003（平坦光照）| 2900× |

### 3.2 梯度冲突矩阵（TCA 共享参数上的余弦）

| | final | N | ortho | prior | temp | div |
|---|:---:|:---:|:---:|:---:|:---:|:---:|
| **final** | 1.00 | 0.81 | +0.11 | -0.03 | -0.11 | **-0.51** |
| **N** | 0.81 | 1.00 | +0.01 | +0.01 | -0.03 | **-0.72** |
| **ortho** | +0.11 | +0.01 | 1.00 | **-0.71** | -0.01 | -0.03 |
| **prior** | -0.03 | +0.01 | **-0.71** | 1.00 | +0.04 | -0.01 |
| **temp** | -0.11 | -0.03 | -0.01 | +0.04 | 1.00 | -0.00 |
| **div** | **-0.51** | **-0.72** | -0.03 | -0.01 | -0.00 | 1.00 |

**两个冲突**：
1. **`div` vs `final`/`N` = -0.51/-0.72**：`L_div` 鼓励分支在专属区域偏离输入，与"输出逼近 GT"直接对抗。这是设计使然（强制分工），但权重需小。
2. **`ortho` vs `prior` = -0.71**：正交要求三路独立，prior 要求各路贴近各自统计量——存在结构张力。

**评估**：冲突 #1 可接受（λ_div=0.05 小，且分工是设计目标）；冲突 #2 需要观察（λ 都小，正交最终胜出）。

## 五、物理意义补充：L_temp 对 N/L 分支的正确形式

### 问题 2 的完整回答

**原 R3/R4 实现能否覆盖物理意义？**
- `|HF(Y_N) - HF(x̄)|`：**不能**。它惩罚正确提亮（HF 幅度随亮度放大），实测倒挂。

**修复后能否覆盖两类噪声？**
- `|cos(HF(Y_N), HF(x_c - x̄))|`：**能**。
  - Read Noise（信号无关高斯）+ Shot Noise（信号相关泊松）**共享"帧间 i.i.d."性质** → 二者都在帧间差分 `x_c - x̄` 中显现 → 输出 HF 与之去相关即同时压制两类（这正是 TSDR 合并 I+II 的物理依据）。

**L 分支的帧间一致性约束**
- 原 `|LF(Y_L) - LF(x̄)|`：错误（Y_L 的低频本应改变）。
- 修正 `|cos(HF(L_t), HF(x_c - x̄))|`：正确约束**光照图**不携带帧间噪声（闪烁源）。

**N/L 能否用同一形式？**
- 能，且**应当**——两者本质都是"输出不应保留帧间 i.i.d. 噪声"，物理同源。

## 六、经验教训

1. **损失项必须有量级上界**：任何无界的正则（MSE 平方、无界 L1）在长训练中都会被特征量级放大。设计时先做**尺度不变性测试**（feat×k → loss×?，应为 k⁰）。

2. **正则项命名 ≠ 语义**：`L_temp` 叫"时序"，实现却是空间 HF 上限；即使改为"时序"，用 L1 直比仍被亮度主导。**必须用真实数据验证方向性**（理想输出是否得分更优）。

3. **零初始化要成对检查**：`proj_out=0` + `scale=0` 是乘法双零死锁（本次 TCA）；`prior scale=0` + `scale=0` 是分支恒等鞍点（本次 ortho）。**只保留一个零初始化**（ConvNeXt 风格）。

4. **用真实数据验证**：合成数据（GT=x×3，含输入噪声）导致多次误判；只有真实 SDSD 配对数据能暴露亮度主导问题。
