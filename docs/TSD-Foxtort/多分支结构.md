# LLVE 中"分而治之"为何多为两分支？三分支的优化冲突分析

（基于联网检索，检索于 2026-09-11；server_now = 2026-09-11）

---

## 一、为何现有 LLVE 论文的"分而治之"多止步于**两分支**？

### 1. 🎯 根本原因：Retinex 理论的物理约束天然只有两个分量

绝大多数 LLVE / LLIE "分而治之"方法都根植于 **Retinex 分解模型**：

$$I = R \otimes L$$

其中 `R` 是反射图（view-independent，反映场景固有内容），`L` 是光照图（view-dependent，反映照明条件）。这一分解源自 Lambertian 成像模型，本身**只有两个物理分量**。

代表性论文：
- **VLLVE (IJCAI 2025)** 明确指出："a frame in the LLVE task can similarly be decomposed as I = L ⊗ R, where L represents the view-dependent term, and R corresponds to the view-independent component"（[IJCAI 2025 主页](https://www.ijcai.org/proceedings/2025/238) | [Arxiv v3](https://arxiv.org/pdf/2405.15660v3.pdf)）
- **Diff-Retinex (ICCV 2023)** 的优化目标 `min_{R,L} τ(R·L) + αφ(R) + βψ(L)` 也只包含两项正则（[Diff-Retinex PDF](https://openaccess.thecvf.com/content/ICCV2023/papers/Yi_Diff-Retinex_Rethinking_Low-light_Image_Enhancement_with_A_Generative_Diffusion_Model_ICCV_2023_paper.pdf)）

### 2. 🎯 两分支已有清晰的"全局 vs 局部"物理分工

两分支方案往往对应两类互补的退化处理策略：

| 分支 | 处理内容 | 特性 |
|------|---------|------|
| 光照/亮度分支 | 亮度不足、非均匀曝光 | **非局部/全局**问题，需大感受野 |
| 反射/噪声/色彩分支 | 噪声、纹理、色彩 | **局部/像素级**问题，需精细特征 |

代表性实现：
- **VSRELL (CVPR 2026)** 的 INCO 模块中"光照敏感分支 + 噪声估计分支"共享编码器、解码端交叉调制融合（[VSRELL PDF](https://openaccess.thecvf.com/content/CVPR2026/papers/Hui_VSRELL_A_Simple_Baseline_for_Video_Super-Resolution_and_Enhancement_in_CVPR_2026_paper.pdf)）
- **LCDBNet** 在 YCbCr 空间做 Y（亮度）+ CbCr（色度）双分支（[LCDBNet DOI](https://doi.org/10.48550/arxiv.2307.09104)）
- **DBENet** 也是 Y/CbCr 分治（[DBENet MDPI](https://doi.org/10.3390/electronics12183907)）
- **DarkIR** 编码器做低光增强 + 解码器做去模糊，本质仍为两分工（[DarkIR Arxiv](https://arxiv.org/html/2412.13443v3)）

两分支边界物理清晰、可解释性高、易于设计正则损失，形成了成熟范式。

### 3. 🎯 噪声通常**寄生**在 R 中一起处理，而非独立成第三分支

即便要处理噪声，主流方法也是将其归入反射图 `R`（或某一现有分支）而非另开分支。Diff-Retinex 明确说明："**the noise is decomposed into the reflectance map**"（[Diff-Retinex ICCV 2023](https://openaccess.thecvf.com/content/ICCV2023/papers/Yi_Diff-Retinex_Rethinking_Low-light_Image_Enhancement_with_A_Generative_Diffusion_Model_ICCV_2023_paper.pdf)）。

少数三分支尝试（如 **ZRRD-MBNet** 显式估计 R / L / N 三分量，[ZRRD DOI](https://doi.org/10.21203/rs.3.rs-4023575/v1)；**Poisson-Guided Decomposition Network**，[Arxiv 2506.04470](https://arxiv.org/html/2506.04470v1)）都仅用于**图像**任务且严重依赖精心设计的联合损失和迭代分解——已经暴露出优化难度。

### 4. 🎯 更多分支带来的实用性代价

- **DP3DF (arXiv 2207.01797)** 明确批评"并行多分支方案"："branches are separated, connections are weak for joint learning ... hard to fine-tune them together for high performance"（[DP3DF Arxiv](https://ar5iv.labs.arxiv.org/html/2207.01797)）
- 分支越多，参数越冗余、推理越慢、训练越不稳定，工程成本显著上升。

## 二、三分支（噪声 + 光照 + 运动模糊）是否面临不可解决的优化冲突？

### ✅ 结论先行：**冲突真实存在且严重，但并非绝对不可解决**——需要引入专门的解耦训练策略才能缓解。

### 冲突存在的直接证据（来自最新 MTL / All-in-One 文献）

| 论文 | 关键结论 |
|------|---------|
| **SEGD (CVPR 2026)** | "共享主干处理多个退化时，不同退化驱动不一致的优化方向，导致**梯度冲突和参数竞争**"，明确为 noise / blur / low-contrast 三种退化设计独立参数的 DRM 模块（[SEGD PDF](https://openaccess.thecvf.com/content/CVPR2026F/papers/Li_Breaking_Degradation_Coupling_A_Structural_Entropy-Guided_Decoupled_Framework_and_Benchmark_CVPRF_2026_paper.pdf)） |
| **GRIDS (arXiv 2407.12273)** | 简单混合 11 种退化联合训练相比专用模型性能最多下降 **5.32 dB**；实证"任务负相关时联合优化导致所有任务的性能大幅下降"（[GRIDS Arxiv](https://arxiv.org/html/2407.12273)） |
| **UIR-LoRA** | "不同任务共享全部参数会导致**梯度冲突**，阻碍统一模型性能进一步提升"（[UIR-LoRA](https://openreview.net/pdf?id=zDYXdR3ClP)） |
| **D3Fusion (2025)** | 直接指出："端到端训练会导致不同任务的损失项在梯度反传时相互干扰，降低收敛稳定性"，因此采用**渐进三阶段训练**（[D3Fusion MDPI](https://www.mdpi.com/2076-3417/15/16/8918)） |
| **Debiased All-in-one (AAAI 2025)** | "统一多任务学习忽略了不同退化任务在模型优化上的异质性"，提出任务不确定性正则化（[AAAI TUR](https://ojs.aaai.org/index.php/AAAI/article/download/32905/35060)） |
| **Task-Conditioned All-in-One (ScienceDirect)** | "结构异质性引起的**任务间优化冲突**——阴影去除需局部校正，去雨/去噪/低光需全局模式抑制"（[ScienceDirect](https://www.sciencedirect.com/science/article/abs/pii/S0925231226016048)） |
| **Multi-Expert Adaptive Selection** | 频域分析显示：**噪声主要在高频、低光主要在低频、模糊同时影响高低频**——不同退化在频带上直接冲突（[Arxiv 2407.19139](https://arxiv.org/html/2407.19139v1)） |
| **Decouple-then-Merge (CVPR 2025)** | 从扩散模型角度证明："**非相邻任务间梯度相似度低，训练时相互冲突**"（[DeMe PDF](https://openaccess.thecvf.com/content/CVPR2025/papers/Ma_Decouple-Then-Merge_Finetune_Diffusion_Models_as_Multi-Task_Learning_CVPR_2025_paper.pdf)） |

### 三分支具体冲突机制分析

针对你提出的三分支设计：

| 退化类型     | 频带特征    | 优化目标方向      | 与其他分支的冲突           |
| -------- | ------- | ----------- | ------------------ |
| **成像噪声** | 高频随机扰动  | ⬇ 抑制高频 / 平滑 | ⚡ 与去模糊分支**频带正面冲突** |
| **光照扰动** | 低频亮度偏移  | ⬆ 全局对比度拉伸   | ⚡ 拉伸暗区必然放大噪声，与去噪冲突 |
| **运动模糊** | 中高频空间退化 | ⬆ 增强高频 / 锐化 | ⚡ 与去噪分支**目标相反**    |
|          |         |             |                    |

**四类具体冲突：**

1. **梯度方向冲突（Gradient Conflict）**
   - 去噪的损失 ∇L_denoise 和去模糊的损失 ∇L_deblur 在共享编码器上梯度方向可能相反（cosine similarity < 0），三个分支反向传播时**相互拉扯**共享参数（[DeMe CVPR 2025](https://openaccess.thecvf.com/content/CVPR2025/papers/Ma_Decouple-Then-Merge_Finetune_Diffusion_Models_as_Multi-Task_Learning_CVPR_2025_paper.pdf)）

2. **特征表示冲突（Representation Conflict）**
   - 去噪要求特征"平滑连续"，去模糊要求"锐利边缘"，**同一个编码器难以同时最优**——这也是为何 DarkIR 采用"编码器做增强、解码器做去模糊"的非对称结构（[DarkIR](https://arxiv.org/html/2412.13443v3)）

3. **频带资源竞争（Frequency Competition）**
   - 去噪和去模糊在**高频带正面竞争**：一个要"擦除"高频伪影，一个要"恢复"高频细节，模型无法区分该保留哪些高频（[Multi-Expert Arxiv](https://arxiv.org/html/2407.19139v1)）
   - 更棘手的是：低光下噪声**本身也表现为高频**，与真实纹理高频难以区分

4. **顺序依赖 / 误差累积（Order Dependency）**
   - **SEGD** 指出："退化间存在潜在的顺序依赖，不当的恢复顺序会扭曲后续退化分布，导致误差累积和伪影放大"（[SEGD PDF](https://openaccess.thecvf.com/content/CVPR2026F/papers/Li_Breaking_Degradation_Coupling_A_Structural_Entropy-Guided_Decoupled_Framework_and_Benchmark_CVPRF_2026_paper.pdf)）
   - 例如：先去噪会磨掉模糊边缘的信息，先去模糊会放大噪声——**先做哪个都不对**

5. **损失尺度不平衡**
   - 三个任务损失量级不同，大 loss 会主导训练方向；这也是 **VJT** 需要采用自适应权重方案让"不同损失达到同一能量水平"的原因（[VJT arXiv 2401.14754](https://ar5iv.labs.arxiv.org/html/2401.14754)）

### 两分支 vs 三分支：为何两分支能"苟活"而三分支冲突加剧？

| 维度       | 两分支（R + L / Y + CbCr）             | 三分支（噪声 + 光照 + 运动模糊） |
| -------- | --------------------------------- | ------------------- |
| **物理基础** | Lambertian 模型明确                   | 三者非物理正交、非独立         |
| **频带重叠** | 光照≈低频；反射≈全频（互补）                   | 噪声与去模糊**都在高频、正面冲突** |
| **目标方向** | 亮度调整 vs 细节恢复（协同）                  | 抑制高频 vs 增强高频（对抗）    |
| **顺序依赖** | R 和 L 可近似同时求解                     | 严重（"先去噪 or 先去模糊"两难） |
| **梯度冲突** | 弱（不同频带）                           | 强（相同频带反向优化）         |
| **成熟方案** | 众多（VSRELL、VLLVE、LCDBNet、DBENet 等） | 极少（且都需渐进训练绕行）       |

### 🛠️ 缓解方案（现有绕行策略，但都需付出代价）

| 策略                              | 代表工作                                                                                                                                                                                                                                              | 代价                |
| ------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------- |
| **渐进/分阶段训练**                    | [D3Fusion](https://www.mdpi.com/2076-3417/15/16/8918)（三阶段：光照→解耦→融合）                                                                                                                                                                               | 非端到端、超参数多、训练时长增加  |
| **独立参数专家 (Decoupled Modeling)** | [SEGD](https://openaccess.thecvf.com/content/CVPR2026F/papers/Li_Breaking_Degradation_Coupling_A_Structural_Entropy-Guided_Decoupled_Framework_and_Benchmark_CVPRF_2026_paper.pdf)（每个退化独立 DRM）、[GRIDS](https://arxiv.org/html/2407.12273)（相似任务分组） | 参数量↑、推理需路由        |
| **LoRA 低秩解耦**                   | [UIR-LoRA](https://openreview.net/pdf?id=zDYXdR3ClP)（共享基座 + 各退化独享 LoRA）                                                                                                                                                                           | 需要退化类型识别          |
| **任务不确定性加权**                    | [TUR (AAAI 2025)](https://ojs.aaai.org/index.php/AAAI/article/download/32905/35060)                                                                                                                                                               | 训练更复杂，仍无法根本消除冲突   |
| **频域分治**                        | [Multi-Expert Adaptive Selection](https://arxiv.org/html/2407.19139v1)（分高低频用不同专家）                                                                                                                                                                 | 需要频域分离模块          |
| **分层块处理**（编码器一件事，解码器另一件事）       | [DarkIR](https://arxiv.org/html/2412.13443v3)、[LEDNet](https://arxiv.org/html/2412.13443v3)                                                                                                                                                       | 只能处理 2 个耦合任务      |
| **多层次特征传递**                     | [VJT (arXiv 2401.14754)](https://ar5iv.labs.arxiv.org/html/2401.14754)（多 tier 各针对不同退化程度）                                                                                                                                                          | 训练复杂、tier 数增加线性代价 |
| **专家混合 (MoE) + 学习分区**           | [MoCRA (arXiv 2608.01829)](https://arxiv.org/html/2608.01829v1)（分解为可复用小单元，专家化其混合）                                                                                                                                                                 | 需要设计路由机制          |

## 三、总结

### 📌 关键结论

1. **两分支范式的选择不是任意的**——它由 Retinex 物理模型天然决定，且两个分支在频带和目标方向上互补（光照≈低频调整，反射≈全频细节恢复），梯度冲突较小。

2. **三分支（噪声 + 光照 + 运动模糊）会遭遇严重的优化冲突**，最棘手的是**去噪与去模糊在高频带的正面梯度冲突**——这也是为何 **DarkIR、LEDNet** 等联合去噪 + 去模糊 + LLIE 方法均不采用平铺三分支，而是用"编码器 - 解码器分工"、"频空分离"等非对称结构规避。

3. **冲突可以缓解但代价高昂**：需引入**渐进训练、独立参数专家、LoRA 解耦、频域分治、任务不确定性加权**等策略之一或组合。即使如此，**SEGD (CVPR 2026)** 这类专门为三种退化设计三分支的方法仍需精心设计的"退化解耦-先验引导-顺序自适应"架构，且目前主要在**图像**（红外/可见光）领域，**尚未有成功的视频域三分支 LLVE 方法**。

4. **一个值得探索的方向**：与其平铺三分支，不如借鉴 **VSRELL** 的"耦合建模"思想——**将耦合的退化联合建模在一个模块内**（如 INCO 联合建模光照+噪声），再用另一个模块处理运动/时序（如 ISFP）——本质是**"物理耦合分组"两分支**而非"退化类型独立三分支"，这是当前最有希望的技术路线。

### 💡 一句话回答你的核心问题

> 三分支不是"不可解决"，而是"直接分成三个独立分支并端到端联合训练必然遭遇严重的梯度冲突、频带竞争和顺序依赖，需要引入渐进训练或独立参数专家等专门解耦策略才可行；这也解释了为什么 LLVE 领域至今仍以两分支为主流"。
