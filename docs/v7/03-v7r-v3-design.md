## 一、设计动机

### 1.1 问题溯源

前序 v7r-v2 的多源解耦路径为：

```
PixelTemporal → SpatialSummary(帧级token) → MatrixRWKV ×2
              → ContextDecomposition(线性投影) → FiLM → 三分支
```

**核心缺陷**：v7r-v2 把三源解耦交给**事后线性投影 + 正交约束**，丢失了 R4 已验证的两个关键机制：

1. **三路差异化 Query**（显式退化先验）—— v2 只有单路 MatrixRWKV 输出
2. **共享 KV 中的逐帧/统计细节** —— v2 的 KV 是帧级 token `[B,T,D]`，空间结构被 `AdaptiveAvgPool2d` 抹平

### 1.2 Golf-R4 实验的教训

| 版本 | KV 设计 | Pair45 PSNR | 结论 |
|------|---------|-------------|------|
| R2 | 聚合统计量 | **17.22** | 有效先验 |
| R4 | `Concat_time(F_{t±i})` 1×1 投影 | 15.89 | 全时序噪声放大 🔴 |
| R5 | 回退聚合统计量 | 15.78 | 仍差于 R2 |

**关键结论**（`Golf-R5-plan.md` §R5-3）：
> 全时序可能引入噪声，聚合量是有效先验

即：**R4 的「三路 Query」思路正确，但「Concat 全时序 KV」实现错误**。正确组合应是：

> **三路差异化 Query（继承 R4） + 统计先验 KV（继承 R2/R5） + 逐像素对齐（继承 v7r-v2 PixelTemporal）**

这就是 v7r-v3。

## 二、架构总览

```
输入: [B, T=5, 3, H, W]
  │
  ├─ Stage 1: SharedEncoder (逐帧独立)
  │    F2_seq = [B, T, 64, H/2, W/2]
  │
  ├─ Stage 2: feature_proj + PixelTemporalAttentionSimple (window=3)
  │    feat_aligned = [B, 128, H/2, W/2]      ← 逐像素时序对齐
  │
  ├─ Stage 3: Matrix RWKV + Triple Query TCA ⭐
  │    │
  │    ├─ (辅助) SpatialSummary → MatrixRWKVBlock ×2 → ctx [B,T,192]
  │    │
  │    └─ TripleQueryTCA(feat_aligned, feats_proj):
  │         ┌─ 三路查询 (从像素对齐特征) ─┐
  │         │  Q_N = query_N(feat_aligned)  │
  │         │  Q_L = query_L(feat_aligned)  │
  │         │  Q_M = query_M(feat_aligned)  │
  │         └───────────────────────────────┘
  │
  │         ┌─ 共享 KV (统计先验拼接) ──────────┐
  │         │  ctx_mean   = mean(F2_seq)         │  ← 噪声: i.i.d. 均值
  │         │  ctx_smooth = LowPass(ctx_mean)    │  ← 光照: 低频慢变
  │         │  ctx_diff   = max|F_c - F_t|       │  ← 运动: 位移差分
  │         │  KV = kv_proj([mean, smooth, diff])│  ← 3C→C 1×1 投影
  │         └────────────────────────────────────┘
  │
  │         ┌─ 三路 RWKV 空间注意力 (共享 KV) ─┐
  │         │  attn_N = RWKVSpatialHead(Q_N, KV)│
  │         │  attn_L = RWKVSpatialHead(Q_L, KV)│
  │         │  attn_M = RWKVSpatialHead(Q_M, KV)│
  │         └───────────────────────────────────┘
  │
  │         F_k = out_norm_k(feat_aligned + attn_k · scale_k)
  │
  ├─ Stage 4: Branch-N/L/M (复用 v7r-v2 简化分支)
  │
  └─ Stage 5: V7RFusion
      O_t = final
```

## 三、模块细节

### 3.1 TripleQueryTCA

位置: `models/golf_v7r/triple_query_tca.py`

| 组件 | 实现 | 参数量 |
|------|------|--------|
| `query_N/L/M` | `LayerNorm2d + Conv2d(1×1)` | 3 × (128×128 + 256) ≈ 49.5K |
| `kv_proj` | `Conv2d(3C→C, 1×1) + LayerNorm2d` | 3×128×128 + 256 ≈ 49.4K |
| `rwkv_inject` | `MatrixRWKVInjector` (Linear 192→3C) | 192×384+384 ≈ 74.1K |
| `attn_N/L/M` | `RWKVSpatialHead` (BiWKV×4方向) | 3 × 66.8K ≈ 200.4K |
| `scale_N/L/M` | LayerScale (零初始化) | 3 × 128 |
| **合计** | | **≈ 0.374M** |

**KV 统计先验**（对齐 R2/R5）：

```python
def _ctx_mean(feats_seq):     # 成像噪声: i.i.d. → 帧间平均最优估计
    return feats_seq.mean(dim=1)

def _ctx_smooth(feats_seq):   # 光照衰减: 低频慢变 → 大核池化低通
    return F.avg_pool2d(feats_seq.mean(dim=1), kernel_size=7, padding=3)

def _ctx_diff(feats_seq):     # 运动位移: 中心帧 vs 邻帧最大绝对差
    diffs = [(center - feats_seq[:,t]).abs() for t != center]
    return stack(diffs).max(dim=0).values
```

### 3.1b MatrixRWKV 注入（方案 B：三路统计门控）

> **背景（审查修正）**：v3 初版存在「死计算」缺陷——`SpatialSummary + 2×MatrixRWKVBlock`
> 算出 `ctx` 却未接入 `TripleQueryTCA`，0.95M 参数每步空转，且使 "Matrix RWKV" 名不副实。
> 本方案 B 将 `ctx` 作为共享统计 KV 的门控，恢复梯度路径。

**注入点**：MatrixRWKV 的时序判断 → 调制统计 KV。二者信息形态互补：

| 路径 | 空间结构 | 时序动力学 | 分辨率 |
|------|----------|-----------|--------|
| 统计 KV (`mean/smooth/diff`) | ✅ 完整 H×W | ❌ 对时间顺序不变 | H/2 |
| MatrixRWKV `ctx` | ⚠️ 仅 2×2 | ✅ T 帧递推 | 帧级 |

因此注入方向是**用时序态势选择退化假设**，而非补充空间细节。

```python
# MatrixRWKVInjector: to_gate 零初始化
gate = to_gate(ctx_center)              # [B, 3C]
gate = gate.view(B, 3, C, 1, 1)
s_mean   = ctx_mean   * (1 + gate[:,0]) # 三路逐通道门控
s_smooth = ctx_smooth * (1 + gate[:,1])
s_diff   = ctx_diff   * (1 + gate[:,2])
kv_shared = kv_proj(concat([s_mean, s_smooth, s_diff]))
```

**恒等性与梯度**：
- `to_gate=0` → `gate=0` → `s_k = ctx_k`，初始不扰动既有表示（恒等）
- 梯度 `∂L/∂W_gate ∝ ∂L/∂kv · ctx_k ≠ 0`（统计量非零）
- 属**单零**（门控层零、被门控量非零），从 step1 起可达 MatrixRWKV，**避开 R4 双零死锁**

**实测验证**（5 步 AdamW lr=4e-4）：

| step | gate_grad | rwkv_block_grad | gate_val | ctx_drift |
|------|-----------|-----------------|----------|-----------|
| 0 | 0 | 0 | 0.000 | 0 |
| 1 | 3.3e-7 | 0 | 0.000 | — |
| 2 | 2.9e-7 | 8.5e-11 | 0.037 | — |
| 5 | 1.5e-7 | 1.6e-10 | 0.096 | 0.277 |
| 59 | 4.9e-8 | 2.0e-10 | 0.208 | 1.025 |

- ✅ Injector 自 step1 解锁，`gate_val` 从 0 增至 0.21
- ✅ MatrixRWKV 梯度非零（step2 起），`ctx_drift` 从 0 增至 1.025 → **真正在学习**
- ℹ️ `rwkv_block_grad ≈ 1e-10` 看似极小，但被门控乘子 `(1+g)`（g≈0.1）衰减，与 LayerScale
  初始 ~1e-10 同量级，Adam 可正常处理；关键是**非零**（对比 v3 初版的**精确 0**）

**参数量**：3.67M → **3.75M**（+74.1K）

### 3.2 关键设计选择

#### ✅ 为什么用统计先验 KV 而非 Concat 全时序？

| 方案 | 优点 | 缺点 | 来源 |
|------|------|------|------|
| Concat 全时序 (R4) | 保留逐帧细节 | 噪声放大、tile 边界不连续 | ❌ 实验失败 |
| 聚合统计量 (R2/R5) | 天然去噪、物理对应 | 丢逐帧细节 | ✅ 实验有效 |
| **统计先验拼接 (v3)** | **保留三源物理语义 + 空间结构** | 仍丢部分逐帧细节 | **本设计** |

**关键**：v3 的统计先验**保留空间结构**（`[B,C,H,W]`），而 v2 的帧级 token 是 `[B,D]`。这使 KV 具有空间选择性 —— 运动区域和静态区域可使用不同的 KV 响应。

#### ✅ 为什么 LayerScale 零初始化？

对称性：三路 `scale_N/L/M = 0` 时，`F_k = out_norm(feat_aligned)`，三路初始完全相同。这看似"坍塌风险"，但：

1. **out_norm 逐通道仿射不同** → 三路归一化参数独立学习
2. **梯度非零**：实测 scale 梯度 `1e-3` 量级（见 §五 验证）
3. **对比 R4 双零死锁**：R4 的 `proj_out=0` + `scale=0` 形成乘法双零链，梯度精确为 0；v3 的 `proj_out` 非零（Xavier 初始化），只有 scale=0 是单零，梯度可达 ✅

### 5.4 关键数据缺陷：SDSD LQ/GT 配对错位 (2026-10-03)

**发现**：SDSD 每个序列的 LQ 与 GT **帧数相等，但文件名区间整体偏移**，且偏移量随序列不同：

| 序列 | LQ 区间 | GT 区间 | 文件名偏移 |
|------|---------|---------|-----------|
| pair19 | 0156–0277 | 0161–0282 | +5 |
| pair40 | 0036–0174 | 0050–0188 | +14 |
| **pair45** | 0047–0177 | 0107–0237 | **+60** |
| pair60 | 0032–0144 | 0054–0166 | +22 |

训练集同样如此（70 序列中 58 个 |偏移|>3）。

**缺陷**：`datasets/sdsd_dataset.py` 采用「LQ/GT **文件名交集**」配对，例如 pair45
把 LQ `0047`(第0帧) 与 GT `0047`... 实际只保留交集 71 帧，并把 LQ 第 60 帧与 GT 第 0 帧
配成一对——**时间错位 60 帧**。

**证据**：
1. 训练日志总步数 = **8253**，恰等于文件名交集帧数（总帧数 9259），证实训练用了错位子集；
2. 亮度归一化 LQ-vs-GT 结构相关：10 个 val 序列**全部** position 配对优于 name 配对，
   平均 **+1.71 dB** (pair40 +1.71, pair60 +3.31, pair55 +3.17)；
3. 用 v7r-v3 模型自身输出对比：position 配对平均比 name 配对 **+0.78 dB** PSNR；
4. 官方 SDSD 参考实现 `reference_repos/LLVE_STCD`（指向同一 `indoor_np` 数据）
   明确按 **sorted 位置** 配对（`img_paths_LQ[0:30]` vs `img_paths_GT[0:30]`，断言帧数相等），
   而非文件名；
5. 视觉核验 pair45：LQ pos60 与 GT pos60 的同一暗色人形/植物一致，而 GT 同名(读作 pos0)
   对应另一场景（白色头盔）。

**修复**：`SDSDDataset` 新增 `pairing` 参数（`"name"` 保留历史行为 / `"position"` 官方约定），
训练/评估/推理脚本均可切换。position 配对后 train=9259 / val=1244 帧（此前 8253 / 1120）。

## 五甲、MatrixRWKV 注入方案矩阵（实验计划）

审查发现 v3 初版的 MatrixRWKV 是「死计算」。本版实现**方案 B**（三路统计门控），
并保留 **方案 C** 作为后续消融，构成一条完整的注入强度梯度：

| 变体 | 机制 | 注入形式 | 参数 | 状态 |
|------|------|----------|------|------|
| **B**（当前） | 三路统计门控 | `s_k = ctx_k · (1 + g_k)`，`g = to_gate(ctx_center)` | +74.1K | ✅ **已实现** |
| **B+C** | 门控 + per-channel FiLM | `kv = kv_proj(s) ; kv = kv·(1+γ) + β` | +123.5K | 📋 计划 |

**方案 C 定义**（`to_film: Linear(rwkv_dim → 2C)`，零初始化）：

```python
gamma, beta = to_film(ctx_center).chunk(2, dim=-1)   # [B, C] each
kv_shared = kv_shared * (1 + gamma[..., None, None]) + beta[..., None, None]
```

**对比设计要点**：
- B 与 C 作用点不同（B 在统计量上、C 在投影后 KV 上），可叠加
- 两者均零初始化 → 均从恒等起步，不冲突、不破坏训练稳定性
- 消融时只看 `inject_stat['gate']` 与 `inject_stat['film']` 的幅度演化

**判读标准**（训练后）：
- 若 B 的 `gate` 幅度显著增长且指标优于"无注入" → MatrixRWKV 的时序门控有增益
- 若 B+C 优于 B → per-channel FiLM 精化有额外增益
- 若均收敛到 → 0 → 诚实结论：MatrixRWKV 对该 KV 无增益（考虑改为方案 A 或删除）

### 6.2 🔴 P0：分支输出未分化（解耦未转化为多样性）

**现象/证据**（§5.5.6）：三路特征 `ortho_loss` 已降到 0.003–0.014（特征正交），
但三路 **RGB 输出余弦 0.99–0.9995**——即 F_N/L/M 虽正交，经各自解码器后回归到几乎同一张图。
融合退化为「N+M 两路加权」（L 权重仅 0.15），中心帧残差 γ≈0.01（关闭）。

**根因假设**：
1. **分支监督过强且目标同一**：`w_branch_{N,L,M}=0.1` 让三支都直接 L1 回归同一 GT，
   解码器被强烈信号拉向同一解，压过了特征正交的差异化；
2. **解码器容量/结构相近**：BranchN/L/M 同构且都从 128 维特征解码，缺少「只能走特定路径」
   的结构约束（如 Retinex 的 R·L^γ 若也加 L1 监督，反而逼它退化成直接回归）；
3. **正交约束作用在特征而非输出**：`_ortho_loss` 只约束 F，不约束 Y，故正交可被解码器绕过。

**解决思路**：
- **A（低风险）**：消融分支监督权重 `w_branch_*`（0.1→0.02/0），观察三路输出余弦是否下降、
  以及最终指标是否变化；若指标不降而分化上升，说明监督确实过度。
- **B（中风险）**：把 `_ortho_loss` 从特征层搬到**输出层**（对 Y_N/L/M 加正交/去相关），
  或特征+输出双约束，直接惩罚输出同质化。
- **C（结构性）**：给各分支**非对称先验**——BranchL 用 Retinex 的物理形式且**只监督亮度通道
  或低频**，BranchM 监督对齐后的时序一致性，BranchN 监督残差/高频；从监督空间上强制分工。
- **D（诊断优先）**：先做**掩码/特征可视化**（§6.3），确认三路 Query 到底学到什么，再决定改监督。

**验证方式**：三路输出余弦（应显著 <0.99）+ 最终 PSNR/SSIM/LPIPS 不变差 + 逐序列增益。
**工作量**：A/B 各约 1 次 5-epoch 受控训练（有 quick 配置可直接复用）。

### 6.3 🟠 P1：三路 Query 的语义分工无证据（可解释性缺口）

**现象/证据**：文档声称 Q_N/L/M 对应噪声/光照/运动，但**从未可视化**三路注意力/响应区域。
§6.2 的输出同质化更让人怀疑三路实际未学到差异化语义。§5.5.6 仅间接显示 M 路融合权重方差最大。

**✅ 诊断已完成（2026-10-08，`scripts/diag_v7r_v3_query_semantics.py`，纯推理）**：

三路在**内部特征层面确实不同**——`|Q_N/L/M|` 两两相关系数接近 0 甚至负（pair50/45/19：
Q corr NL/NM/LM = −0.16/−0.07/0.004、−0.08/−0.001/0.02、−0.10/−0.05/0.01），
`|attn_N/L/M|` 亦低相关（−0.02/−0.11/−0.12、0.07/−0.10/−0.04、0.04/−0.11/−0.07）。
**即：三路在「特征空间」是分化的**（与 §5.5.6 特征正交一致）。

但**受控退化实验暴露关键缺陷**——对同一 clip 注入 噪声/压暗/位移，看各路的响应是否「对口」：

| 退化 | 应有主导路 | 实测响应最大路（absQ 比值） | 是否对口 |
|------|:--:|------|:--:|
| 加噪 (i.i.d.) | N | Q_N **0.83**（↓）、Q_L 0.81（↓）、Q_M 0.99（不变）；`ctx_diff`↑2.9× | ❌ 反而是 M/ctx_diff 响应 |
| 压暗 (gamma) | L | Q_L **1.26**（↑最大）；`ctx_mean/smooth`↑1.2–1.4× | ✅ L/Q_L 唯一沾边 |
| 位移 (motion) | M | Q_M **1.00**（几乎不变）；`ctx_diff` 仅 1.07× | ❌ 完全无响应 |

**结论（诚实）**：
1. 三路 Q 在数值上**去相关**（不是复制），但**去相关 ≠ 语义分工**——没有一路对「噪声」或
   「运动」产生选择性响应；
2. **位移几乎不被感知**：motion 下 `absQ`/`absKV` 比值≈1.00，唯一上升的是 `ctx_diff`（≈1.07×）；
3. **压暗对 L 路有效但弱**（1.26×），且 `ctx_mean/smooth` 同步上升，说明 L 的「光照敏感性」其实
   主要来自统计 KV 而非 Query 本身；
4. 噪声注入会让 `ctx_diff` 暴涨 ≈2.9×，**证实 §6.8 的「ctx_diff 被噪声主导」假设**。

**补充：`ctx_diff` 对位移的敏感性直接实测（`pair50`，中心 vs 邻帧特征最大绝对差）**

| 扰动 | `ctx_diff` mean 比值 | max 比值 |
|------|:--:|:--:|
| 加噪（中心帧 σ=0.05） | **3.19×** | 1.12× |
| 压暗（γ=2） | 0.16× | 0.62× |
| 位移 shift=2 px | 1.07× | 1.15× |
| 位移 shift=8 px | 1.30× | 1.26× |
| 位移 shift=**16 px** | 1.53× | 1.29× |

> **关键修正**：`_ctx_diff` 计算在 **`feats_seq`（投影后、PixelTemporal 对齐之前）**上，
> 因此「对齐把位移抹掉」**不是**根因。真正的根因是：**该统计量对噪声的敏感度（3.19×）远高于
> 对大位移的敏感度（1.53×）**——即使 16 px 位移，其特征差也远小于注入噪声。即 **`ctx_diff`
> 本质上测的是「帧间特征不相似度」，噪声/压缩/闪烁都能触发，而运动由于编码器特征的平移
> 容错性只触发很弱**。这同时解释了为何 M 路语义落空（§6.2）与 §6.8 的先验纯度问题。

**修正后的解决思路**：
- **A（结构，Phase A 采用）**：把「运动」信号改为对**噪声不敏感、对位移敏感**的代理——
  在 `ctx_diff` 前先对邻帧特征做**空间低通/去噪**再求差，并显式用**帧间相关对齐**（如对
  邻帧做小范围搜索对齐后再求残差），使「结构位移」而非「高频噪声」主导；
- **B（监督）**：见 §6.2-C，按退化类型分配监督空间（L 只监督亮度/低频、M 监督时序一致、
  N 监督残差/高频），从标签层面强制语义；
- **C（诊断）**：本脚本可复用于**逐序列热力图**（已产出 `pair50/45/19_maps.png`）。

**验证方式**：受控退化下「对口路」的 absQ/absAttn 比值应显著 >1 且高于其它路。
**工作量**：诊断已完成（仅推理）；A/B 属结构性改造，需重训。
**产物**：`outputs/golf_v7r_v3_query_semantics/{pair*_maps.png, summary.json}`。

### 6.6 🔴 P0：极暗序列无法恢复（能力瓶颈）

**现象/证据**（§5.5.4）：DID 上 video19/video20 PSNR≈12（其它 20–29），且 video19 随训练倒退。

**量化证据（2026-10-08 实测平均亮度，8 帧采样）** —— 直接支持「训练分布无同等级暗样本」：

| 分组 | 序列 | 平均亮度 (0–1) |
|------|------|----------------|
| **DID（失败）** | video20 / video19 | **0.019 / 0.023** |
| DID（边缘） | video203 / video116 | 0.040 / 0.055 |
| DID（成功） | video10 / video114 / video30 | 0.229 / 0.181 / 0.148 |
| SDSD 训练集最暗 8 序列 | pair61 / pair25 / pair24 … | 0.043 / 0.044 / 0.048 … |
| SDSD 训练集中位 | — | 0.090 |

**关键**：DID 两个失败序列（0.019/0.023）**比 SDSD 训练集最暗的序列（0.043）还要暗约 2×**，
且训练集中位亮度（0.090）是它们的 4–5×。模型**从未见过这个亮度区间**，退化属分布外。

**根因假设**：
1. 训练集中**缺少同等级极暗样本**（上表已证）；
2. 损失对**极暗区的梯度被亮区主导**（L1 在亮区数值大），暗区学不动；
3. 物理上极暗帧信息已被噪声淹没，纯回归有信息上限。

**解决思路**：
- **A**：**极暗增广**——训练时对 LQ 施加更极端的 gamma 压暗（目标把训练亮度分布下探到
  ~0.02），覆盖 DID 暗度分布；
- **B**：**分区/感知加权损失**——按亮度倒数加权 L1，或对暗区单独算 loss；
- **C**：**色彩/亮度统计对齐**（§6.5-C）缓解跨相机整体偏移；
- **D**：接受信息上限，报告中明确该场景为能力边界。

**验证方式**：DID video19/20 PSNR 是否脱离 12 平台。
**工作量**：A/B 各 1 次 60-epoch 训练。

### 6.7 🟡 P2：输入利用率不足（T=5 被局部降为 3）

### 6.8 🟡 P2：统计先验 KV 的纯度（center 回环 + diff 噪声）

**现象/证据**（02 §13.4 ⚠️3/⚠️4/⚠️5）：`ctx_mean` **含 center 帧本身**，而 Q 也来自 center，
KV 与 Q 同源 → 削弱「先验」独立性；`ctx_diff=max|center−F_t|` 在极暗场景可能由**噪声主导**
而非位移；`ctx_smooth` 实为空间低通而非时序慢变。

**✅ 已量化（2026-10-08，§6.3 补充实测）**：`ctx_diff` 对**加噪的敏感度 3.19×**，
而对 **16 px 大位移仅 1.53×** → `ctx_diff` **本质上测的是帧间特征不相似度**，噪声/压缩/闪烁
都能触发，运动因编码器特征的平移容错只触发很弱。这是 §6.2「M 路语义落空」的直接机制证据。

**✅ Phase A.2 修复已验证（零训练成本, 2026-10-08）**：对邻帧先做 `avg_pool` 低通再求差
（`motion_aware_diff`），噪声/运动敏感度比被压平：

| 配置 | noise× | motion16px× | ratio (noise/motion) |
|------|:--:|:--:|:--:|
| 历史 (off) | 3.37 | 1.53 | **2.21** |
| k=3 | 2.27 | 2.27 | **1.00** |
| k=5 (当前默认) | 2.35 | 2.14 | **1.10** |
| k=9 | 2.25 | 2.09 | 1.08 |

→ 低通后再差分使「结构位移」与「噪声」被同等程度感知, 修复了 §6.8 的先验纯度缺陷。
是否转化为分支分化, 仍需训练验证 (§6.14 H-m)。

**解决思路**（Phase B 单变量推进）：
- `ctx_mean` 改 **leave-one-out**（排除 center）；
- `ctx_diff` 先对邻帧做**空间低通/去噪**、再求差，并加**小范围对齐搜索**，使结构位移主导；
- `ctx_smooth` 更名或补**时序低通**（如对 t 方向做一阶滤波）。

**验证方式**：消融 A/B，尤其极暗序列；用 §6.3 脚本复测 `ctx_diff` 的 noise/motion 敏感度比。
**工作量**：小改动，配合 §6.6 重训验证。

### 6.9 🟠 P1：损失函数缺感知/频率项（LPIPS 只在评估用）

#### 预注册判据 (DID: Decision If Different, 修订后自洽版)

> **⚠️ 注意**: 5ep 时 LayerScale 级联期仍处于线性增长阶段 (scale_N/L/M ≈ 0.026–0.033),
> 余弦若未达标不应立即否决 — 见"三段式假阴性保护"。

**H-m** (`phaseA_m` ep5 vs 参照):
- **机制判据** (主判据): `motion` 条件下 absAttn_M 为三路最大 **且** absAttn_M/base ratio ≥ **1.5**
  - 测量: `diag_v7r_v3_query_semantics.py` motion 行, 三序列均值
  - 基线当前: 1.000 → 目标: ≥ 1.5 (表明 M 路感知到位移)
- **性能判据**: PSNR ep5 ≥ **21.87 dB** (= 21.92 − 0.05)
- **分化判据**: Y_M↔Y_N cosine ≤ **0.9767** (= 0.9967 − 0.02)
  - 分化判据在 5ep 有假阴性风险; 见三段式保护

**H-l** (`phaseA_l` ep5 vs 参照):
- **机制判据** (主判据): `dark` 条件下 absAttn_L 为三路最大 **且** absAttn_L/base ratio ≥ **2.0**
  - 基线当前: 0.916 → 目标: ≥ 2.0 (表明 L 路感知到亮度变化)
- **性能判据**: PSNR ep5 ≥ **21.87 dB**
- **分化判据**: Y_L↔Y_N cosine ≤ **0.9775** (= 0.9975 − 0.02)

**H-holdout** (`phaseA_holdout` ep5):
- 不判通过/失败, 只记录:
  - ep5 holdout PSNR (无泄漏口径)
  - 泄漏幅度 = pospair_quick ep5 PSNR − holdout ep5 PSNR (预期 0.3–1.0 dB)
- 用途: 为后续所有变体提供无泄漏 PSNR 参照

#### 三段式假阴性保护

| 状态 | 机制判据 | 分化余弦 | 处置 |
|------|:--:|:--:|------|
| 强通过 | ✅ 达标 | ✅ 达标 | 该 toggle 进 60ep 合并 run |
| 机制活化 / 余弦未达 | ✅ 达标 | ❌ 未达 | 续训 10–15ep 再判 (防 LayerScale 期假阴性, 约 16–24h) |
| 机制显著改善但未达 | ⚠️ H-l: dark ≥ 1.3 且 L 最大 | 任意 | 同"续训 10–15ep 再判"(边界规则, 见下) |
| 机制未活化 | ❌ 未达 (H-l: dark < 1.3) | 任意 | 判为失败, 不续训, 转 §6.6 / §6.9 路线 |

> "续训 10–15ep"判定: 若机制判据仍达标且余弦达标 → 通过; 否则失败.

> **边界规则动机 (H-l 专属)**: `use_lowfreq_L` 是**监督侧**改动, 靠训练塑形, 比 H-m 的
> **输入侧**信号慢一拍; 要求 5ep 从 0.916 跳到 ≥2.0 (≈2.2×) 偏激进。故对 H-l 增设边界:
> 若 `dark` 的 absAttn_L ∈ [1.3, 2.0) 且为三路最大 → 并入"续训"分支而非直接判失败。
> H-m 阈值维持 ≥1.5 不变 (输入侧信号在 step1 即生效, 无慢拍问题)。
> **此边界规则已于 2026-10-08 在训练启动前锁入预注册。**

> **机制判据的局限 (诚实声明)**: `kv_shared` 被三路共享, `motion_aware_diff` 改的是 KV 里的
> `s_diff`, 因此信号会同时进入三路; 「M 路 ratio 最大」实际检验的是 **query_M 是否把该信号
> 转成自己的输出** (即分化), 而非"信号只到 M". 该判据是 proxy, 故与 cosine 判据**并列**而非替代.

**最可能的根因（按可能性排序）**：

1. **电源 (PSU) 保护动作或老化** — 最能解释"瞬间失电 + 无任何软件痕迹"。

3. **主板 VRM 或 12VHPWR 供电接口问题** — Z790 D DDR4 + 4090 属已知瞬态敏感组合。
4. **CPU 老化 (Raptor Lake Vmin Shift)** — i7-13700F 属受影响型号, BIOS 停留在 **F3 (2023-01-09)**。

(注: `use_lowfreq_L` 是**纯损失侧**开关, 不影响推理路径, 故 `phaseA_l` 首次读数有效。)

**协议一致性验证**: 参照 ckpt (`pospair_quick` ep5) 重跑诊断, motion absAttn_M = 1.000、
dark absAttn_L = 0.916 (三序列 0.879/1.009/0.859)、余弦 NM = 0.9967 / NL = 0.9975,
与 §6.14 预注册基线**逐位吻合** → 测量口径可信。

**H-m (`phaseA_m` ep5, `motion_aware_diff=true` k=5)**

| 判据 | 阈值 | 实测 (三序列均值) | 结果 |
|------|------|------------------|:--:|
| 机制: motion absAttn_M ratio ≥ 1.5 | ≥1.5 | **1.000** (0.998/1.000/1.001) | ❌ |
| 机制: absAttn_M 为三路最大 | 是 | 否 (pair50 为 L, pair45/19 为 M) | ❌ |
| 性能: PSNR ep5 ≥ 21.87 | ≥21.87 | **24.02 dB** | ✅ |
| 分化: Y_M↔Y_N cos ≤ 0.9767 | ≤0.9767 | **0.9981** | ❌ |

**裁决: 机制未活化 → 判失败** (§6.14 三段式: 机制 ❌ → 不续训)。开关对输出的实测影响
|Δfinal|max = **6.05e-06** (CPU, 1/4 分辨率对照): `s_diff` 虽被 `motion_aware_diff` 改变
(noise 组 `ctx_diff` 能量 1.08→1.17、8.94 量级确认路径生效), 但经 `kv_proj` 汇入**三路共享 KV**
后被三路等量吸收, 再由 `scale_*` ≈ 0.018–0.029 的 LayerScale 压到输出——**输入侧信号无法转化为
单路分化**, 这正是 §6.14"机制判据局限"声明的实证。

**H-l (`phaseA_l` ep5, `use_lowfreq_L=true` k=16)**

| 判据 | 阈值 | 实测 (三序列均值) | 结果 |
|------|------|------------------|:--:|
| 机制: dark absAttn_L ratio ≥ 2.0 | ≥2.0 | **0.878** (0.933/0.855/0.846) | ❌ |
| 机制: absAttn_L 为三路最大 | 是 | 否 (三序列均为 **N**, 1.617) | ❌ |
| 边界规则: dark absAttn_L ≥ 1.3 | ≥1.3 | **0.878** | ❌ |
| 性能: PSNR ep5 ≥ 21.87 | ≥21.87 | **24.37 dB** | ✅ |
| 分化: Y_L↔Y_N cos ≤ 0.9775 | ≤0.9775 | **0.7169** (0.655/0.772/0.723) | ✅ |

**裁决: 机制未活化 → 判失败** (低于边界规则下界 1.3, 不进"续训"分支)。
**但分化判据强通过**, 需特别记录其性质: 分支余弦从 0.9975 崩到 0.717 的同时, **融合权重把 L 路
关掉了** (`fusion w N/L/M = 0.603/0.004/0.393` vs 参照 `0.469/0.181/0.350`)。即低频谱监督让
Branch-L 学出了**与 N 不同的解**, 但该解**不产生亮度响应**, 融合层选择弃用它 —— 这是**退化解耦**
(靠放弃该路换取正交), 而非"L 路学会感知光照"。机制判据与分化判据在此**方向相反**, 说明
单看余弦会给出假阳性: **分化是必要条件, 不是充分条件**。

> 归因注记: `branch_warmup_epochs=5` 使分支监督权重在 ep5 才首次到达满值 (`frac=(epoch+1)/5`),
> 故 `use_lowfreq_L` 这一**监督侧**开关实际只以满强度作用了 1 个 epoch。预注册已就此设边界规则,
> 但实测 0.878 距下界 1.3 仍有明显差距, 故仍判失败 (不因该注记改判)。

**结论**: 两个 toggle 均**未通过机制判据** → 按 §6.14, 不启动 60ep 合并 run,
转入 **§6.6 (极暗增广) + §6.9 (感知损失)** 实现阶段。`phaseA_holdout` 继续跑满 5ep,
其用途不变: 提供**无泄漏** PSNR 参照 (不参与通过/失败判定)。

**副产物 (值得单独利用)**: `phaseA_l` 证明"低频谱监督可把 Branch-L 从 0.9975 推到 0.717 余弦"
—— 解耦手段本身**有效**, 失效环节在"融合层弃用该路"。后续若要走监督分工路线 (§6.2-B),
需同时解决**融合权重塌缩**问题, 否则任何靠 loss 塑形的分支都会被融合层抵消。

**同时暴露的架构问题 (与 H-m/H-l 独立)**: 三路输出余弦在**未分化**时恒为 0.99+
(参照 0.9967/0.9975, `phaseA_m` 0.9981/0.9949), 根因是 `raw_* = feat_spatial + attn_* * scale_*`
中 `feat_spatial` 主导而 `scale_*` 仅 0.018–0.029 —— 三路结构上被同一基特征锁死。
这是 §6.3「三路分工」在 v3 上无法成立的**结构性障碍**, 建议在 §6.6/§6.9 之前先评估
(如提高 scale 初始化 / 去掉残差基 / 分支输出不再共享 feat_spatial)。

#### 同质化根因定位 (2026-10-09 补充, 三分量逐层测量)

对三个 ckpt 在同一 clip 上**分别**测量「仅 Q 输出」「仅 attn 输出」「最终分支输出」的余弦:

| ckpt | scale N/L/M | 仅 Q 输出 cos (NL/NM/LM) | 仅 attn 输出 cos | 最终输出 cos |
|------|-------------|--------------------------|------------------|--------------|
| 参照 `pospair_quick` | 0.026/0.032/0.033 | −0.163 / −0.038 / −0.034 | **0.265 / −0.158 / −0.241** | 0.984 / 0.984 / 0.988 |
| `phaseA_m` | 0.029/0.025/0.018 | 0.141 / 0.128 / 0.002 | **−0.335 / −0.215 / −0.219** | 0.992 / 0.988 / 0.990 |
| `phaseA_l` | 0.010/0.012/0.023 | −0.023 / 0.096 / −0.070 | 0.329 / 0.242 / −0.259 | 0.369 / 0.993 / 0.371 |

**结论 (关键, 修正了此前的猜测)**: **分化在到达残差之前就已经存在** —— 三路 `attn_*` 输出
的内部余弦本身就接近 0 甚至为负 (−0.34 ~ +0.33), 三路 Q 也彼此近正交。也就是说
**`query_*` / `attn_*` 的差异化机制是工作的**, 三路内部的解**确实不同**。

真正的问题在 **`raw_* = feat_spatial + attn_* · scale_*` 这一步**: `scale_*` 只有 0.01–0.03,
而 `feat_spatial` 是同一份张量被三路**完全相同地**加进去。当 `|attn·scale| ≲ 0.03·|attn|`
远小于 `|feat_spatial|` 时, 输出恒等于「同一个 base + 一个极小扰动」, 余弦必然 → 1。
`phaseA_l` 的例外恰好印证: 它把 `scale_L` 训到 0.0231 (N/M 反而降到 0.010/0.012),
L 路的相对扰动变大, 输出余弦才掉到 0.369 —— **`scale` 的相对大小直接决定输出分化程度**。
`phaseA_l` 的诊断 `out cos` (0.65/0.77/0.72) 与本次 (0.37) 的差异来自采样 clip 不同 (全帧 vs 中心 5 帧),
但方向一致。

**因此 §6.3 的问题是「读出瓶颈」而非「表征瓶颈」**: 三路学出了不同的表征, 但共享残差基 + 小
`scale` 把它们**在读出端重新合并**了。这为后续改造给出了明确、低成本的靶点 (优先于重训):
- 提高 `scale_*` 初始化 / 放宽其增长 (当前零初始化, 5ep 才到 0.02 量级);
- 或把 `F_* = out_norm(base + attn·scale)` 改为**不再共享 base** (如各分支用独立投影);
- 或先做**零成本诊断**: 直接对 `attn_*` 输出测余弦来判定分工, 绕开残差合并
  (现有 `diag_v7r_v3_query_semantics.py` 已有的 `attn corr` 行即是此量)。

> 注意: `phaseA_l` 的输出余弦 0.369 说明**"输出已分化"并不蕴含"L 路感知光照"** —— 它的
> dark 响应反而是三路最小 (0.878)。故分化判据与机制判据必须并列看, 不可用前者替代后者
> (与 §6.14 "机制判据的局限"一致)。
