## 一、这份文档解决什么问题

前面的实验已经确认了三件事, 它们共同决定了最终结构应该长什么样:

1. **三分支在当前监督方式下是冗余的。** 三个分支各自都对同一张 GT 做 L1 回归, 因此
   最优解本来就是同一张图。零成本消融实测: 去掉任意一路、把它的融合权重分给另外两路,
   最终指标几乎不变 (详见 `03-v7r-v3-design.md` §6.17 附带发现)。
2. **用损失项逼迫三路分化会走向退化解。** 输出层去相关损失 `|cos(Y_i, Y_j)|` 的两个
   训练 seed 都退化了: 某一路输出常数图, 因为常数图减去自身均值后余弦恒为 0, 这是该
   损失最省力的解 (§6.17)。
3. **特征层的正交约束本来就在工作, 但它管不到输出层。** 三路 `attn_*` 内部余弦
   实测在 −0.34 到 +0.33 之间, 表征确实是分开的; 问题出在读出端——共享基特征
   `feat_spatial` 加上过小的 `scale_*`(0.018–0.029) 把三路重新合并。

结论是: **冗余的根因不在结构, 而在监督目标。** 三路输出之所以相同, 是因为它们被要求
预测同一个东西。因此正确的做法不是加损失去惩罚"相似", 而是**让每一路预测不同的东西**。

这份文档给出的就是按这一原则确定的最终结构。

## 二、总体结构

```
输入: 低光视频片段 [B, T=5, 3, H, W]
  │
  ├─ Stage 1  共享编码器 SharedEncoder (逐帧, 0.410M 参数)
  │           输出 F2 [B,T,64,H/2,W/2]
  │
  ├─ Stage 2  特征投影 + 像素级时序对齐
  │           feature_proj: 1×1 卷积 64→128
  │           PixelTemporalAttentionSimple: 3D 卷积, 窗口 3, 0.024M
  │           → feat_spatial [B, 128, H/2, W/2]
  │
  ├─ Stage 3  帧级时序建模 MatrixRWKV (0.853M)
  │           SpatialSummary(GAP) → frame_tokens [B, T, 192]
  │           2× MatrixRWKVTimeMix(矩阵值状态 S∈R^{d×d}, 数据相关衰减)
  │           → rwkv_ctx [B, T, 192]
  │
  ├─ Stage 4  三路查询 TCA (TripleQueryTCA, 0.374M)
  │           三路独立 Query + 共享统计 KV + 三路 RWKV 空间注意力
  │           → F_N, F_L, F_M [B, 128, H/2, W/2]
  │
  ├─ Stage 5  三个源专用分支 (各自独立监督目标, 见第四节)
  │           BranchN (0.556M): 时序均值目标
  │           BranchL (0.609M): 光照归一化低频目标
  │           BranchM (0.804M): 对齐参考帧目标
  │           → Y_N, Y_L, Y_M [B, 3, H, W]
  │
  └─ Stage 6  自适应融合 V7RFusion (0.013M)
              逐像素门控权重 (softmax, Σw=1) + 恒等初始化精化卷积
              + 中心帧残差门 tanh(gamma) × X_center
              → O_t [B, 3, H, W]

总参数: 3.742M (bs=2, 256×256 裁剪, 显存约 10.8GB)
```

各模块参数量:

| 模块 | 参数量 | 占总量 |
|------|--------|--------|
| encoder | 0.410M | 10.9% |
| pixel_temporal | 0.024M | 0.6% |
| spatial_summary | 0.099M | 2.6% |
| matrix_rwkv | 0.853M | 22.8% |
| triple_query_tca | 0.374M | 10.0% |
| branch_N | 0.556M | 14.9% |
| branch_L | 0.609M | 16.3% |
| branch_M | 0.804M | 21.5% |
| fusion | 0.013M | 0.3% |
| **合计** | **3.742M** | 100% |

## 三、逐模块说明

### 3.1 共享编码器与像素级时序对齐

编码器对五帧逐帧处理, 输出二分之一分辨率的特征。三帧窗口(前后各一帧加中心帧)经过
3D 卷积建模像素级时序关系, 输出对齐后的空间特征 `feat_spatial`。

这一层的作用是提供**三路共享的基特征**。它是后续所有分支的共同起点, 本身不做源分离。

### 3.2 帧级时序建模 (MatrixRWKV)

SpatialSummary 用全局平均池化把每帧的空间特征压成一个 192 维 token, 得到 `[B, T, 192]`
的帧级序列。两个 MatrixRWKV 块在这个序列上做递推, 状态是矩阵而非向量:

$$S_t = S_{t-1} \cdot \mathrm{diag}(w_t) + v_t^\top k_t,\qquad w_t = \exp(-\exp(\text{base} + \mathrm{LoRA}(x_t)))$$

矩阵值状态让每一帧能存下更丰富的帧间关系; 数据相关衰减 `w_t` 让模型自己决定遗忘速度。
这一步的产物 `rwkv_ctx` 是**帧级语义态势**——"当前这段视频整体上更接近哪种退化条件"。

它参与后续的方式是门控三路统计量, 见下节。实测该门控从初始 0 增长到 1.2–1.8,
说明优化器确实在用这条通路 (不是死计算)。

### 3.3 三路查询 TCA

这是结构上做源分离的核心。它的设计是"**共享 KV、差异化 Query**":

**共享 KV(键值)** 由三个统计量拼接后经 1×1 卷积投影得到, 对应三种退化的统计特征:

| 统计量 | 计算方式 | 对应的退化假设 |
|--------|----------|----------------|
| `ctx_mean` | 五帧特征逐像素求均值 | 成像噪声: 帧间独立, 平均即可抑制 |
| `ctx_smooth` | 均值特征再做 7×7 平均池化 | 光照: 帧间慢变, 低频主导 |
| `ctx_diff` | 中心帧与各邻帧绝对差的最大值 | 运动: 帧间结构化位移 |

三个统计量先被 MatrixRWKV 的中心帧上下文门控一次
(`s_k = ctx_k · (1 + g_k)`, `g` 由零初始化线性层产生), 再拼接投影成共享 KV。
零初始化保证初始时 `s_k = ctx_k`, 不扰动既有表示; 同时因为被门控的量非零,
梯度从第一步就能到达 MatrixRWKV, 不存在乘法双零的死锁。

**三路独立 Query** 由三个独立的 `LayerNorm + 1×1 卷积` 从同一个 `feat_spatial` 生成。
三路 Query 分别与共享 KV 做 RWKV 空间注意力 (线性复杂度双向扫描), 得到三路注意力输出。

**残差与缩放** 把三路注意力加回共享基特征:

$$F_k = \mathrm{Norm}\big(\texttt{feat\_spatial} + \mathrm{attn}_k \cdot \mathrm{scale}_k\big),\quad k \in \{N, L, M\}$$

`scale_k` 是 LayerScale 形式的可学习逐通道缩放, 零初始化, 因此初始时 `F_N = F_L = F_M`,
训练中各自增长。

同时计算一路特征层正交损失, 惩罚三路特征的余弦相似度。

> **实测状态**: 三路 `attn_*` 的输出内部余弦在 −0.34 到 +0.33 之间, 说明 Query 的
> 差异化确实产生了不同的注意力表征。但 `scale_*` 只长到 0.018–0.029, 三路特征仍被
> 共享基特征 `feat_spatial` 主导, 这是输出层同质化的直接原因。

### 3.4 三个源专用分支

| 分支 | 结构 | 物理依据 | 输出 |
|------|------|----------|------|
| BranchN | 2×NAFBlock + 通道注意力(SE) + Upsample3x3 | 成像噪声: 帧间独立, 可用时序均值抑制 | Y_N |
| BranchL | 2×NAFBlock + 光照图预测头 + Retinex 分解 + 可学习 gamma | 光照: Retinex 的 `I = R ⊙ L^γ` | Y_L |
| BranchM | 2×NAFBlock + 光流估计 + 可变形对齐 + 置信度门控 | 运动: 需要显式对齐而非平均 | Y_M |

BranchL 的光照头零初始化, 初始输出 `sigmoid(0) = 0.5`; BranchM 只用中心帧的相邻两帧
估计光流——这是经过验证的取舍: 用全部四帧会引入过多噪声 (R4 的教训)。

三个分支的输入分别是 `F_N`、`F_L`、`F_M`, 输出都是三通道 RGB 图, 分辨率回到原图大小。

> **实测状态**: 三个分支各自都能独立重建完整图像, 逐分支 PSNR 都在 17–27 dB。
> 这正是冗余的体现——它们在做同一件事。

### 3.5 自适应融合

融合层用一个小卷积网络从 `[Y_N, Y_L, Y_M, X_center]` 四路拼接输入预测逐像素权重,
经 softmax 归一化后加权求和:

$$Y_{\text{fused}} = w_N Y_N + w_L Y_L + w_M Y_M,\qquad \sum_k w_k = 1$$

之后经过一个恒等初始化的 3×3 精化卷积, 再叠加中心帧残差:

$$O_t = \mathrm{clamp}\big(\mathrm{refine}(Y_{\text{fused}}) + \tanh(\gamma) \cdot X_{\text{center}},\ 0, 1\big)$$

`gamma` 从 0 初始化并增长(实测 `tanh(gamma)` 达 0.49–0.60), 意味着最终输出有相当一部分
直接来自输入中心帧。这是当前模型能保持指标的重要原因, 也说明融合层对三分支的依赖
没有表面看起来那么强。

融合权重网络末层零初始化, 因此初始时三路权重各为 1/3, 初始输出等于三分支均值——
这一点对受控 A/B 很重要。

## 四、关键设计决定: 让三路预测不同的东西

前面三节描述的是**已经实现**的结构。本节描述的是由实验结论推出的**必须的修改**。

### 4.1 当前的问题在监督, 不在结构

三个分支接收不同的特征 `F_N`、`F_L`、`F_M`(这些特征实测确实不同), 但它们的**监督目标
完全相同**——都是同一张 GT, 都用 L1 回归。这直接决定了最优解:

$$\min_{Y_k} \|Y_k - X\|_1 \ \Rightarrow\ Y_N^* = Y_L^* = Y_M^* = X$$

三路输出相同不是缺陷, 而是这个目标下的**正确解**。任何惩罚"输出相似"的附加损失都是在
和一个全局最优解对抗, 效果上必然要么无效, 要么把模型推向退化解(§6.17 两种退化形态)。

### 4.2 修改方案: 分支专属监督目标

保留三分支结构, 把"各自都对同一张 GT 做 L1"改为"**各自对不同的目标做 L1**"。
三个目标都是从输入片段自身构造的, 不需要额外标注:

| 分支 | 监督目标 | 构造方式 | 为什么这一路该学它 |
|------|----------|----------|--------------------|
| BranchN | 时序均值目标 $X^{\text{avg}}$ | 邻帧经光流对齐后与中心帧求均值 | 成像噪声帧间独立, 平均是它的最优估计; 对齐后的平均不会引入运动伪影 |
| BranchL | 光照归一化目标 $X^{\text{illu}}$ | 对 $X^{\text{avg}}$ 做大面积低通得到光照场 $\hat{L}$, 目标为 $X^{\text{avg}} / \hat{L}$ | 光照是低频、慢变的全局量; 归一化后这一路只负责曝光与白平衡, 不必重建纹理 |
| BranchM | 对齐参考目标 $X^{\text{align}}$ | 相邻帧按光流 warp 到中心帧时刻 | 运动退化的修复结果就是"对齐后的帧"; 这一路的输出天然是位移校正量 |

三个目标互不相同, 因此三路输出的最优解不再重合。融合层面对三张真正不同的图,
才有"选择"的余地。

### 4.3 为什么这比加损失项好

**冲突在目标层被消除, 而不是在损失层被压制。** 前一版的做法是让三路都对同一个 GT 回归,
再加一个惩罚项把它们的输出推开。此时主损失和惩罚项方向相反, 训练在两者之间找平衡,
而平衡点恰好是"某一路放弃"这种退化解。

新做法里三个目标本身不同, 因此没有任何一路需要"放弃"——每一路都有明确的、可达到的
正确输出。融合损失仍然是原来的 L1(对最终输出 $O_t$ 与 GT), 不需要改动。

### 4.4 需要改动的代码

改动集中在监督侧, 融合与主干不变:

1. `datasets/sdsd_dataset.py`: 在返回中心帧 GT 之外, 额外构造并返回三个目标图。
   光流可用现有 BranchM 的 `FlowEstimator` 提供, 或在数据侧用简单块匹配近似。
2. `models/golf_v7r/loss.py`: `_branch_loss` 由"三路对同一 GT"改为"每路对各自目标"。
   保留 `w_branch_N/L/M` 三个权重, 便于单独调节。
3. `train_golf_v7r_v3.py`: 把三个目标图透传到损失函数。

`models/golf_v7r/triple_query_tca.py`、三个分支、融合层都不需要改。

### 4.5 判据

因为本机 5 epoch 训练的 seed 间 PSNR 方差实测达 3 dB(§6.17), 不能用最终 PSNR 判断
这个改动是否有效。应当用机制判据:

1. **三路输出余弦是否下降**——这是本次改动直接针对的量;
2. **每一路与它自己的目标之间的误差**是否下降——确认每一路都在学它该学的东西;
3. **三路单独 PSNR 是否都保持合理**——确认没有出现"某一路放弃"的退化解;
4. **消融测试**: 去掉任一路后最终指标应明显变差。若仍然可替代, 说明三分支没有形成
   分工, 需要重新审视结构本身。

## 五、明确不再采用的做法

以下几项都经过实验验证, 记录在此以免重走:

| 做法 | 结论 | 证据 |
|------|------|------|
| 输出层去相关损失 `\|cos(Y_i,Y_j)\|` | 两 seed 均退化解, 常数输出即可使该项为 0 | §6.17 |
| 融合算子权重下限 (ε-floor) | 结构上有效(消除像素级塌缩), 但无功能收益 | §6.16 A/B |
| 调大 `scale_*` 打破共享基特征主导 | 曲线非单调, `mult=1` 已是局部最高点, 训练主动选择高余弦 | §6.14 因果干预 |
| 单靠特征层正交约束 (`ortho_loss`) | 特征层确实正交, 但管不到输出层 | §6.14 |
| `motion_aware_diff` / `use_lowfreq_L` 两个开关 | 机制判据全部未达标, 效应量 −0.07 / +0.30 dB | §6.14 |

## 六、当前状态与下一步

结构本身(第一至三节)已经实现并训练到 60 epoch, 跨域指标 DID 20.17 dB。
第四节的目标构造改造尚未实现。

下一步按优先级:

1. 实现第四节的分支专属监督目标, 用第五节的四条机制判据验证;
2. 若判据 4(消融)仍显示三路可替代, 则需要重新评估"三分支"这个结构选择本身——
   此时应考虑回到单分支或改用加性级联, 而不是继续在监督侧做文章;
3. §6.6 极暗增广与 §6.9 感知损失尚未训练验证, 配置已就绪
   (`configs/golf_v7r_v3_phaseD_dark_perc.yaml`)。
