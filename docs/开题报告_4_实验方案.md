# 4 实验方案

> 课题：基于三源解耦修复（Tri-Source Decoupled Restoration, TSDR）框架的低光视频增强方法
> 网络名：**TSD-Net**（对应本项目代码中的 `TFSNet`，配置 `configs/delta_flight10m5.yaml`）

---

## 4.1 实验总体方案

本课题以"低光视频增强"为研究任务，围绕三源解耦网络 TSD-Net 展开实验验证。核心科学假设为：**光照退化、成像噪声与运动扰动在时域差分上呈现本质不同的统计行为，通过对三者解耦并分配专用处理分支，可降低多分支梯度冲突、提升增强质量与跨域泛化能力**。实验总体方案遵循"模型构建 → 分阶段训练 → 定量评估 → 消融归因 → 对比验证 → 跨域泛化"的闭环流程，系统验证 TSDR 框架及各核心模块的有效性。

### 4.1.1 整体实验流程

1. **模型构建**：依据 `configs/delta_flight10m5.yaml` 搭建 TSD-Net，数据流为 `PyramidEncoder → DPE → TCA(RWKV) → {ISPN, NDPN, MCPN} → CXG → SGRF`，参数量约 1.5 M；输入为 $T=5$ 的多帧滑窗，监督中心帧的增强输出。
2. **分阶段训练**：采用 Mark4 相位调度策略（Phase 1 Warmup → Phase 1 Main → Phase 1.5 → Phase 2），按 epoch 边界逐级解锁 NDPN/MCPN/CXG 三源分支并切换损失项，避免早期多分支梯度冲突导致的收敛停滞（`train.py:336-354`）。
3. **定量评估**：训练中每隔 `val_interval=10` 个 epoch 在 SDSD 测试集上验证 PSNR / SSIM / LPIPS，并保存最佳权重 `best.pth` 及各相位 checkpoint（`phase1_warmup.pth`/`phase1.pth`/`phase15.pth`）。
4. **消融实验**：对核心模块逐项剥离——TCA 的 RWKV 空间扫描、DPE 退化先验、NDPN/MCPN 三源分支、CXG 交叉激励门、SGRF 阶段式融合、Kendall 不确定性加权等，量化各模块对最终 PSNR 的贡献。遵循"单变量对照、逐项隔离"原则（吸取 v5 阶段组合实验无法归因的教训）。
5. **对比实验**：与代表性低光视频增强方法（基于 Retinex/迭代增强的视频方法如 LAN、SDSDNet，以及 Zero-DCE 系列单帧方法的多帧适配）在**相同训练集、相同裁剪、相同 $T=5$ 窗口**下训练或复现，统一在 SDSD 测试集与 DID 测试集上给出 PSNR/SSIM/LPIPS 三维量化对比。
6. **跨域泛化**：将 SDSD 上训练的最佳模型直接在 DID 测试集上推理（零样本迁移，不参与训练），评估模型对未见光照/运动分布的泛化能力，使用项目内置 `eval_did.py` 流程。

### 4.1.2 训练超参数与策略

下表给出主实验的训练配置（源自 `train.py` 与 `configs/delta_flight10m5.yaml`）：

| 项目 | 配置 | 说明 |
|------|------|------|
| 优化器 | AdamW | lr=8e-4，weight_decay=1e-4 |
| 梯度裁剪 | 5e-1 | `grad_clip=0.5`，防止 RWKV chunk-wise cumsum 数值溢出 |
| 批次 | batch=2，grad_accum=8 | 等效批大小 16，缓解小数据集样本多样性不足 |
| 训练轮数 | 80 epoch | P1W(0–4)+P1(5–10)+P1.5(11–25)+P2(26–80) |
| 数值精度 | fp32，AMP 关闭 | 保证四方向 Bi-WKV 递归的数值稳定 |
| 随机种子 | 42 | `utils/misc.py:seed_everything`，保证可复现 |
| 学习率调度 | 相位相关 | 见下表 |

| 相位 | Epoch | 学习率 | 损失/分支状态 |
|------|-------|--------|----------------|
| Phase 1 Warmup | 0–4 | 8e-6 → 8e-4（线性 warmup） | 仅 pix+ssim+illum+align+gain_sup，NDPN/MCPN 置零 |
| Phase 1 Main | 5–10 | 6e-4（固定） | 同上，三源分支仍截断 |
| Phase 1.5 | 11–25 | 6e-4 → 4.4e-4（线性过渡） | 解锁 NDPN/MCPN，unlock_ratio 线性 0→1，启用 aux 损失 |
| Phase 2 | 26–80 | 4e-4 → 1.6e-5（阶梯衰减） | 全三源恢复 + CXG，启用感知/频域/inter/感知解耦损失，取消 diag_prior |

### 4.1.3 损失函数

总损失采用 **Kendall 不确定性加权**（`losses/losses.py:286-292`）聚合多任务项，使大损失任务自动降权、小损失任务提权：

$$\mathcal{L}_{\text{total}}=\sum_i \frac{1}{2\exp(s_i)}\mathcal{L}_i+\frac{1}{2}s_i,\quad s_i=\log\sigma_i^2$$

各损失项包括：Charbonnier 像素损失 $\mathcal{L}_{\text{pix}}$、$1-\text{SSIM}$、多层 VGG16 感知损失（relu1_2/relu2_2/relu3_3 加权，`losses/losses.py:45-107`）、FFT 频域纹理损失（幅度可选 + 相位）、光照图边缘感知平滑 / TV / 防塌缩 $\mathcal{L}_{\text{illum\_spatial}}$、中间乘法监督 $\mathcal{L}_{\text{inter}}$（$I_{s2}\times\text{gain}$）、NDPN/MCPN 辅助监督、亮度保持正则等。损失项随相位激活，实现"先收敛无冲突的 ISPN 路径，再逐级解锁三源分支"。

## 4.2 数据集与预处理

### 4.2.1 SDSD 数据集（主训练与评测集）

SDSD（Static-Dynamic Static-Dynamic）是面向低光视频增强的真实拍摄配对基准数据集，提供低光视频与对应正常光视频的严格时空配对。本研究使用其 **indoor（室内）** 划分作为主训练与测试集。目录组织遵循 `序列/帧` 二级结构，输入帧位于 `.../indoor/input/<seq>/*.png`，GT 帧位于 `.../indoor/GT/<seq>/*.png`，输入与 GT 按文件名一一配对（`datasets/sdsd_dataset.py:30-54`）。

- **训练集**：SDSD indoor，共 70 个序列、约 2064 个训练样本（每样本为一个中心帧的滑窗切片）；
- **测试集**：SDSD test 的 10 个序列；快速验证默认取前 5 个序列（约 620 帧，`max_val_seqs=5`）以控制推理耗时，最终评测使用全部序列；
- **场景特性**：室内场景、相机运动相对受限、光照较均匀但伴随显著噪声与低亮度，适合验证"光照解耦 + 时序去噪"路径。

### 4.2.2 DID 数据集（跨域泛化评测集）

DID（Dancing in the Dark，ICCV 2023）相比 SDSD 具有更丰富的真实场景、更大的相机运动和更精确的空间对齐，由多相机在多种光照条件下采集。本研究**仅使用其 test 划分进行零样本跨域评测，不参与训练**，用于评估模型对未见光照/运动分布的泛化能力。DID 测试目录组织为 `low-light/<video>/*.png` 与 `GT/<video>/*.png`（`eval_did.py:83-86`）。

### 4.2.3 数据组织与滑窗监督

- **滑动窗口**：窗口长度 $T=5$、半窗 $k=2$，对每个中心帧构造 $\{I_{t-2},I_{t-1},I_t,I_{t+1},I_{t+2}\}$ 的多帧输入；窗口边界采用 clamp 填充（`sdsd_dataset.py:59-65`）防止越界；
- **中心帧监督**：仅对窗口中心帧 $I_t$ 的输出 $\hat{X}_t$ 与 GT 配对监督，复用邻帧提供时序信息而无需多帧 GT 标注；
- **样本索引**：按序列遍历，每帧都作为一个中心帧样本，滑窗在序列内部构造，跨序列不混窗。

### 4.2.4 预处理与数据增强

| 阶段 | 操作 | 说明 |
|------|------|------|
| 读取 | PIL → RGB → `np.float32/255.0` → `[3,H,W]` 张量 | 归一化到 [0,1]（`sdsd_dataset.py:12-15`） |
| 训练增强 | 随机裁剪 256×256 | clip 与 target 在相同位置裁剪，保证空间配对 |
| 训练增强 | 随机水平/垂直翻转 | 50% 概率联合作用于 clip 与 target（`transforms.py:17-24`） |
| 训练增强 | 随机时序反转 | 50% 概率对 clip 沿时间维翻转，增强时序对称性（`transforms.py:27-30`） |
| 验证 | 无随机增强 | 中心裁剪到 `val_crop_size=256` 控制推理耗时 |
| 推理 | Tiles 推理 | tile_size=256，overlap=32，边界 reflect-padding（`utils/inference.py`） |
| 推理 | LRU 帧特征缓存 | 容量 64，复用已编码帧金字塔特征，降低长视频重复计算 |

## 4.3 评价指标与分析

### 4.3.1 全参考客观指标

为全面衡量增强质量，本研究采用三类互补指标：像素保真、结构相似、感知质量。

- **PSNR（峰值信噪比，dB）**：基于 MSE 的对数指标，$\text{PSNR}=10\log_{10}(1/\text{MSE})$，反映像素级保真度，**越大越好**。本研究采用全帧平均 PSNR 作为**主指标**（`utils/metrics.py:8-12`）。
- **SSIM（结构相似性）**：基于亮度/对比度/结构三因子的窗口相似度，采用 11×11 高斯窗（σ=1.5）：
  $$\text{SSIM}=\frac{(2\mu_x\mu_y+c_1)(2\sigma_{xy}+c_2)}{(\mu_x^2+\mu_y^2+c_1)(\sigma_x^2+\sigma_y^2+c_2)},\quad c_1=0.01^2,\ c_2=0.03^2$$
  反映结构保持能力，**越大越好**（`utils/metrics.py:15-16`、`losses/losses.py:23-35`）。
- **LPIPS（学习感知图像块相似度）**：基于 AlexNet 深度特征的距离度量，反映人眼感知质量，**越小越好**。通过 `lpips` 库（AlexNet backbone）在 GPU 上计算；库不可用时自动降级跳过（`train.py:35-36, 273-283`），作为感知质量补充。

### 4.3.2 指标计算与分析方法

- **计算粒度**：逐中心帧计算 PSNR/SSIM/LPIPS，再在测试集全体帧上取算术平均（全参考平均），避免序列级聚合导致的长视频偏置；
- **评估频率**：训练中每 10 个 epoch 验证一次，记录 `best.pth` 与各相位 checkpoint；
- **收敛与活跃度诊断**：除最终数值外，结合训练日志监控关键中间量——DPE 的 $s_{\text{illum}}$ 均值/标准差（防塌缩）、ISPN gain 分布、NDPN/MCPN 的 γ 值、曲线 $\alpha$ 等（`train.py:228-244`），诊断各模块是否塌缩或活跃，判断三源解耦是否真正生效；
- **公平对比**：对比方法在相同训练集、相同裁剪与相同输入窗口 $T=5$ 下训练或复现，统一在 SDSD 与 DID 上评估，全部采用 fp32 与相同 tile 推理策略，消除数值精度差异；
- **跨域分析**：以 SDSD → DID 的 PSNR 下降幅度量化泛化损失，并与纯图像域方法对照，分析时序特征学习对跨域鲁棒性的影响；
- **感知—失真权衡**：参照 Blau & Michaeli (CVPR 2018) 的感知-失真权衡理论，将 PSNR/SSIM（失真侧）与 LPIPS（感知侧）联合报告，避免单一指标偏置。

## 4.4 所需设备、软件与材料

### 4.4.1 硬件设备

| 设备 | 规格 | 用途与说明 |
|------|------|------------|
| GPU | NVIDIA GeForce RTX 4090（24 GB） | 单卡训练，fp32 精度 |

### 4.4.2 软件与框架

- **深度学习框架**：PyTorch（含 torchvision）；
- **核心依赖**（见 `requirements.txt`）：Pillow（图像 I/O）、PyYAML（配置解析）、numpy、tqdm（进度条）；
- **评估扩展**：`lpips`（AlexNet，LPIPS 指标，可选，缺失时自动降级跳过）；
- **感知损失前置权重**：VGG16 ImageNet1K_V1 分类权重，由 torchvision 自动下载，仅用于 VGG 感知损失特征提取（参数冻结）；离线不可用时回退随机初始化并告警（`losses/losses.py:53-63`）；
- **操作系统**：Linux（Ubuntu），CUDA 环境；
- **主要入口命令**：
  - 训练：`python train.py --config configs/delta_flight10m5.yaml`
  - 推理：`python infer.py`
  - 跨域评测：`python eval_did.py --config configs/delta_flight10m5.yaml --checkpoint outputs/sdsd_f10m5/best.pth`
