## 二、2.1 节问题建模的批判性审视

### 2.1 当前建模的三大逻辑缺陷

**缺陷 1：单帧退化模型 $I_t = X \odot \ell_t + n_t$ 与三分量方差分解 $\text{Var}(I_t - X) = \sigma^2_{\text{img}} + \sigma^2_{\text{illu}} + \sigma^2_{\text{dyn}}$ 数学上无法互推**

对当前模型 $I_t = X\odot\ell_t + n_t$ 展开：

$$\text{Var}(I_t - X) = \text{Var}(X\odot(\ell_t-1) + n_t) = \text{Var}(X\odot(\ell_t-1)) + \sigma^2_n + 2\text{Cov}(\cdot)$$

这里**根本导不出 $\sigma^2_{\text{dyn}}$**——因为单帧模型中 $X$ 是常数，运动扰动无从体现。$\sigma^2_{\text{dyn}}$ 在数学上是一个"凭空插入"的分量。

**缺陷 2：三源"在信号域可分离"的说法过于强断言，且与你后续 SWD 的实际行为矛盾**

- 在低光条件下，$\sigma^2_{\text{img}}$（信号相关的泊松-高斯噪声）与 $\sigma^2_{\text{illu}}$（乘性光照退化）在 LL 子带内实际上是**耦合的**——低光→ $\ell_t\downarrow$ → 信噪比↓ → 泊松噪声方差随信号 $y$ 增大而增大（[Foi et al., TIP 2008](https://webpages.tuni.fi/foi/papers/Foi-PoissonianGaussianClippedRaw-2007-IEEE_TIP.pdf) 公式 $\sigma^2 = ay + b$）
- 这也是你文档中 SWD 节坦承的："旧 DWT-LFF ...TFDE 的 IntensityHead 被全 HF 噪声压制（输入 norm 达 60~113），退化分离失效"

**缺陷 3：三源时域特性描述与后续 SGRF 顺序（去噪→去模糊→提亮）的动机链条不完整**

当前 2.1 节说 $\sigma^2_{\text{illu}}$ 是"帧间缓慢变化，低频主导"，但没有直接推出"为什么提亮要放在最后"。这个关键顺序动机（"若提亮在前则会放大噪声"）在 2.8 节才补上，理论建模章节的连贯性打断了。

### 2.2 建议改写方案——时域差分驱动的三源解耦建模

以下是我推荐替换当前 2.1 节的**完整改写**：

---

### **2.1 问题建模：三源解耦修复 (Tri-Source Decoupled Restoration)**

**主张。** 我们将低光视频增强重新表述为一个 **三源解耦修复问题 (tri-source decoupled restoration problem)**。核心洞察是：**光照退化、成像噪声与运动扰动在时域上呈现完全不同的统计行为，因此不应在早期共享同一处理路径**。光照退化主要破坏曝光一致性并使 brightness constancy 假设失效；成像噪声表现为帧间独立的随机扰动；运动退化则依赖可靠的时序支持与对齐。

**单帧退化模型**。 沿用低光成像的物理模型（[Foi et al., TIP 2008](https://webpages.tuni.fi/foi/papers/Foi-PoissonianGaussianClippedRaw-2007-IEEE_TIP.pdf)；[Wei et al., ICCV 2019](https://openaccess.thecvf.com/content_ICCV_2019/papers/Wang_Enhancing_Low_Light_Videos_by_Exploring_High_Sensitivity_Camera_Noise_ICCV_2019_paper.pdf)），观测帧 $I_t$ 与潜在干净信号 $X_t$ 之间满足：

$$I_t = X_t \cdot \ell_t + n_t, \quad n_t \sim \mathcal{P}(\alpha \cdot X_t\ell_t) + \mathcal{N}(0, \sigma_r^2) \tag{1}$$

其中 $\ell_t \in (0,1)$ 为逐像素光照衰减系数，$n_t$ 服从泊松-高斯混合分布——泊松部分来自光子散粒噪声（signal-dependent），高斯部分来自读出噪声（signal-independent）。

**时域差分揭示的三源结构**。 视频任务的关键差异在于时域。引入时域差分算子 $\Delta_t I_t = I_t - I_{t-1}$：

$$\Delta_t I_t = \underbrace{X_t\cdot(\ell_t - \ell_{t-1})}_{\Delta^{\text{illu}}_t\ \text{(光照源)}} + \underbrace{(n_t - n_{t-1})}_{\Delta^{\text{img}}_t\ \text{(成像源)}} + \underbrace{(X_t - X_{t-1})\cdot \ell_t}_{\Delta^{\text{dyn}}_t\ \text{(动态源)}} \tag{2}$$

三个差分分量在**时空统计特性**上有本质区别，见 Table 1。

**Table 1. 三源扰动的时空统计特性对比**

| 分量 | 空间分布 | 时域特性 | 频域主导 | 物理来源 | 对应模块 |
|------|---------|---------|---------|---------|---------|
| $\Delta^{\text{illu}}_t$ | 全局或大块区域 | 慢变，均值非零 | 低频 (LL 子带) | 自动曝光切换、光源闪烁 [Land & McCann 1971](https://doi.org/10.1364/JOSA.61.000001) | **ISPN** |
| $\Delta^{\text{img}}_t$ | 逐像素独立 | 帧间独立，零均值 | 全频段，HF 显著 | 光子散粒 + 读出噪声 [Foi et al. 2008](https://webpages.tuni.fi/foi/papers/Foi-PoissonianGaussianClippedRaw-2007-IEEE_TIP.pdf) | **NDPN** |
| $\Delta^{\text{dyn}}_t$ | 空间稀疏，运动边界集中 | 非零均值，方向性 | 中高频 | 物体运动、相机抖动 [Baker et al. 2011](https://doi.org/10.1007/s11263-010-0390-2) | **MCPN** |

**核心可分性假设 (工程层面而非数学层面)**。 在像素域，$\Delta^{\text{illu}}$、$\Delta^{\text{img}}$、$\Delta^{\text{dyn}}$ 三者**不可解析分离**——它们通过 $X_t$ 和 $\ell_t$ 相互耦合。但我们主张：**通过合适的表征变换 $\mathcal{T}$，可以构造出三路先验信号 $\{p_{\text{illu}}, p_{\text{img}}, p_{\text{dyn}}\}$，使得每路先验以某一扰动为主导**：

$$\mathcal{T}: \{I_{t-k},\ldots,I_{t+k}\} \mapsto \{p_{\text{illu}}, p_{\text{img}}, p_{\text{dyn}}\} \tag{3}$$

**TSDR 框架的具体实现**。 我们将 $\mathcal{T}$ 分解为两个协同变换：

- **SWD (空域小波分流)**：利用 Haar DWT 将频域分离，LL 子带天然对应 $\Delta^{\text{illu}}$ 的低频主导性，HF 子带对应 $\Delta^{\text{img}}$ 与结构成分的高频分布。这与 [AFD-LLIE](https://doi.org/10.48550/arxiv.2409.01641) 通过 Laplace 金字塔将 LLIE 解耦为"低频光照 + 高频噪声"两个子任务的思路一致，但我们将其扩展到三源。

- **TCA (时序对应矩阵 $C_{t,\Omega}$)**：构造帧间空间对应关系，$C_{t,t'}$ 的对角线占优程度直接指示 $\Delta^{\text{dyn}}_t$ 的强度——对角线扩散越严重，运动越剧烈；对角线置信度越低，多帧融合去噪越不可靠。这与 [IJCAI 2025 LLVE](https://www.cse.cuhk.edu.hk/~byu/papers/C275-IJCAI2025-LLVE.pdf) 利用 cross-frame correspondence 建立 view-independent 约束的思路同源。

由此得到三路先验：

$$p_{\text{illu}} = \text{SWD}_{\text{LL}}(F_t), \quad p_{\text{img}} = \text{diag}(C_{t,\Omega}) \oplus \text{SWD}_{\text{HF}}(F_t), \quad p_{\text{dyn}} = \text{off-diag}(C_{t,\Omega}) \tag{4}$$

三路先验分别输入 ISPN、NDPN、MCPN，每个专用网络在**接近单一主导扰动**的信号上进行处理，避免了梯度冲突（该点与 [PDHAT (TMM 2024)](https://doi.org/10.1109/tmm.2024.3355634) 的感知解耦思想一致——不同退化属性分配到异构分支，独立损失独立回传）。

**为什么 SGRF 采用 "去噪 → 去模糊 → 提亮" 顺序**。 由式 (1)，若先施加提亮变换 $I_t / \ell_t$，则噪声 $n_t / \ell_t$ 会被同比放大——在暗区 $\ell_t \to 0$ 时噪声爆炸。因此正确顺序必须是：先在原始亮度域抑制 $\Delta^{\text{img}}$（NDPN → S1），再修正帧间 $\Delta^{\text{dyn}}$ 引起的对齐偏差（MCPN → S2），最后施加光照补偿 $\ell_t^{-1}$（ISPN → S3）。这一顺序与 [DP3DF (AAAI 2023)](https://ojs.aaai.org/index.php/AAAI/article/view/25409/25181) 提出的联合处理架构中隐含的处理顺序一致，但我们通过显式的三阶段 SGRF 使这一物理约束成为**架构级归纳偏置**。

---

**改写方案的核心优势**：

1. **式 (2) 的时域差分公式直接自然导出三源**，取代了原文突兀的方差分解
2. 明确区分了"数学上不可分离"和"工程上可通过表征构造先验"，避免了原文"三源可分离"的强断言
3. 将 SWD 和 TCA 的作用统一到"三路先验构造器" $\mathcal{T}$ 的框架下，理论与架构无缝衔接
4. SGRF 三阶段顺序有了严格的物理推导（式 (1) 的乘性光照结构 + 噪声放大不等式），而非工程直觉
5. 与文献的对话点清晰——AFD-LLIE 是频域二源解耦，IJCAI 2025 是二源分解，你是**三源 + 时域差分驱动**的原创贡献

## 三、三源分解合理性的文献支撑

### 3.1 σ²_img (成像噪声) 的物理建模——**证据强**

| 文献 | 结论 | 支持强度 |
|------|------|---------|
| [Foi et al., TIP 2008](https://webpages.tuni.fi/foi/papers/Foi-PoissonianGaussianClippedRaw-2007-IEEE_TIP.pdf) (被引 1001) | 泊松-高斯模型：$\sigma^2 = ay + b$，Poisson (光子散粒) + Gaussian (读出) | ⭐⭐⭐⭐⭐ 经典 |
| [Wang et al., ICCV 2019](https://openaccess.thecvf.com/content_ICCV_2019/papers/Wang_Enhancing_Low_Light_Videos_by_Exploring_High_Sensitivity_Camera_Noise_ICCV_2019_paper.pdf) | 低光视频专用噪声模型：$y_i = K(S_i + D_i + R_i)$，Poisson shot + Poisson dark + Gaussian read | ⭐⭐⭐⭐⭐ 视频专用 |
| [Wei et al., "Physics-based Noise Modeling"](https://doi.org/10.48550/arxiv.2108.02158) | 极低光下需要更多分量：shot + read + row + quantization noise | ⭐⭐⭐⭐ |
| [Monakhova et al., "Dancing under the stars"](https://arxiv.org/pdf/2204.04210) (CVPR 2022) | 星光级低光视频噪声：shot + read + row + temporal row + quantization + fixed pattern + periodic | ⭐⭐⭐⭐⭐ 极端场景 |

**结论**：成像噪声本身在物理上就是**多源合成的**，将其抽象为单一 $\sigma^2_{\text{img}}$ 通道由 NDPN 处理是合理的简化。

### 3.2 σ²_illu (光照扰动) 作为独立分量——**证据强**

| 文献                                                                                        | 结论                                                                | 支持强度       |
| ----------------------------------------------------------------------------------------- | ----------------------------------------------------------------- | ---------- |
| [Land & McCann, JOSA 1971](https://doi.org/10.1364/JOSA.61.000001)                        | Retinex 理论：图像 = 光照 L × 反射率 R                                      | ⭐⭐⭐⭐⭐ 经典   |
| [Liu et al., IJCAI 2025](https://www.cse.cuhk.edu.hk/~byu/papers/C275-IJCAI2025-LLVE.pdf) | 视频级 view-independent (反射率) + view-dependent (光照) 分解，验证光照是时域变化主导因素 | ⭐⭐⭐⭐⭐ 视频专用 |
| [AFD-LLIE (2024)](https://doi.org/10.48550/arxiv.2409.01641)                              | 频域证据：低频=光照，高频=噪声/结构；Laplace 金字塔解耦学习                               | ⭐⭐⭐⭐ 频域支撑  |
| [Decoupled LLIE (2021)](https://doi.org/10.48550/arxiv.2111.14458)                        | 二阶段解耦：可视性(光照) → 保真度(其他)                                           | ⭐⭐⭐⭐       |
| [DCD-Net (Sensors 2025)](https://www.mdpi.com/1424-8220/25/22/7038)                       | Decoupling-Centric Decomposition：光照-反射率解耦精化                       | ⭐⭐⭐        |

**结论**：将光照作为独立分支处理已有大量文献支撑，且视频领域已有二源解耦（光照+反射率）的先例。

### 3.3 σ²_dyn (运动扰动) 作为独立分量——**证据较强但需谨慎**

| 文献 | 结论 | 支持强度 |
|------|------|---------|
| [Baker et al., IJCV 2011](https://doi.org/10.1007/s11263-010-0390-2) | 光流基础：运动=warping + occlusion，与像素级退化本质不同 | ⭐⭐⭐⭐⭐ 经典 |
| [D²RNet (AAAI 2024)](https://doi.org/10.1609/aaai.v38i4.28144) | UDC 视频解耦为 flare(需长程) 和 haze(需短程)——**方法论上直接类比** | ⭐⭐⭐⭐⭐ 强类比 |
| [VSRELL (CVPR 2026)](https://openaccess.thecvf.com/content/CVPR2026/papers/Hui_VSRELL_A_Simple_Baseline_for_Video_Super-Resolution_and_Enhancement_in_CVPR_2026_paper.pdf) | INCO 明确联合建模光照+噪声，ISFP 单独处理运动传播——**验证运动应独立** | ⭐⭐⭐⭐⭐ 最新支撑 |
| [DP3DF (AAAI 2023)](https://ojs.aaai.org/index.php/AAAI/article/view/25409/25181) | 论证去噪(需多帧平均)与提亮(需保对比度)存在时域冲突，需专用架构 | ⭐⭐⭐⭐ |
| [TCE-Net (IJCV 2024)](https://link.springer.com/article/10.1007/s11263-024-02084-w) | 明确指出低光视频存在"spatial fidelity vs temporal consistency"根本冲突 | ⭐⭐⭐⭐ |

**结论**：将运动作为独立第三源在文献中虽然没有直接的"三源"表述，但**将运动补偿从像素级去噪和光照增强中显式分离**已有充分先例（D²RNet, VSRELL, TCE-Net）。你的贡献是**首次将三者整合为统一的三源解耦框架**。

### 3.4 需要注意的理论边界——**Perception-Distortion Tradeoff**

[Blau & Michaeli, CVPR 2018](https://openaccess.thecvf.com/content_cvpr_2018/papers/Blau_The_Perception-Distortion_Tradeoff_CVPR_2018_paper.pdf) (被引 849) 数学证明失真与感知质量在任何度量下都存在权衡。这对你的三源框架的启示：
- 三源解耦是**降低优化难度**的手段，但仍受此 tradeoff 制约
- 你的 Mark2 损失调度（先像素后感知）正是应对该 tradeoff 的正确策略
