## 六、核心竞争策略

### TSD-Net vs VLLVE++ 差异化定位

| 维度 | VLLVE++ | TSD-Net 优势 |
|------|---------|-------------|
| **分解理论** | Lambertian I=L⊗R+B，残差项 B 缺乏物理解释 | TSDR 二维统计分类，三源 sufficient & necessary 严格证明 |
| **噪声处理** | 隐式嵌入在 R 和 B 中，无专用噪声分支 | 显式 NDPN 分支 + DPE 噪声先验 s_noise + 置信度引导 |
| **时间建模** | 依赖 DKM 预训练光流（昂贵） | TCA 线性复杂度 RWKV 扫描 + 显式 C_omega 矩阵 |
| **融合策略** | 端到端隐式，L/R/B 无顺序约束 | SGRF 物理驱动 denoise→deblur→brighten，防止噪声放大 |
| **训练策略** | 标准训练 + DKM 预训练依赖 | 两阶段渐进式 + 感知解耦 + Kendall UW |
| **参数效率** | 3.87M / 20.15G | **1.45M** / GFLOPS 待测（预期 < 15G） |

### 论文叙事策略

1. **Introduction**：指出 VLLVE++ 的残差项 B "initialized to zero and learned from reconstruction error" 本质上是端到端黑盒补丁，而 TSD-Net 的三源分解每一源都有明确的物理含义和独立的处理策略
2. **Related Work**：将 VLLVE++ 归入 "Parallel methods" 但指出其仅做了 2+1 分解（R, L 是显式的，B 是隐式残差），不等于真正的三源解耦
3. **Method**：强调 Eq.1 的三源模型与 VLLVE++ 的 I=L⊗R+B 的本质区别——TSD-Net 区分 imaging noise 和 motion 两种时间行为完全不同的退化源，而 VLLVE++ 的 B 混合了两者
4. **Experiments**：在计算效率表中突出 **1.45M vs 3.87M** 的参数优势
