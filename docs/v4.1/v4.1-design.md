## 1. 设计动机

### 1.1 v4 问题诊断

v4 训练 9 epoch 后，梯度诊断结果：

| 模块 | 梯度均值 | 相对 IGRF |
|------|----------|-----------|
| encoder | 0.003601 | 0.616x |
| tfsi | 0.002748 | 0.470x |
| sace | 0.001366 | 0.234x |
| **ifpn** | **0.000505** | **0.086x** |
| ndpn | 0.001478 | 0.253x |
| mrpn | 0.003025 | 0.517x |
| igrf | 0.005848 | 1.000x |

**核心问题**：
1. IGRF 的 4 路 concat → Conv(4C→C) → 4×ResBlock 结构，使各分支梯度经过长链衰减
2. IFPN 内部乘法调制 `F_t * (1+ratio_feat)` 在 ratio_feat ≈ 0 时产生梯度消失
3. 并行 concat 一次性融合缺乏物理语义

### 1.2 学术依据

- **FDN (Tu et al., IEEE TIP 2025)**：低光和模糊退化在傅里叶域可解耦——先修复振幅（光照亮度恢复），再修复相位（模糊边缘恢复）。物理模型 y = gamma(x*k) + n 的修复应逆序进行。
- **MPRNet (Zamir et al., CVPR 2021)**：多阶段渐进式修复 + 每阶段独立监督 + 跨阶段特征传递，验证了逐步消除退化的有效性。
- **DarkIR (Feijoo et al., CVPR 2025)**：encoder 处理光照退化（频域），decoder 处理模糊退化（空间域大感受野），功能分区设计。
- **NAFNet (Chen et al., ECCV 2022)**：残差 skip connection 是保证深层网络梯度畅通的关键。

## 2. 架构设计

### 2.1 整体流程对比

**v4（旧）：**
```
Encoder → TFSI → SACE → [IFPN, NDPN, MRPN 并行] → IGRF(concat 4路) → delta → res_t
```

**v4.1（新）：**
```
Encoder → TFSI → SACE → [IFPN, NDPN, MRPN 并行]
                                    ↓
                              IGRF v4.1 顺序级联融合：
                              image_center
                                ↓ + f_illum_out
                              Stage 1: 光照修复 → img_s1 (中间监督)
                                ↓ + f_noise_out
                              Stage 2: 去噪修复 → img_s2 (中间监督)
                                ↓ + f_motion_out
                              Stage 3: 运动修复 → res_t (最终输出)
```

**关键**：三源分支仍然**并行**独立计算各自特征（不改动 IFPN/NDPN/MRPN 的内部逻辑），仅在 IGRF 融合阶段改为**顺序**应用到图像上。

### 2.2 IGRF StageBlock 设计

```python
class StageBlock(nn.Module):
    """单阶段修复块"""
    def __init__(self, channels, img_channels=3):
        self.img_proj = Conv2d(img_channels, channels, 3, 1, 1)
        self.fuse = Sequential(
            Conv2d(channels*2, channels, 1), GELU(),
            ResBlock(channels), ResBlock(channels),
            Conv2d(channels, img_channels, 3, 1, 1),
        )

    def forward(self, f_branch, img_current):
        img_feat = self.img_proj(img_current)
        combined = cat([f_branch, img_feat], dim=1)
        delta = self.fuse(combined)
        return clamp(img_current + delta, 0, 1), delta
```

每个 StageBlock：
- 输入：分支特征 + 当前阶段图像
- 将图像编码为条件特征（让网络知道"还需修复什么"）
- 输出：残差 delta + 修复后图像

### 2.3 IFPN 加法残差修复

**v4：**
```python
F_t_illum = F_t * (1.0 + ratio_feat)  # 乘法调制
```

**v4.1：**
```python
f_illum_out = F_t + self.refine(F_t + ratio_feat)  # 加法 + skip
```

即使 ratio_feat = 0，梯度仍通过 skip connection 直通回传。

## 3. 数学公式与理论分析

### 3.1 低光视频退化的物理模型

低光视频帧的成像过程可建模为复合退化函数：

```
y_t = f_illum( f_motion( f_noise(x) ) )
```

其中：
- `x`：真实场景辐照度（即 GT）
- `f_noise`：成像噪声（传感器高斯噪声 + 散粒噪声）
- `f_motion`：运动模糊（帧间运动 + 相机抖动导致的卷积模糊）
- `f_illum`：低光照导致的非线性亮度衰减（gamma 响应曲线）

根据 **Tu et al. (TIP 2025)**，上述退化在傅里叶域可解耦：

```
F{y_t} = A(y_t) · exp(j·φ(y_t))
```

- 振幅谱 `A(y_t)` 主导 **亮度/对比度退化**（低光特征）
- 相位谱 `φ(y_t)` 主导 **几何结构退化**（运动模糊、散焦）

因此物理上合理的修复顺序是 **逆序消除退化**：先修复光照（振幅域），再修复噪声（像素域），最后修复运动模糊（结构域）。

> **依据**：若先修复模糊再修复光照，光照的非线性变换（gamma 曲线）会破坏已恢复的边缘结构。

### 3.2 IFPN 光照修正：v4 乘法 → v4.1 加法残差

**v4 设计（乘法调制）**：

```
f_illum = F_t ⊙ (1 + ratio_feat)
f_illum_out = Refine(f_illum)
```

其中 `F_t ∈ R^{B×C×H×W}` 为中心帧特征，`ratio_feat ∈ R^{B×C×H×W}` 由光照比率图投影得到。

梯度分析（对 F_t 的偏导数）：

```
∂f_illum / ∂F_t = (1 + ratio_feat)   ← 乘法调制因子
```

**问题**：初始化时 `ratio_feat ≈ 0`，因此：

```
∂f_illum / ∂F_t |_{ratio_feat→0} = 1 + 0 = 1  （看似没问题）
```

但梯度回传到 ratio_feat 本身时：

```
∂f_illum / ∂(ratio_feat) = F_t   ← 依赖 F_t 的绝对值大小
```

当 `F_t` 在低光区域数值较小时（低光帧特征激活度低），**ratio_feat 的梯度本身也弱**，导致光照比率估计无法有效学习，形成"光照估计越差 → 特征越弱 → 梯度越小 → 光照估计更差"的恶性循环。

**v4.1 设计（加法残差 + skip connection）**：

```
f_illum_out = F_t + Refine(F_t + ratio_feat)
```

梯度分析（对 F_t 的偏导数）：

```
∂f_illum_out / ∂F_t = 1 + ∂Refine/∂F_t
```

对 ratio_feat 的偏导数：

```
∂f_illum_out / ∂(ratio_feat) = ∂Refine/∂(ratio_feat)
```

**关键改进**：
- `∂f_illum_out / ∂F_t = 1 + ∂Refine/∂F_t ≥ 1`，梯度始终有 skip connection 直通路径（恒等映射），不会被乘法衰减
- 即使 `ratio_feat = 0`，`Refine` 网络的输入仍然是非零的 `F_t`，其内部权重梯度正常更新
- 这与 NAFNet（ECCV 2022）的残差设计一致：恒等映射路径是梯度畅通的保障

### 3.3 IGRF v4.1 顺序级联融合

**v4 设计（一次性 concat 融合）**：

```
f_fused = Conv_{4C→C}( [f_base, f_illum, f_noise, f_motion] )  ← 通道拼接
delta   = ResBlock×4 (f_fused)
res_t   = clamp(I_center + delta, 0, 1)
```

各分支特征对 delta 的梯度需要穿越 4 个 ResBlock + 1 个投影卷积才能回传，且分支间无明确的语义区分。

**v4.1 设计（顺序级联 + 图像条件化）**：

定义单阶段修复函数 `Stage_k(f_k, I_{k-1})`：

```
img_feat_k = Conv_{3→C}(I_{k-1})                        ← 图像条件编码
combined_k = Concat( [f_k, img_feat_k] )                  ← 分支特征 + 图像拼接
delta_k    = Conv_{2C→C}( combined_k ) → GELU → ResBlock×2 → Conv_{C→3}
I_k        = clamp( I_{k-1} + delta_k, 0, 1 )           ← 残差叠加
```

三阶段顺序执行：

```
Stage 1（光照修复）：  I_1 = I_0 + delta_1(f_illum, I_0)        其中 I_0 = I_center
Stage 2（去噪修复）：  I_2 = I_1 + delta_2(f_noise, I_1)
Stage 3（运动修复）：  I_3 = I_2 + delta_3(f_motion, I_2)      最终 res_t = I_3
```

展开后：

```
res_t = clamp( I_0 + delta_1 + delta_2 + delta_3, 0, 1 )
```

**理论优势（vs v4）**：

| 维度 | v4 concat | v4.1 顺序级联 |
|------|-----------|---------------|
| 融合语义 | 无物理顺序，依赖网络自学 | 光照→噪声→运动，与退化物理顺序一致 |
| 图像条件 | 无（仅从特征预测 delta） | 每阶段感知当前图像，自适应决定修复策略 |
| 梯度回传 | 所有分支共享同一梯度链（8层） | 每分支有独立短链（2层）+ 直接中间监督 |
| 可解释性 | 融合权重不透明 | 每阶段 delta 有明确物理含义 |

### 3.4 中间阶段监督损失 L_inter

**v4 设计（aux_head 特征重建）**：

```
L_aux = (1/K) × Σ_k Charbonnier( Head_k(f_branch_k), I_GT )
```

其中 `Head_k: R^{B×C×H×W} → R^{B×3×H×W}` 是额外训练的辅助重建网络（每分支约 3.2K 参数）。

**问题**：Head_k 从特征空间到图像空间需要学习复杂的映射，本身也面临训练困难，辅助监督信号被 Head 网络的学习瓶颈过滤。

**v4.1 设计（直接图像空间监督）**：

IGRF 的 StageBlock 直接输出图像，无需额外 Head：

```
img_s1 = Stage_illum (f_illum, I_0)    ← 光照修复后图像，已在图像空间
img_s2 = Stage_noise (f_noise, img_s1)  ← 去噪后图像，已在图像空间
```

中间监督损失：

```
L_inter = (1/2) × [ Charbonnier(img_s1, I_GT) + Charbonnier(img_s2, I_GT) ]
```

其中 Charbonnier 损失定义为：

```
Charbonnier(pred, target) = E[ √((pred - target)² + ε) ]     ε = 1e-6
```

**梯度流分析**：对 IFPN 而言，L_inter 对 `f_illum` 的梯度路径为：

```
∂L_inter / ∂f_illum  = ∂Charb(img_s1 - I_GT) / ∂delta_1 × ∂delta_1 / ∂f_illum
```

`∂delta_1 / ∂f_illum` 仅穿越 StageBlock 的 `fuse` 网络（1×Conv + GELU + 2×ResBlock + 1×Conv），约 4 层，衰减远小于 v4 的 8 层链。

---

### 3.5 总损失函数完整表达

```
L_total = L_recon + λ_ssim · L_ssim + λ_perc · L_perc + λ_illum · L_illum + λ_inter · L_inter
```

其中：

```
L_recon = Charbonnier(res_t, I_GT) + λ_freq · L1(|FFT(res_t)|, |FFT(I_GT)|)

L_ssim  = 1 - SSIM(res_t, I_GT)

L_perc  = L1(φ_VGG(res_t), φ_VGG(I_GT))       ← VGG-16 特征空间

L_illum = E[|∇_h s_illum| · exp(-|∇_h I_GT|)]  +  E[|∇_v s_illum| · exp(-|∇_v I_GT|)]
          ← edge-aware smoothness（在 GT 边缘处允许强度图不连续）

L_inter = (1/2) · [Charbonnier(img_s1, I_GT) + Charbonnier(img_s2, I_GT)]
```

超参数：
```
λ_ssim = 0.2,  λ_perc = 0.2,  λ_freq = 0.1,  λ_illum = 0.01,  λ_inter = 0.3
```

## 4. 梯度流改善分析（实测）

### 4.1 v4 梯度路径（长链）
```
Loss → IGRF.recon_head(4×ResBlock) → IGRF.fuse_proj(4C→C) → f_illum_out → IFPN
                    约 8 层衰减
```

### 4.2 v4.1 梯度路径（短链 + 直接监督）
```
L_inter(img_s1 vs GT) → delta_s1 → StageBlock_illum → f_illum_out → IFPN
                              仅 2 层 (img_proj + fuse)，且有中间监督直达
```

| 模块 | v4 (ratio/IGRF) | v4.1 (ratio/IGRF) | 改善 |

| ndpn | 0.253x | 0.131x | — |
