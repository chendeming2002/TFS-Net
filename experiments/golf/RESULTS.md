## 二、问题诊断与分析

### 2.1 Golf R1-S2 四大问题

#### 问题 #1：conf_map 饱和崩溃（证据链）

| epoch | conf_map 均值 | std | 判读 |
|-------|--------------|-----|------|
| ep5 | 0.812 | 0.15 | 健康动态 |
| ep10 | 0.969 | 0.08 | 逼近饱和 |
| **ep20** | **1.000** | **0.00** | **完全饱和，退化恒等门** |

**根因诊断**：
```python
# models/golf/branch_m.py::ConfidenceEstimator
self.conf_head = nn.Sequential(
    nn.Conv2d(channels, channels//2, 3, 1, 1),
    nn.ReLU(inplace=True),
    nn.Conv2d(channels//2, 1, 1),  # ← bias 默认初始化 ~0.5
    nn.Sigmoid(),  # ← 通过 bias=2.0 手动设置偏高起点
)
```

实际效果：
- bias=2.0 → sigmoid 输入均值 ≈ 2.5（bias + feature 小贡献）
- sigmoid(2.5) = **0.92**（起点过高）
- 5 帧 softmax 后：`[0.94, 0.94, 0.94, 0.94, 0.94]`（均匀分布假象）
- 优化路径：0.94 → 1.0（空间极窄，6% 剩余）
- ep10 后梯度全部推向唯一可行方向 → 全部饱和

**验证证据**：
1. 训练日志 `conf_map` 轨迹单调上升无回落
2. ep20 检查点可视化：所有位置 conf=1.0（白色满图）
3. 对比 Flight11（无手动 bias）：conf 长期维持 0.698±0.15 健康动态

**结论**：**ConfidenceEstimator 的 bias=2.0 偏置是设计错误**，制造了饱和陷阱。正确设计应 bias=0（中性起点 0.5）。

---

#### 问题 #2：Branch-M warp_t 贡献崩溃

| 分支 | ep5 权重 | ep20 权重 | 预期 | 判读 |
|------|----------|----------|------|------|
| Branch-N (原始) | 0.65 | 0.72 | 基线贡献 ✓ | 稳定 |
| Branch-L (低频) | 0.29 | 0.25 | 低频增强 ✓ | 正常 |
| **Branch-M (warp)** | **0.18** | **0.03** | **> 0.5（运动对齐）** | ⚠️ **被抑制** |

**根因诊断**：
```python
# models/golf/branch_m.py::forward()
# Step 1: F2 编码（H/2 分辨率）
F2_seq = [self.enc_proj(f2) for f2 in F2_list]  # shape: (B, C, H/2, W/2)

# Step 2: 光流估计 + warp（H/2 域）
flow = self.flow_estimator(F2_t, F2_ref)
F2_warped = self.warp(F2_ref, flow)  # ← 在 H/2 分辨率 warp

# Step 3: warp 后上采样到 H
F2_warped_up = F.interpolate(F2_warped, scale_factor=2, mode='bilinear')
```

**问题链**：
1. 双线性插值（bilinear）= 低通滤波，**精细结构模糊**
2. warp 本就引入插值误差，二次插值（warp 内部 + 上采样）累积模糊
3. 模糊特征 vs Branch-N 清晰特征 → 权重网络学到 "warp 分支不可靠" → 抑制权重

**对比 LLVE 最佳实践**（fastdvdnet, STCD）：
- **正确做法**：F2 → **先上采样 H** → warp(H 域) → 保持锐度
- Golf 错误做法：F2 → warp(H/2) → 上采样 → 累积模糊

**验证证据**：
1. ep20 warp_t 从 ep5 的 0.18 衰减到 0.03（6 倍下降）
2. 可视化：warp_t 输出边缘明显模糊于 norm_t
3. PSNR 消融（无 warp 分支）= 19.61 vs 有 warp=19.66（仅 +0.05dB，贡献微弱）

**结论**：**H/2 域 warp + 双线性上采样 = 精细结构损失 → 分支被权重网络判定无效**。

---

#### 问题 #3：高频震荡（夜景过增强）

**观测**：
- 输入夜景 HF 能量（高通滤波后）：mean = 0.05
- 预测输出 HF 能量：mean = 0.09（1.8× 输入）
- GT HF 能量：mean = 0.06（1.2× 输入）
- **过增强**：预测 HF 比 GT 高 50%

**根因诊断**：
```python
# models/golf/loss.py::GolfLoss._temp_consistency()
def _temp_consistency(self, X, O):
    X_high = self.high_pass(X)
    O_high = self.high_pass(O)
    threshold = 1.5 * X_high.abs().mean()  # ← 阈值过宽
    return F.relu(O_high.abs().mean() - threshold)
```

**问题**：
- 阈值 1.5× 允许输出 HF 能量达到输入的 150%
- 夜景输入本身低对比（HF 弱），1.5× 仍然很宽松
- 实际训练中 L_temp 很少被激活（< 1% 的 step），失去约束

**对比 FRBNet**（频域正则 SOTA）：
- 动态阈值：`threshold = max(1.1 * X_high, 0.5 * GT_high)`（更紧）
- 自适应调整：亮场景 1.5×，暗场景 1.1×

**验证证据**：
1. 训练日志 L_temp 均值 ≈ 0.0002（接近零，未激活）
2. 预测图像 histogram：高频成分过集中（锐化过度）
3. 主观评价：夜景噪声放大（HF 过增强副作用）

**结论**：**L_temp 阈值 1.5× 对低光场景过宽，需收紧至 1.2× 或自适应**。

---

#### 问题 #4：验证集过拟合风险

**观测**：
- val 集：仅 5 个序列（pair1-5, 室内静态为主）
- 训练 60 epoch = 每序列被验证 6 次 × 多裁剪窗口 = **高频重复**
- pair45（高速运动）从未在训练/验证中出现

**风险**：
- 模型可能记忆 5 序列的特定模式（光照分布、纹理）
- val PSNR 上升 ≠ 泛化能力提升
- pair45 性能未知（运动场景可能崩溃）

**对比 EvRWKV**（长视频 LLVE SOTA）：
- test-easy（静态）+ test-hard（运动）双指标
- 若 test-easy ↑ 但 test-hard ↓ → 过拟合警报

**验证需求**：
- 每 val_interval 同步评估 pair45 前 30 帧
- 记录双指标：`val_psnr` (5 序列) + `pair45_psnr` (运动序列)
- 若 gap > 3dB → 过拟合，需数据增强

**结论**：**单一静态 val 集不足以监控泛化，需增加 pair45 运动指标**。

| 维度 | Golf R1-S2 | Flight11 S1.5 v1.1 | 判读 |
|------|-----------|-------------------|------|

## 三、顶层 idea 回溯（LLVE 最佳实践）

从 8 个 SOTA 仓库源码级分析（CDVD-TSP/fastdvdnet/STCD/DRWKV/URWKV/EvRWKV/StableLLVE/FRBNet）提取的 **已验证有效模式**：

| ID | 模式 | 源仓库 | Golf R1 采用情况 | R3 改进计划 |
|----|------|--------|-----------------|------------|
| **#1** | **conf 中性起点** | CDVD-TSP | ❌ 用了 bias=2.0 | ✅ R3-A: bias→0 |
| **#2** | **高分辨率 warp** | fastdvdnet, STCD | ❌ H/2 域 warp | ✅ R3-B: H 域 warp |
| **#3** | **退化感知调制** | StableLLVE (FiLM) | ❌ 无 | ✅ R3-C: F3 FiLM |
| **#4** | **高频能量正则** | FRBNet | ⚠️ 阈值过宽 | ✅ R3-E: 1.5→1.2 |
| **#5** | **双验证集监控** | EvRWKV (test-easy/hard) | ❌ 仅 val | ✅ R3-D: +pair45 |
| #6 | luckiness 残差门 | URWKV | ✅ 已采用 | - |
| #7 | disp_field 外部监督 | CDVD-TSP | ❌ 无 disp | 🔄 R4 可选 |
| #8 | LAN 时间锚定 | FRBNet | ❌ 无 | 🔄 R4 可选 |

**R3 策略**：优先修复 #1-#5（P0/P1 问题直接对应），#6 已有，#7-#8 留待 R4（若 R3 成功）。

---

### 3.1 idea #3 详解：F3 FiLM 退化感知调制

**原理**（StableLLVE 验证有效）：
- TCA-RWKV 当前所有帧用统一权重 → 无法区分低光/运动模式
- F3 (H/4 深层编码) 包含高级语义（亮度、运动幅度）
- 时序均值 + 全局 pool → 退化描述子 (B, C3)
- MLP → FiLM 参数 γ/β (B, tca_channels)
- 每个 RWKV block：`x = x * (1 + γ) + β`（通道级调制）

**预期效果**：
- 低光帧：γ 放大低频通道，β 提升基线
- 运动帧：γ 放大高频通道，β 保持中性
- 动态自适应 vs 当前固定权重

**验收**：FiLM γ std > 0.1（非退化常数）+ 不同场景 γ 分布分化

---

### 3.2 idea #7/#8 为何暂缓

| idea | 原因 |
|------|------|
| **#7 disp_field 监督** | Golf 无 MCPN（运动补偿分支），disp 无处接入；若 R3 成功可在 R4 加第四分支 |
| **#8 LAN 时间锚定** | 需要 multi-stage 架构（ISPN→LAN→输出），Golf 单 stage；改动成本高 |

**决策**：R3 聚焦 P0/P1 修复（5 改进），R4 若需要再考虑架构扩展（#7/#8）。
