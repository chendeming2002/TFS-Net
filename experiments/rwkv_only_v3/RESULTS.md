## 2. 阶段 1 诊断结果

### 方案 1: motion_map 可视化 — **确认完全退化**

v2 (ep49) 与 v3 (ep50) 在 pair20/pair45 上的 motion_map：

| 模型 | pair20 | pair45 | 空间 std |
|------|:--:|:--:|:--:|
| v2 | 0.6400 (std=0.0000) | 0.6400 | 0.0000 |
| v3 | 0.7613 (std=0.0001) | 0.7613 | 0.0001 |

**结论**：设计文档 1.1 节的质疑（"没有数据前退化结论不成立"）已由数据裁决——**motion_map 是纯全局常数**。conf_proj（4→1 Linear per-pixel）无论加不加 conf_scale 都会坍塌为固定 bias。v2/v3 的"运动门控"实际退化为**固定的 TCA/l1 信号配比**（v2: 36%TCA+64%l1；v3: 24%TCA+76%l1）。

v2 相对 v1 的 +0.22dB 提升来自"整体更信任单帧特征"，而非逐像素运动感知。C_omega 对角线作为运动信号的判别力不足（doc 1.1 观察三的推测被证实）。

### 方案 5: 无 TCA ablation — TCA 的真实角色

| ep | 无TCA | v1(有TCA) | 差值 |
|:--:|:--:|:--:|:--:|
| 10 | **19.66** | 19.57 | +0.09 |
| 20 | 19.56 | 19.53 | +0.03 |
| 30 | 19.37 | **19.80** | -0.43 |

**结论**：
- TCA 在训练早期是**负贡献**（低分辨率软对齐引入的模糊 > 多帧降噪收益）
- TCA 在后期提供**容量/正则化**（无TCA 从 ep10 起持续过拟合下跌）
- TCA 的价值不是"时序对齐"而是"多帧信息正则化"——证实软对齐模糊问题真实存在
- 长训（≥30ep）TCA 净收益 +0.4dB 级别，值得保留

## 3. 阶段 2/3: 组件归因（ablation 系列）

### 方案 3（sigmoid 移除）单独 = 有害 ★ 关键反直觉发现

ablation A（v2+仅方案3）：ep10=19.31, ep20=19.34
同期 v2 对照：ep10=19.46, ep20=19.63

**-0.29dB @ep20**。设计文档第 5 节预测 sigmoid 移除是"+0.5dB 的最大 free lunch"——**实测方向完全相反**。

原因复盘（假设，待进一步验证）：
1. 无 sigmoid 后 head 输出无界，模型需额外容量学习输出域约束
2. SSIM 损失在无界数值上的统计量（μ、σ²）计算数值不稳定
3. 推理时 clamp(0,1) 造成训练/推理不一致，暗区输出可能被截断

**文档第 6 节"暗光 sigmoid 梯度压制是最大问题"的判断被证伪。** Sigmoid 的暗区梯度衰减并没有成为瓶颈——可能因为 L1 主导的损失对输出域的约束学习成本低于 sigmoid 饱和损失。

### BC（v2+2A+4）= 19.52@20 —— "+0.26dB" 推断正式撤回 ★ 方法论教训

BC 实测：ep10=19.52, ep20=19.52（平坦），vs v2@20=19.63 → **-0.11dB**。

早期曾由 "v3@ep40(19.99) - A@ep20(19.34)" 推断 2A+4≈+0.26dB——该推断**跨训练长度比较，是伪影**，由此启动的 BC 实验未能兑现。

**同 ep20 配对的全景（20ep 预算内）**：

| 配置 | ep20 | vs v2 |
|------|:--:|:--:|
| v3 (2A+3+4) | 19.66 | +0.03 |
| v2 (基线) | 19.63 | 0 |
| 无TCA | 19.56 | -0.07 |
| v1 | 19.53 | -0.10 |
| BC (2A+4) | 19.52 | -0.11 |
| A (仅3) | 19.34 | -0.29 |

**三条结论**：
1. **组件交互非可加**：v2+3=-0.29, v2+2A+4=-0.11, v2+2A+3+4=+0.03——单组件消融无法预测组合行为
2. **head 层面微调路线穷尽**：所有 2A/3/4 组合均在 ±0.3dB 内纠缠，无一稳定超越 v2 → v2 保持基线（20.02@40）
3. **未决混淆**：BC 仅 20ep（v2 最大涨幅在 ep20→40 的 +0.39 被截断）；且 A/BC 用 AMP+v2 未用。BC@40 未知——严格终判需续训到 ep40

### T-BC1（局部窗口对齐）= 新管线组最优，但置信度引导死锁 ★ 机制诊断

TBC 实测：ep10=19.60, ep20=**19.69**——新管线组（A/BC/TA/TBC）最优，ep10→20 仍在上升（+0.09，非 BC 的平坦型）。

**但机制诊断揭示冷启动死锁**：

| 诊断量 | 实测 | 判读 |
|--------|------|------|
| conf 均值 (pair20 静态) | **0.0133** | = 均匀 softmax 底线 (1/81=0.0123) |
| conf 均值 (pair45 运动) | **0.0131** | 与静态场景**无差异** |
| motion_map 空间 std | 0.0011-0.0015 | 无空间结构 |

conf 从随机初始化 (≈0.013) 经 20 epoch 训练**纹丝未动**，静态/运动场景无分化 → TSDR §6.4 的路由预测失败，T-BC 实际以"单帧自举"模式运行：LocalWindowAlignment 内部 `out = conf·F_agg + (1-conf)·center` ≈ 纯 center 透传，模型级 motion_map≈0.99 → tca_gated ≈ 纯 l1_gate。

**死锁根因（已量化）**：conf 是**乘性自门控**——对齐支路的梯度被 conf 本身缩放（×0.013 ≈ 75×衰减）。初始 temp=softplus(0)+0.02=0.713 下随机嵌入余弦相似度 ±0.1 → max_prob≈0.017≈均匀 → 支路关闭 → 无梯度改善嵌入 → conf 永远起不来。诊断性验证：temp=-2 时 max_prob 也仅 0.049——**单纯调温度不够，需结构修复**。

**PSNR 归因**：TBC 的 +0.13 vs 无TCA@20 (19.56) 不来自时序对齐（已旁路），而来自 **l2 通路的 spatial WKV（修复后算子）**——这与 TA 中性的结论组合指向：WKV 空间增强有小正贡献，C_omega 时序路径贡献为零。

**修复方向（T-BC1b 候选）**：打破自举死锁——在恒等偏移 (0,0) 加 logit 偏置（初始 conf≈0.9，"先信任对齐，学会在错误处不信任"），或将 conf 改为独立可学习门（conv on [center, F_agg] 统计量）而非乘性自门控的 max-prob。

### T-BC1b（bootstrap=bias + 逐帧 softmax）= 死锁解除 + 当前最优 ★ 但路由假说二次证伪

**实现**：(1) 恒等偏移 (0,0) logit bias（init 5.8，初始 conf≈0.78，"先信任对齐后学弃权"）；(2) 修复 T-BC1 隐藏 bug——原实现 Tn·R² 联合 softmax 使 Tn 个恒等偏移互相竞争，**conf 上限被钳在 1/Tn=0.25**；改为逐帧 softmax（帧内对齐 × 帧间门控解耦），上限恢复 1.0。

TBC1B 实测：ep10=19.27（低开——初始信任随机嵌入的垃圾对齐）, ep20=**19.78**（ep10→20 斜率 +0.51 为全部实验最陡）。

| 对照 | @ep20 | 差值 |
|------|:--:|:--:|
| **TBC1B** | **19.78** | — |
| TBC（死锁版）| 19.69 | **+0.09（聚合激活的净收益）** |
| 无TCA | 19.56 | +0.22 |
| v2@20 | 19.63 | **+0.15** |
| v3@20 | 19.66 | +0.12 |

**机制诊断——bootstrap 修复成功，路由假说二次证伪**：

| 诊断量 | T-BC1 | T-BC1b | 判读 |
|--------|:--:|:--:|------|
| conf 均值 (pair20) | 0.0133 | **0.698** | 激活 ✓（0.013→0.70）|
| conf 均值 (pair45) | 0.0131 | **0.6995** | 激活 ✓ |
| 静态 vs 运动分化 | 无 | **仍无**（0.698≈0.6995）| ✗ 路由假说二次证伪 |
| identity_bias 轨迹 | — | 5.8→5.22（缓降）| 温和调制 |

三层结论：
1. **自举修复有效**：conf 激活（0.70 高位运行），聚合通路真实参与 → **+0.09dB 净收益来自"多帧聚合首次在正确算子+全分辨率下工作"**——TSDR 理论中 Type I/II 时间平均降噪的红利首次兑现
2. **路由假说二次证伪**：即使 conf 活跃且量级正常，静态/运动场景仍无分化。根因：SDSD 室内运动极小（±1-4px），窗口内真实匹配与非匹配内容高度相似 → max-prob 天然不区分。**"运动感知路由"（v2 gate / T-C fallback）在两种实现下均告死亡**
3. **胜出配置是更简单的形态**：始终开启的全分辨率局部窗口聚合 + 可学习帧门，无任何运动路由——与整个实验弧线"简化者胜"一致

**未决**：TBC1B 仅 20ep 且轨迹陡升（+0.51）——v2 的主涨幅在 ep20→40 (+0.39)，TBC1B@40 大概率挑战 20.02 基线。管线混淆（-0.1dB）未消解。

### T-BC1b 续训至 ep40 = 平 v2 峰值 + 运动场景决定性改善 ★ 骨干路线收官

TBC1B 全轨迹：ep10=19.27 → ep20=19.78 → ep30=19.46（dip，与 v1/v3 的 ep30 谷一致）→ ep40=**19.99**。

**全局 PSNR 终判（256² 测试集）**：

| 配置 | 峰值 | 差值 |
|------|:--:|:--:|
| v2（基线，全局 warp + motion gate）| 20.02@40 | 0 |
| **TBC1B（局部窗口对齐，无运动路由）** | **19.99@40** | **-0.03（噪声内平手）** |

**运动场景终判（pair45 全量 127 帧， hardest 场景）**：

| 指标 | TBC1B@40 | v2@49 | 差值 |
|------|:--:|:--:|:--:|
| PSNR | **15.69** | 15.04 | **+0.65** |
| SSIM | **0.697** | 0.679 | +0.018 |

**机制归因**：pair45 的 +0.65dB 证明局部窗口对齐**真实改善了运动场景**——SDSD 的 ±1-4px 小运动落在 9×9 窗口容限内，窗口对齐成功补偿位移（旧全局 warp 在此场景产生凸组合模糊）。conf 在 pair45 上仍≈0.69 与静态无分化，进一步佐证：**收益来自"对齐机制本身"，与"运动路由"无关**（路由假说二次证伪的补证）。

**终审结论**：
1. **PSNR 全局：平手**（-0.03 在噪声/管线混淆内）
2. **运动场景：+0.65dB 决定性改善**——T-BC 的原始动机（修复运动模糊）兑现
3. **架构推荐**：T-BC1b 形态（局部窗口对齐 + bootstrap=bias + 逐帧 softmax + 可学习帧门）**取代 v2 成为下一完整版本的主干**。理由：全局 PSNR 平手的前提下，运动场景 +0.65dB、消除全帧凸组合模糊机制、TSDR 契合（显式对齐）、三分支接口就绪（warped_list/disp_field/conf_map）
4. v2 的 motion gate 被 T-BC1b 的"始终开启聚合 + 可学习帧门"取代——门控的生存形态是帧选择，不是运动路由

### v3 (19.99) ≈ v2 (20.02) 谜底的修正表述

~~"2A+4 净贡献 ≈ +0.26 被方案 3 抵消"~~ → 实际：同长度对比下 v3@20 (19.66) 与 v2@20 (19.63) 本就相当（+0.03），组合内部是 3 与 2A/4 的非可加纠缠，不存在可分离的"+0.26 正成分"。

### T-A（WKV 算子修复 + 解除休眠）= 中性结果，但锁定瓶颈 ★ 骨干路线第一步

修复内容：(1) `_scan_cumsum` 跨 chunk 衰减方向改正（ew^{cs-1-j}→ew^{j'+1}）+ state off-by-one（ew^{cs-1}→ew^{cs}），naive 对照 4.77e-07 PASS、旧版 2.40e-02 BUG 实锤；(2) `spatial_gamma` 零初始化→ones；(3) 删死代码。

TA 实测：ep10=19.31, ep20=**19.55**，vs v2@20=19.63 → **-0.08dB（中性）**，与 v1(19.53)/无TCA(19.56) 同一水平带。

**关键证据——gamma 轨迹**：从 ones 出发训练后 mean=0.79、范围 [0.34, 1.24]。WKV 分支**真实参与且被主动调制**（若无用会被压向 0），但净收益仍≈0。

**推论链**：
1. "算子错误/休眠"不是当前瓶颈——修好并激活 WKV 后结果不变
2. 结合无TCA@20=19.56 ≈ TA@20=19.55：**TCA 的存在本身在 ep20 预算内净贡献为零**，无论算子对错
3. 瓶颈锁定在时序聚合路径（C_omega 全局 warp 的结构性模糊）→ **T-BC（局部窗口对齐）成为决定性实验**

**未决混淆（量化的 -0.1dB 系统性差距）**：新管线组（A/BC/TA: 19.34/19.52/19.55）系统性低于旧管线组（v2/v3: 19.63/19.66）@ep20。嫌疑：(a) AMP 混合精度；(b) 分桶采样同 pair 批内高相关 → 批多样性下降；(c) 20ep 截断（v1/v2 的主涨幅在 ep20-40）。TA 的二段斜率（ep10→20: +0.24）是所有 20ep 实验中最陡的，ep30/40 未探明。

## 4. 工程侧结论（与模型无关但影响实验效率）

1. **机器有反复静默断电问题**（7 次，与训练强相关）。两次带温度记录的崩溃均发生在 Package 68-74°C 安全区 → **CPU/GPU 核心过热已排除**，嫌疑集中在 VRM/PSU（无传感器可监测）。建议硬件检修。
2. 温度监控已常态化：`scripts/temp_logger.py`（5s采样+fsync+断电间隙自动标注）+ `scripts/monitor.sh` 监视终端 + `@reboot` crontab 自动恢复。
3. 数据管线优化：uint8 短路 + LRU 帧缓存 + 时序分桶采样，每样本 CPU 162.8→79.4ms（2.1x）。
4. 训练部署：E-core 钉绑（taskset 16-23）+ RAPL PL1=95W（需 root，`scripts/thermal_limit.sh`，重启后失效需重跑）。
5. keepalive 包装器实现断点自动续训（`keepalive_ablation.sh <A|B|C|BC|ABC|none>`）。

## 5. 当前阶段性结论

1. **T-BC1b 架构收官**：TBC1B@40=19.99 平 v2 峰值（20.02@40，-0.03 噪声内），**运动场景 pair45 +0.65dB/SSIM+0.018 决定性改善**——T-BC 原始动机（修复运动模糊）兑现，**推荐 T-BC1b 形态取代 v2 成为下一完整版本主干**
2. **"运动感知路由"假说二次证伪（本阶段最重要结论）**：v2 gate（C_omega 对角线）与 T-C fallback（窗口 max-prob）两种实现下，置信信号均不区分静态/运动（pair45 conf=0.693 仍≈pair20 0.698）。**多帧聚合的有效形态 = "始终开启 + 可学习帧门"，不是"运动路由"**；路由分支从架构候选中移除
3. **TCA 解构完成**：WKV 空间增强 = 小正贡献（TBC vs 无TCA +0.13）；时序聚合激活后 = +0.09（TBC1B vs TBC）+ 运动场景 +0.65；旧 C_omega 全局 warp = 零贡献且机制性致糊。TCA 正确定位 = "空间增强器 + 全分辨率局部窗口聚合器"
4. **head 层面微调路线已穷尽**：方案 3 证伪（-0.29）；2A+4 组合不超 v2（-0.11）；v3 微弱 +0.03 在噪声内
5. **骨干路线历程**：T-A 算子修复（中性，排除嫌疑）→ T-BC1 死锁诊断（乘性自门控冷启动）→ T-BC1b 修复成功 → **平基线 + 运动场景决胜**
6. **方法论教训累积**：组合归因同预算配对；算子必过 naive 测试；乘性自门控冷启动死锁；**跨帧联合 softmax 钳制置信上限（1/Tn）**——帧内归一才算对齐置信；**机制诊断（conf 场景分化）与 PSNR 同等重要**——T-BC1 的 19.69 若无 conf 诊断会被误读为成功
7. **管线混淆待消解**：新管线组 -0.1dB @ep20 系统性差距——TBC1B 旧管线条件下可能 ≈20.1（即实际超基线）
8. **理论侧**：TSDR 的"分离信号"在 SDSD 上不可操作化（动态源太弱）；但 T-BC1b 兑现了理论的另一预测——Type I/II 时间平均在全分辨率对齐下产生真实降噪红利。ISPN 时间锚定缺口仍开放

### 6.7 修正结论存档（本周期改写的旧判断）

1. **"分离信号"判读修正**：conf_map 二次证伪为场景判别器（静态 0.698 ≈ 运动 0.6995）→ 正确语义是**匹配唯一性先验**（warp 前向权重）。TSDR 三源分离是静态机制划分（平滑/对齐/平均），不依赖 TCA 在线判别；TCA 职责 = "对齐材料供应商 + 全局亮度状态提供者"
2. **文献事实澄清**：StableLLVE 无 DCE curve（纯 UNet + 时序一致性 loss）；CDVD luckiness 是光度残差 RBF 权重（非地理高斯 mask），5×5 mean filter 是承重细节；STCD 无 "Anti-Normalization" 概念（最近似物 = log 域反梯度 LTV 权重 + 未启用的 SNR mask）
